# 知衢 · 硕士版

**目标**：让考虑读研的学生或已工作者拿到一份自己看得懂的读研决策报告。报告要回答三件事：
- 该走哪条路（保研、考研、境外读研、中外合作办学、先工作、在职读研、考公，以及是否继续调查博士路径）；
- 每条路报哪里、按什么时间表做；
- 失败了退到哪里。

每条建议都要写明理由和数据来源，并标出哪些还没核实。

保研（推免）分别核本校推荐资格与目标校接收；夏令营、预报名是否存在、与接收有何关系，按学校当年办法看，正式接收在教育部推免服务系统办理。保研要从大一积累，多数人却到大二大三才规划读研，所以按年级判断保研还现不现实，见 `references/tuimian.md`。

和高考版的区别：高考是一次性的位次博弈，有完整的全省数据。读研分几条路，规则不同、时间窗口不同、数据零散；同名的"合作办学硕士"可能是统招，也可能只发外方学位。所以这里**先判断路径，再在路径内选学校**，数据等确定了学生和方向后才去收集。

## 工作流程

1. **确认时间坐标**。先问清几件事：
   - 今天是哪年哪月；
   - 学生读到几年级，哪年毕业；
   - 想哪年入学。

   - 处在哪个阶段（「你现在的位置」一节）。

   **读研版和高考版的根本区别**：高考问卷是出分后填的，分数已定，做的是一次性决策；读研问卷多半在考试或申请之前几个月甚至一两年填，最关键的分数和结果还不知道。所以按阶段决定报告重点：
   - **还在考虑 / 刚决定 / 备考中**：重点是路径、方向、目标区间和备考或申请计划。分数未产生时按可比练习与基础列情景，不能无证据估分；择校给出"目标 + 两档备选"，并写明到哪个节点再定。
   - **初试已出分**：问题变得和高考相似，分数已定。重点是复试规则与本人差距、调剂目标的资格和实际余额，以及二战或就业的比较。
   - **已有录取在比较**：重点是按学生的优先级比较，列出每个录取的确认截止日期、费用和认可度风险。付款和确认由学生本人操作。

   这份报告是**会更新的规划**：在时间线上标出检查点（如 9 月招生目录、10 月报名、初试出分、国家线公布、调剂开放），请学生到时回来改问卷、重新生成画像，AI 据此重算。

   路径能不能走，首先取决于时间。国内报名、初试等已核日期只见 `references/kaoyan.md`；境外按项目的入学季和官方截止日。先查当年文件，窗口未发布或未取到的标明，不能用往年日期冒充今年安排。
2. **读画像，分清四类信息**：
   - 事实：成绩、排名、英语、经历；
   - 偏好：兴趣、城市、预算；
   - 约束：钱、家庭、能否二战；
   - 学生自己的判断：比如"我数学肯定能考 120"。

   第四类需要核实，不能直接当事实。按 `references/routes.md` 做**路径判断**：
   1. 先看资格；
   2. 再看可行性，包括时间、资金、科目与证据缺口；
   3. 最后看值不值。

   如果时间、精力和资金可兼顾，就保留“主路径＋可接受备选”，例如考研与合适的秋招；否则先排冲突。参加秋招不等于已有工作保障。
3. **只读需要的参考**：
   - 中外合作办学或"境内读境外学位"看 `references/sino-foreign.md`；
   - 保研看 `references/tuimian.md`，大三及以上先按其中“能不能拿到本校推荐”部分判断还现不现实；
   - 考研择校、跨专业、调剂、二战看 `references/kaoyan.md`；
   - 要不要读、学硕/专硕、全/非全、在职路径和读博选择看 `references/routes.md`；
   - 出国/境外看 `references/abroad.md`。

   - 「方向与状态」一节有作答，或「为什么读研」一节显示对工作了解很少时，读 `../zhiqu-shared/references/direction-and-state.md`：判断卡在哪一类，给小而具体的下一步；日常烦恼用平常语气回应，不下诊断。

   - 「性格与传统视角」一节有八字时，读 `../zhiqu-shared/references/bazi-lens.md`：八字只作传统视角，与性格作答、现实三方对照，不进入打分和排序。

   前景判断同高考版：若同时安装了 `zhiqu`，读 `../zhiqu-shared/references/outlook.md`（专业和行业的有条件前景）和 `../zhiqu-shared/references/job-market.md`（全国就业形势，每次先更新数字）。用条件句写前景，兴趣优先，前景只用来排除风险。
4. **确定方向后再收集数据**（`references/data-sources.md`）。只收集和这位学生的候选相关的数据：
   - 为当前判断确有必要的可比年份复试线和拟录取分数统计；
   - 招生目录与推免人数；
   - 合作办学项目的教育部名单条目与招生简章；
   - 项目官网的申请要求、截止日期和学费。

   只用官方来源。取原文遵循本机可用的官方取文工作流；HTTP优先，必要时正常浏览器读取。未取得原件就标“未取到”与影响，不拿摘要或经验帖补结论；不收集名单个人信息。
5. **按条件比较**：每个候选写清资格、支持/反对证据、本人差距、费用与可接受性、失败去向和再判断节点。考研按 `references/kaoyan.md` 做分科与名额情景；申请按 `references/abroad.md` 看门槛、匹配与组合。**不写个人上岸概率，也不从群体录取比例或录取者分布推个人百分比。** 未核清的核心条件写“待确认”，不为给出排序而补假数字。
6. **出报告**：按 `references/report-guide.md` 的 12 节固定目录写，渲染成 PDF。报告前几节只用大白话。时间线要精确到月，写明每个节点"要做什么、做不到会怎样"。

## 原则

共用的骨架、原则、防误伤规则和交付前自查见 `../zhiqu-shared/references/shared-rules.md`，**每份报告交付前都按其中的"交付前自查"逐条核对**。读研版另有两条：
- **几个申请的结果高度相关**：同一个人的成绩、背景相同，不能把各个申请当成独立事件，把录取概率相乘。
- **给路线图，不陪跑**：报告写清各路径大致怎么准备、要投入多少、里程碑和切换条件；不做逐日备考计划、讲题、复试辅导、代写文书。
