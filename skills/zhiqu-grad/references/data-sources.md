# 数据来源与收集清单

读研的数据分散在各校网站，没有高考那样的全省统一表。所以**只在确定学生和候选方向后才收集**，每条都记下来源网址、年份和查询日期。遇到登录、验证码或人机验证不绕过，请学生本人查询后提供截图或文件。

## 全国通用（每年查一次）

| 数据 | 来源 |
|---|---|
| 当年《全国硕士研究生招生工作管理规定》 | 教育部 moe.gov.cn（每年 9 月前后）；研招网转载 |
| 报名、初试时间与公告 | 研招网 yz.chsi.com.cn |
| 国家线（一区、二区，按学科门类） | 教育部、研招网（次年 3 月前后） |
| 调剂系统 | yz.chsi.com.cn/yztj |
| 报考人数（全国） | 见 `../zhiqu/references/job-market.md` 的数据快照（唯一存放处） |

## 按候选收集（考研）

对每个候选院校和专业，收集近三年的：
1. 招生目录：专业代码、研究方向、考试科目、拟招人数（含或不含推免）、学习方式；
2. 推免接收人数：推免录取公示；
3. 复试线：学院或研究生院公布；
4. **复试名单与拟录取名单**：每个录取者的初试分、复试分、总成绩。这是最有价值的数据，算出最低分、中位数和一志愿录取人数；
5. 复试录取办法：权重、差额比例、复试内容；
6. 专业课参考书与真题来源；
7. 当年是否改考科目、改招生人数。

整理成 CSV：`school,program,year,plan,tuimian,retest_line,admit_n,admit_min,admit_median,first_choice_n,subjects,source`，并在备注里写明数据是否完整。

## 按候选收集（境外与合作办学）

- 项目官网：入学要求（均分、语言、先修课、院校名单）、截止日期与轮次、学制、学费、课程设置；
- 学校官方的生活费估算；
- 教育部留学服务中心的学历认证要求；
- 目标城市人社部门的留学生落户政策（按当年文件）；
- 合作办学项目：教育部中外合作办学监管工作信息平台 crs.jsj.edu.cn 的名单条目、招生简章（是否纳入统招、证书、学费）。

## 可信度等级

在报告的数据来源一节，为每条数据标等级：
- 官方原表；
- 官方页面转述；
- 学生本人提供，未核实；
- 经验帖线索，未核实，不作依据。
