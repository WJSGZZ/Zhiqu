# 数据来源与收集清单

读研的数据分散在各校网站，没有高考那样的全省统一表。所以**只在确定学生和候选方向后才收集**，每条都记下来源网址、年份和查询日期。取文按可用的官方取文流程，先HTTP、必要时正常浏览器读取；未取得原文就记录具体缺口和对判断的影响，不拿摘要作证据。

## 全国通用（每年查一次）

| 数据 | 来源 |
|---|---|
| 当年《全国硕士研究生招生工作管理规定》 | 教育部 moe.gov.cn（每年 9 月前后）；研招网转载 |
| 报名、初试时间与公告 | 研招网 yz.chsi.com.cn |
| 国家线（一区、二区，按学科门类） | 教育部、研招网（次年 3 月前后） |
| 调剂系统 | yz.chsi.com.cn/yztj |
| 报考人数（全国） | 见 `../zhiqu-shared/references/job-market.md` 的数据快照（唯一存放处） |

## 按候选收集（考研）

只对实际候选院校与专业收集近两三年可比信息；若有改考或口径差异先解释，不强凑三年：
1. 招生目录：专业代码、研究方向、考试科目、拟招人数（含或不含推免）、学习方式；
2. 推免接收人数：推免录取公示；
3. 复试线：学院或研究生院公布；
4. **复试与拟录取信息**：只在本机按普通一志愿/调剂/各专项等渠道汇总必要的初试分统计、人数和完整性，不保存姓名、考生编号或其他个人行级资料；
5. 复试录取办法：权重、差额比例、复试内容；
6. 专业课参考书与真题来源；
7. 当年是否改考科目、改招生人数；
8. 复试笔试科目、单项不及格淘汰规则；学费、学制、奖助；
9. 拟招人数是按专业还是按学院合计；是否要求学士学位；
10. 跨考前置资格、课程及加试；学院官网常是专业信息首发处。录取者本科来源不能单独证明筛选歧视、机会公平或个人概率，不为这一推断收集院校层次名单。

确需跨候选比较时，可整理匿名汇总 CSV（方法完善阶段不建表）：`school,program,year,plan,tuimian,retest_line,admit_n,admit_min,admit_median,first_choice_n,subjects,source`，并在备注里写明数据是否完整。

## 按候选收集（境外与合作办学）

- 项目官网：入学要求（均分、语言、先修课、院校名单）、截止日期与轮次、学制、学费、课程设置；
- 学校官方的生活费估算；
- 教育部留学服务中心的学历认证要求；
- 目标城市人社部门的留学生落户政策（按当年文件）；
- 合作办学项目：教育部中外合作办学监管工作信息平台 crs.jsj.edu.cn 的名单条目、招生简章（是否纳入统招、证书、学费）。

## 可信度等级

在报告的数据来源一节，为每条数据标等级：
- 官方原表；
- 官方页面转述；
- 学生本人提供，未核实；
- 经验帖线索，未核实，不作依据。

## 按问题追加最少信息

- 要不要读研/二战：少量目标岗位的雇主官网要求、真实工作机会与本人资金期限；判断见[routes.md](routes.md)。
- 调剂：当届学校授权公告和正式系统的接收范围、实时余额、窗口及确认期限；往年公告仅作入口线索。
- 在职/学位形式：当年招生章程、培养/课程表、收费、定向合同及退费退出；制度原文只在[routes.md](routes.md)。
- 博士路径：目标年度章程、直博/硕博连读选拔规则、导师和培养/资助/退出条款；不批量收集导师或拟录取名单。
- 一年制及合作办学用途：项目的真实学习与获证时间、留服要求、目标年度具体岗位原文/正式答复；见[abroad.md](abroad.md)。

每条事实同时标“已核实 / 有证据待确认 / 未取到”，记录原文、URL、发布/适用年份、取文日及方式、复核期限；未署发布日期不从URL推定。表内数字需有单位、分母、计划类型和完整性。其他文件只链接该事实的唯一存放处；缺口不写成不存在。
