# 出国与境外读研（港、新、英、澳、欧、美、日等）

这类信息变化快、项目之间差别大。**所有录取要求、截止日期、学费都以项目官网的当年页面为准**，并记录网址、项目名、入学年份和查询日期。中介说法、经验帖和排名网站只当线索。

## 一、先算三笔账

1. **钱**：
   - 学费 + 生活费 + 申请费、语言考试、签证、机票；
   - 学费看项目官网，按币种、每年还是全程、本地还是非本地学生分开记；
   - 生活费看学校官网给出的估算；
   - **奖学金不计入基准预算**。
2. **时间**：
   - 香港、英国、新加坡的授课型硕士多为 1—2 年，美国多为 1.5—2 年，欧洲大陆和日本各有不同；
   - 一年制省钱省时间，但实习和求职窗口很短；
   - 还要考虑国内秋招（多在 8—11 月）能不能参加。
3. **回国认可**：
   - 准备回国工作的，先查三件事：
     - 教育部留学服务中心的国（境）外学历学位认证要求，比如学习方式、在境外实际就读时间；
     - 目标城市对留学生的落户政策，各地规定不同，会调整，要查当地人社部门当年文件；
     - 目标单位的认可程度，比如考公、选调、国企对境外学历和一年制硕士的态度。
   - 这三项都要查官方原文。

## 二、按地区的一般特点（选校前的方向判断，不作为录取依据）

| 地区 | 一般特点 | 要核实的 |
|---|---|---|
| 香港 | 离家近、授课型一年制多、中文环境；申请集中在 9 月到次年春季，分轮次 | 各项目截止日期与轮次；学费；是否要求相关背景；认证与落户 |
| 新加坡 | 学费和生活费较高、项目少、竞争强 | 项目要求与学制 |
| 英国 | 授课型多为一年；部分大学按中国本科院校名单设不同的均分要求 | 该校官网的中国院校名单与分档；学费；认证 |
| 澳大利亚 | 多为 1.5—2 年，入学要求相对明确；可能有工作签证 | 学制、学费、签证政策当年版本 |
| 欧洲大陆 | 部分国家公立大学学费低，但有语言与学制差异 | 授课语言、学制、学费政策 |
| 美国 | 1.5—2 年、费用最高；实习机会多，但签证与就业政策不确定 | 项目要求、费用、签证政策当年版本 |
| 日本 | 有研究生（预科）等路径，常需要日语或导师联系 | 项目与导师要求 |

## 三、选校：冲 / 稳 / 保

- **先过门槛再谈竞争力**：均分（按学校规定的计算方法，**不要自己线性换算绩点**）、语言成绩、先修课、本科院校名单。门槛不确定的项目，标"待确认"，不要给概率。
- **同一个学生的申请结果高度相关**：同样的成绩、同样的院校背景。几个项目不能当成独立事件，"投十个总能中一个"的算法不成立。
- **保底必须是真的愿意去、付得起的项目**。
- **概率**：没有可比的录取数据时，写定性判断，列出支持和反对的证据。不编"录取率 70%"这类数字。

## 四、时间线（以次年秋季入学为准）

| 时间 | 事项 |
|---|---|
| 大三上—大三下 | 保持均分；准备雅思或托福（常需考 2—3 次）；科研、实习、项目 |
| 大三暑假 | 语言出分；确定地区与项目名单；准备简历、个人陈述、推荐人 |
| 大四 9—12 月 | 第一轮申请（香港、英国、新加坡等多在这一阶段开放，早申请通常更有利，按各校规则） |
| 大四 1—4 月 | 后续轮次；面试；收到录取后比较；按时交留位费（**付款前让学生本人确认**） |
| 大四 5—8 月 | 签证、住宿、毕业证与学位证、成绩单认证 |

## 五、材料（只给结构建议）

- **个人陈述**：回答项目的实际问题，结合真实经历说明"为什么是这个项目"，不要写成通用模板。
- **简历**：写做过什么、用了什么方法、结果如何。不编经历，不夸大角色。
- **推荐信**：由推荐人本人写或确认。不代签，不代写后冒充推荐人。

## 六、与国内路径同时准备

- 同时考研：申请高峰在 9—12 月，正是考研冲刺期，会冲突。只有在语言已出分、材料基本完成时才建议同时准备。
- 已有推免机会：推免录取后不能再参加当年统考。境外录取和国内推免的取舍，要在推免系统确认前想清楚。
