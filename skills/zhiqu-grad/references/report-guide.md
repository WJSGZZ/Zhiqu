# 报告结构（固定 12 节）

每份报告都用同一目录，方便对照。缺内容的节写明原因（如"尚未取得拟录取名单"），不要删节。封面标语与高考版统一：「知其所往，方行其衢。」

| 节 | 内容 | 要点 |
|---|---|---|
| 01 摘要 | 一页纸：当前阶段；主路径、保险路径、首选候选；下一步最重要的三件事及截止日期；下一个检查点 | 学生和家长只读这一页也能行动 |
| 02 你的画像 | 分四类列出：事实、偏好、约束、有待核实的自我判断；「性格与传统视角」一节有作答时，加"性格"与"传统视角：八字"两个小节（后者按 `../zhiqu-shared/references/bazi-lens.md`，含三方对照） | 引用问卷原话，不改写成标签；八字不进入打分和排序 |
| 03 为什么读研、卡在哪 | 动机分析；若动机主要是"暂缓就业"或"家里要求"，给出"先工作"方案的比较；若填了「方向与状态」一节，写迷茫的类别和两三个一两周内能做的小步骤；当前就业形势对这位学生的含义 | 见 `routes.md` 第一节、`../zhiqu-shared/references/direction-and-state.md`、`../zhiqu-shared/references/job-market.md` |
| 04 路径判断 | 各条路的资格、时间、花费、可行性、本人接受度对比表，以及结论 | 没资格或来不及的路径写明原因 |
| 05 方向与前景 | 专业方向；前景写成条件句；不喜欢、要排除的方向 | 兴趣优先，前景只用于排除风险 |
| 06 候选清单 | 考研有同科目完整模考证据后按[择校方法](kaoyan.md)作个人条件分档；无模考只列调查对象，明示取得模考后的定档检查点；申请列门槛与匹配证据。每项写支持与反对证据、费用、本人接受度、失败去向 | 不写个人上岸概率；缺口与待确认项单列 |
| 07 时间线与检查点 | 按月列到入学：每个节点做什么、截止日期、做不到的后果；标出**检查点**：到时请学生更新问卷，AI 重算 | 标出和其他路径冲突的时间；报告是会更新的规划，不是一次性结论 |
| 08 行动路线 | 每个候选要达到的门槛（分数区间、语言、均分、先修课）和本人目前的差距；大致怎么补、先后顺序、要投入多少、最耗时的环节；**里程碑与切换条件**（如"报名前核心科目的可比表现仍未改善、已不足以补齐差距，就调整候选或转向工作备选"） | 给路线图，不做逐日计划和辅导 |
| 09 风险与备选 | 失败情景：调剂、二战、就业、补录；每种情景的触发条件和应对 | 提前写好，免得临时慌乱 |
| 10 追问清单 | 需要学生本人去问或查的问题（本校教务处、学长学姐、目标导师、项目招生办） | AI 只准备问题 |
| 11 方法与假设 | 成绩和名额如何核口径、分档条件、偏好如何表达、哪些条件变化会改结论 | 术语集中在这里 |
| 12 核对与来源 | 写给要核对的人或 AI：声明（不保证录取，一切以官方为准）、逐项核对材料（生成时自动加入）、每条数据的来源、年份、查询日期、可信度等级 | 见 `data-sources.md` |

备考、申请与就业备选的路线结构见[共用规则](../../zhiqu-shared/references/shared-rules.md)。

三版共用的封面、图表、来源尾注与统一术语见[统一呈现与术语](../../zhiqu/references/report-guide.md#统一呈现与术语)，组件写法见[报告渲染器说明](../../zhiqu/scripts/render_report.py)。本版保留12节角色，默认题名沿用上表，个人化题名不能省略角色内容；图表缺原始依据时标未取到，不用个人概率补空。

读研各步留下的文件见[阶段表](case-workflow.md)；本版组件的数量和输入位置统一以[内容合同](report-contract.json)为准。[工作流总纲](../../zhiqu-shared/references/report-workflow.md)说明证据、操控者核查及评分。
