# 报告结构（固定 12 节）

每份报告都用同一目录，方便对照。缺内容的节写明原因（如"尚未取得拟录取名单"），不要删节。封面标语与高考版统一：「知其所往，方行其衢。」

| 节 | 内容 | 要点 |
|---|---|---|
| 01 摘要 | 一页纸：当前阶段；主路径、保险路径、首选候选；下一步最重要的三件事及截止日期；下一个检查点 | 学生和家长只读这一页也能行动 |
| 02 你的画像 | 分四类列出：事实、偏好、约束、有待核实的自我判断 | 引用问卷原话，不改写成标签 |
| 03 为什么读研、卡在哪 | 动机分析；若动机主要是"暂缓就业"或"家里要求"，给出"先工作"方案的比较；若填了「方向与状态」一节，写迷茫的类别和两三个一两周内能做的小步骤；当前就业形势对这位学生的含义 | 见 `routes.md` 第一节、`direction-and-state.md`、`../zhiqu/references/job-market.md` |
| 04 路径判断 | 各条路的资格、时间、花费、概率、满意度对比表，以及结论 | 没资格或来不及的路径写明原因 |
| 05 方向与前景 | 专业方向；前景写成条件句；不喜欢、要排除的方向 | 兴趣优先，前景只用于排除风险 |
| 06 候选清单 | 考研：各候选的期望满意度计算；境外与合作办学申请：冲 / 稳 / 保分层清单。每项写概率区间及依据、满意度、失败去向 | 无数据时写定性判断，不编百分比 |
| 07 时间线与检查点 | 按月列到入学：每个节点做什么、截止日期、做不到的后果；标出**检查点**：到时请学生更新问卷，AI 重算 | 标出和其他路径冲突的时间；报告是会更新的规划，不是一次性结论 |
| 08 门槛与差距 | 每个候选要达到的门槛（分数区间、语言、均分、先修课）和本人目前的差距；各项目截止日期 | 只说要达到什么，不做备考或文书辅导 |
| 09 风险与备选 | 失败情景：调剂、二战、就业、补录；每种情景的触发条件和应对 | 提前写好，免得临时慌乱 |
| 10 追问清单 | 需要学生本人去问或查的问题（本校教务处、学长学姐、目标导师、项目招生办） | AI 只准备问题 |
| 11 方法与假设 | 概率怎么估、满意度怎么打分、哪些假设不成立时结论会变 | 术语集中在这里 |
| 12 数据来源与声明 | 每条数据的来源、年份、查询日期、可信度等级；声明不保证录取，一切以官方为准 | 见 `data-sources.md` |
