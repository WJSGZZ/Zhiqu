# 院校调研：考研前景与实习就业

分数和位次只回答"能不能上"，这一份回答"上了之后，这所学校能不能把考生送到他想去的地方"。它的结论写进效用打分里的"学校""前景""城市"三项，并注明证据等级。

调研顺序按成本从低到高：先查**官方文件**（免费、可核对，AI 可以代查），再由考生亲自问**学长学姐**（成本高、主观，但能补上文件里没有的"软信息"），最后才考虑**付费咨询**。

## 考研 / 保研

**先查官方文件：**

| 要看什么 | 去哪里找 |
|---|---|
| 有没有推免资格、每年推免多少人 | 学校研究生院或教务处每年公示的推免名单；推免人数 ÷ 该届本科毕业生数，就是推免率 |
| 升学率、升到哪里（本校、更好的学校、出国） | 学校每年发布的《毕业生就业质量年度报告》，很多学校会按学院甚至专业列出升学率和去向 |
| 专业基础打得牢不牢 | 该专业的培养方案：核心课程、数学课是"高等数学"还是"数学分析"、前两年的课程难度 |
| 本校该学科的研究生招生 | 研究生院的招生专业目录：本校有没有这个方向的硕士点、博士点，对想留本校读研的考生很重要 |

注意：学院之间的升学率可能差很多，要看目标专业所在的学院，不要只看全校平均。报告是学校自己发布的，口径各校不一，比较时先弄清"升学率"算不算出国、算不算二战。

**再问学长学姐。** 官方文件回答不了的，比如考研氛围、自习室够不够、保研名额是不是被某些专业占满、老师愿不愿意带本科生做项目，只能问在读或刚毕业的人。

## 实习 / 就业

实习好不好找，是几个因素叠加的结果，不能只看城市大小：

1. **课有多满**：看培养方案每学期的学分分布、有没有集中实践学期或小学期、实习是否计学分。课表空不空、能不能请假去实习，文件上看不出来，要问学长学姐或辅导员。
2. **附近有没有这类岗位**：计算机、金融类实习集中在一线和新一线城市；偏远地区可能根本没有对口岗位。计算机等可以远程实习的专业受地域限制小一些，医学、工科现场岗位受地域限制大。
3. **竞争有多激烈**：同一城市同类院校越多，同一批岗位的竞争者越多。比如上海 985、211 很多，名企实习很难抢。但要看两面：大城市的岗位总量也大得多，中小公司的实习机会可能反而比小城市多。竞争主要压在头部岗位上，这里要做判断，不能套公式。
4. **专业和当地需求是否对口，学校有没有合作渠道**：这一条常常比城市更重要。
   - 医学类的实习（见习、实习、规培）主要依托附属医院和教学医院。一个地区如果只有一所医科大学，本地医院大多和它合作，实习反而好安排。
   - 师范类依托当地中小学实习基地。
   - 行业特色校（电力、铁路、石油、邮电等）往往有行业内的定向合作。
   - 要查：附属医院的数量和等级、学院官网公布的实习基地和校企合作、就业质量报告里的主要用人单位。
5. **毕业生去了哪里**：就业质量报告里的就业地域分布（留在本省的比例）、行业流向、主要雇主，是"这所学校能把人送到哪里"最直接的证据。

## 问学长学姐（含付费咨询）

**这一步由考生本人（或家长）亲自去问。** AI 不代为联系、不代为付款，只做两件事：事先准备好问题清单（写进报告第 06 节），事后帮考生整理回答、判断证据等级。

问人的价值在"软信息"，风险在于个例和立场偏差。请考生按下面的规矩问：

- **只要他们确定的事**：请对方把每条回答标成三类："亲历或确认过""听说的""不知道"。不知道就说不知道，不要猜。这条要在提问开头就讲清楚。
- **问具体、可核对的问题**，不问"好不好"：
  > 你所在的年级、专业是？以下请每条注明"确认 / 听说 / 不知道"：
  > 1. 本专业上一届大概多少人保研、多少人考研上岸？去了哪些学校？
  > 2. 大二、大三每周大概多少节课？有没有整段没课的学期？能不能请假去实习？
  > 3. 本专业同学实习一般去哪里找、去哪些单位？学校或学院有没有合作单位？
  > 4. 有没有你入学前不知道、入学后才发现的问题？
- **问两个以上的人**，最好不同年级。对关键问题，单一来源只当线索。
- **注意偏差**：愿意回答的人往往是过得好或过得特别差的；卖资料的人有夸大资料价值的动机。情况每年都会变，要问清楚是哪一年的情况。
- **核对身份靠细节**：问一两个能在培养方案或学校官网上查到的细节（某门必修课的名字、所在校区），对得上再继续。不要求对方出示学生证等个人证件。
- **付费咨询**（例如在二手平台上找学长学姐买资料或咨询）：
  - 用平台交易，不先转大额款；
  - 付的是对方的时间和信息，不为任何"保证录取""内部名额"之类的说法付钱；
  - 不向对方透露考生的身份证号、准考证号、账号密码等信息。

## 怎样用进效用

- 把查到的信息落到"学校""前景""城市"三项的打分上，并在打分表里写出依据和证据等级：官方文件、多人一致、单人说法、推测。
- 单人说法可以作为考虑因素，但不能单独把一个志愿从候选池里删掉或加进来；要删、要加，至少要有官方文件或多人一致的证据。
- 这部分调研成本高，只对**最终候选里排名靠前、而且考生在意这件事**的学校做，不要对全部候选逐个调研。
