# 本机交互重算报告

`serve_report.py` 显式启动一个只绑定 `127.0.0.1` 的本机服务。页面可勾选愿意就读的候选、调整已有模型参数，再按按钮实际调用 `optimize.py` 重算，并用 `report.py` 生成和核验当前数值报告。它不是静态页面自行估算，也没有新增概率模型。

## 启动与结束

在技能目录执行完全虚构的演示：

```bash
python3 scripts/serve_report.py examples/candidates_demo.csv \
  --report examples/report_demo.json --rank 22000 --slots 6 --u-fall -60
```

打开终端显示的地址，默认是 `http://127.0.0.1:8765/`。端口占用时可加 `--port 8766`；`--port 0` 会选一个空闲端口。脚本不自动打开浏览器，不安装常驻服务。终端按 Ctrl+C 关闭；如正在计算，会等当前计算完成或达到超时再释放资源。

已有优化结果时，可继承完整固定参数：

```bash
python3 scripts/serve_report.py examples/case_b_zhejiang_2027/candidates.csv \
  --report examples/case_b_zhejiang_2027/report.json \
  --result examples/case_b_zhejiang_2027/result.json
```

`--rank`、`--slots`、`--u-fall` 可覆盖继承的启动值。不提供 `--result` 时，这三项必须显式给出，其余参数用优化脚本的既有默认值。默认最多载入 1000 个候选、每次优化最多 90 秒；可用 `--max-candidates`（上限 2000）和 `--timeout`（上限 300 秒）在启动时调整。模拟次数从原结果继承，允许 100–20000 次，页面不调整模拟次数和随机种子。

候选须已核实资格、效用与有效历史位次。含 `majors` 时必须显式写 `majors_complete=0` 或 `1`；目录只取得部分时用 `0`，不能为了启动服务直接填 `1`。原案例 C 尚未显式标注完整性时，服务会拒绝载入，需先如实补齐字段。

## 在页面里做什么

1. 按名称筛选显示，勾选/取消候选。搜索仅影响显示，不会自动取消隐藏的候选；“全选全部候选”和“取消全部”作用于整个已载入池。
2. 调整位次、可填志愿数、滑档效用、录取线共同波动程度（`rho`）、波动倍数（现有 `sigma-scale`）、滑档概率上限。上限留空表示不设置；应填概率小数，如 `0.01` 表示 1%。手填 `sigma` 的条目不受 `sigma-scale` 影响，与命令行规则一致。
3. 按“按当前选择重算”。后台串行运行现有脚本，计算期间锁定相关输入；不会每拖动一次参数就重复启动模拟。
4. 查看报告，或下载本次 HTML 与结果 JSON。HTML 可再用浏览器打印为 PDF，并勾选背景图形；作为正式交付件时仍须逐页检查版式。

更改参数或候选后，页面会提示下面仍是上次结果，并隐藏旧结果下载入口；必须再次按重算更新。重算失败或超时不会产生新结果。固定的漂移、目标年、历史人数折算、波动规则、调剂默认、压力倍数等从启动参数保留；需要改这些时重新启动服务，不在浏览器请求里传入额外命令或文件路径。

## 当前数值报告与原报告的关系

重算报告保留原报告的身份信息与数据来源，更新当前位次、志愿数、日期和压力倍数。位次调整后没有自动换算分数，封面明说“本次未换算分数”。摘要指标、志愿表、专业落点、填报单和方法参数均来自这次实际优化输出，并自动核验。

原报告的摘要正文、排序理由、专业分析、院校调研、敏感性表与追问不会因为新数值自动变成有效判断，重算报告不自动沿用这些文字。固定 12 节仍保留，并说明缺项。本机工具产生的是数值重算报告，完整志愿决策报告仍需主 Agent 结合事实与偏好重新写作、审查。

下载结果记录 `interactive_input`：原候选文件名、从 0 开始的已选行索引及解析表的 SHA-256。结果的路径字段使用临时输出的通用名称，不是可以调用的文件入口。重现时必须使用同一份候选内容、同一行顺序及记录的全套参数；筛选后的有限模拟结果不承诺与另一种候选次序完全相同。

## 运行边界

- 输入文件在启动时固定并读入内存；浏览器不能改文件路径、历史位次、效用、资格或组内参数。
- 仅接受固定本机 Host、同源请求与页面会话令牌；不提供跨域访问或任意本地文件读取，不能用于公网部署。
- 请求只允许候选行索引与有限范围的数字，拒绝重复/越界索引、非有限数字和额外参数。没有 shell 拼接。
- 每次计算使用随后删除的临时 CSV/JSON，不改原候选、报告或已有结果；只有点击下载才保存新成品到浏览器下载目录。
- 候选姓名/名称按文本转义；报告预览位于禁止脚本执行的 iframe。公开仓库演示没有真实个人材料。
- 不保证满足上限就能找到可行组合；最终以优化输出的实际滑档概率为准。未知资格不能通过降低效用或交互筛选变成可填项。
