# 从画像到方向与效用

## 画像字段

问卷输出按十节组织，下表只列对分析最要紧的字段及用途。

| 节 | 关键字段 | 用途 |
|---|---|---|
| 一 分数坐标 | 省份、投档分、全省位次、科类/选科、分数档位 | 决定可报范围；**位次是核心输入**。只有分数时用本省当年一分一段表换算 |
| 二 根本目标 | 毕业后第一意向及追问、收获、收入期望、价值、十年后 | 决定"学校"和"前景"两个属性怎么打分（见下文目标映射） |
| 三 专业 | 明确度、兴趣探索、感兴趣专业、不想读、冷热 vs 兴趣、大类招生、转专业、培养路子、短板、校名 vs 专业 | 方向分析主材料；"校名 vs 专业"与第九节排序交叉验证 |
| 四 院校 | 层次最低期望、院校类型、梦校、不去的学校、行业特色校态度、公办民办 | 硬过滤 + 学校属性打分 |
| 五 城市 | 是否出省、城市层级、节奏、离家远近、气候饮食、想去/不想去、定居 | 硬过滤 + 城市属性打分 |
| 六 禀性 | 轻松/犯怵科目、人或物、标准答案或开放、性格、能力、沉浸的事、自律、决策方式、深或广、工作状态 | 方向分析的能力与倾向证据 |
| 七 现实约束 | 身体条件、外语语种、单科短板、学费承受、生活费、独生/照顾家庭、竞赛特长、特殊路径、提前批 | **硬约束**与特殊批次 |
| 八 风险心态 | 冲稳保风格、平行志愿认知、复读倾向、服从调剂 | 风险参数与 `obey` |
| 九 优先级排序 | 学校层次 / 专业 / 城市 / 前景 / 稳妥 的排序 | **效用权重的来源** |
| 十 心里话 | 最纠结的事、家里期望、补充 | 找出真正要回答的问题；家庭分歧 |

"（未填）"表示考生留空，按未知处理，不要自行补全。

## 方向分析

目的不是给考生贴标签，而是找出"感兴趣 + 做得来 + 通向想要的生活 + 现实允许"的交集。

**证据分级**：具体行为（课余最容易沉进去的事、学得轻松的科目、获奖）> 情境选择（遇到问题偏好标准答案还是开放探索）> 自我标签（"我偏内向"）。自我标签只作辅助。

**四条线交叉**：

1. 兴趣：第三节的专业勾选与"最戳的事"，第六节沉浸的事
2. 能力：轻松/犯怵科目、擅长能力、短板能力、单科成绩
3. 目标与价值：第二节的去向、收入期望、工作状态
4. 约束：选科、身体、学费、城市

**参考框架**：Holland 职业兴趣类型（RIASEC；Holland, *Making Vocational Choices*, 1997）可作为组织证据的镜头。问卷"最戳的事"大致对应：拆解搭建实物 → R（实用型）；数字/逻辑、钻研未知 → I（研究型）；艺术审美、写作表达 → A（艺术型）；帮助影响他人 → S（社会型）；组织带人、商业 → E（企业型）；和数字/钱、规则打交道也带 C（常规型）成分。**问卷不是标准化的 RIASEC 量表**，只能说"倾向"，不能报出类型代码当测评结果。

**每个方向必须写**：对应的专业类（按教育部本科专业目录的专业类名称）；支持证据（引用画像原句）；反证或张力（如"想学计算机，但数学犯怵"）；怎么验证（读两三所目标院校该专业的培养方案，看前两年核心课是否能接受；看一门公开课的第一周）。

**常见名实不符**，提醒考生：信息与计算科学 ≈ 数学；生物医学工程 ≈ 工科；电子商务可能偏管理或偏计算机，取决于学校；心理学多数学校要大量统计。

**目标映射到院校属性**（第二节意向 → 打"学校""前景"分时额外看什么；具体怎么查、怎么问学长学姐见 [school-research.md](school-research.md)）：

| 意向 | 额外看重 |
|---|---|
| 直接就业 | 课程负荷是否留出实习时间、所在城市的对口岗位、同城同类院校的竞争、学校的行业合作与实习基地（医学看附属医院）、就业质量报告里的去向 |
| 考研 | 专业基础扎实程度（看培养方案）、本学院升学率与去向（看就业质量报告）、本校学科实力与硕士点；推免资格是加分项 |
| 保研 | 是否有推免资格、推免比例、专业内排名竞争程度；可接受"排名稍低但推免多"（看追问） |
| 考公/选调 | 是否在目标省份定向选调名单、专业是否对口常见岗位（如法学、汉语言、财会、计算机） |
| 出国 | 本科院校的国际认可度、交换项目、语言环境；家庭预算决定中外合作能否进池 |
| 军警 | 转提前批，按该批次单独推理；先核体检、政审、年龄、视力 |
| 还没想好 | 转专业政策、大类招生、宽口径专业，给"留余地"加分 |

## 从画像到效用

每个候选志愿按四个结局属性打 0–10 分：**学校**（层次与在目标路径上的实力）、**专业**（与方向分析的契合度）、**城市**（偏好、距离、气候、资源）、**前景**（与第二节目标的吻合）。

**权重来自第九节排序。** 五项中"录取稳妥"不是结局的属性（没有哪个学校"本身更稳"），而是风险态度，单独处理。其余四项按它们在考生排序中的相对先后，用"排序重心权重"（Rank Order Centroid；Barron & Barrett, 1996, *Management Science*）换算：

| 相对名次 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| 权重 | 0.52 | 0.27 | 0.15 | 0.06 |

效用 = 10 × Σ 权重 × 属性分，范围 0–100。

然后做三件事：

1. **与其他题交叉核对**：若第九节把"专业"排第一，但第三节"校名 vs 专业"选了"愿意，更看重校名"，这是矛盾，先问考生，不要自行裁决。
2. **家长期望**：第十节家长意见与考生排序不同时，可以各算一版效用，把两张志愿表和各自的期望效用都给出来，让分歧变成看得见的取舍。
3. **"宁可复读也不去"的学校不进池子**，而不是给它一个很低的效用。

**调剂后的效用 `utility_adjusted`**：用该专业组内考生最不想读、但仍可能被调去的那个专业来打"专业"分，其他属性不变，偏保守。

## 风险态度：滑档效用

滑档（含退档）的真实后果是：进入征集志愿、掉到下一批次，或复读。它的效用 `--u-fall` 与志愿效用在同一刻度上，通常为负数。默认值（本技能的约定，需向考生说明并允许修改）：

| "录取稳妥"在第九节的名次 | `--u-fall` | `--max-fall` |
|---|---|---|
| 第 1–2 名 | −100 | 0.005 |
| 第 3 名 | −60 | 0.01 |
| 第 4–5 名 | −30 | 0.03 |

再按第八节调整：选"宁可复读，也不将就"的，滑档代价较小，`--u-fall` 可提高到 −10 左右并放宽上限；选"接受录取，不复读"或"求稳为主"的，保持或收紧。

**需要更精确时，用一道标准博弈题校准**（von Neumann–Morgenstern 期望效用的标准做法）：

> 两个选择：A. 确定被 B 校录取（它的效用为 b）；B. 有 p 的概率被你最想去的 A 校录取（效用 100），1−p 的概率滑档。p 至少多大，你才愿意选 B？

考生给出的临界值为 p*，则 u_fall = (b − 100·p*) / (1 − p*)。例如 b = 60、p* = 0.9，得 u_fall = −300：说明这位考生极其厌恶滑档，应在报告中说明这一点并严格控制滑档概率。
