# 志愿博弈：机制、模型与计算

## 1. 为什么可以把填志愿当成期望值问题

平行志愿的投档规则是"分数优先、遵循志愿、一次投档"：按位次从高到低，逐个考生检索其志愿表，投到第一个仍有余额且考生过线的志愿。对单个考生来说，结果等价于：**落到表中第一个"你的位次 ≤ 它今年的最低录取位次"的志愿。**

由此有三个推论，它们决定了整个算法：

1. **表内顺序按真实喜好排。** 你排在前面的志愿不会因为"浪费了第一志愿"而降低后面志愿的录取机会（这与老式"顺序志愿"不同）。在志愿个数有限的平行志愿下，给定入选集合，按真实喜好排序是弱占优的（Haeringer & Klijn, 2009, *Journal of Economic Theory*；中国高考机制的系统分析见 Chen & Kesten, 2017, *Journal of Political Economy*）。
2. **真正要决定的是"选哪几个"。** 这是一个组合选择问题：从候选池里挑不超过 K 个，使 E[最终结局的效用] 最大。
3. **这个问题有已知的好算法。** 若各志愿录取与否相互独立，"边际改进贪心"（每步加入让期望效用增加最多的那个）是最优的（Chade & Smith, 2006, "Simultaneous Search", *Econometrica*）。现实中各校录取线会一起涨落，不独立，所以脚本用蒙特卡洛模拟相关性，贪心之后再做单点替换改进。

**不适用的情形**：提前批、部分专项/强基等"顺序志愿"或"第一志愿优先"的批次，第一志愿有额外价值，不能直接套用上面的结论和脚本；需要按该批次规则单独推理。

**其他招生类型**：给考生的讲解、广东浙江江苏的回测数据与建议规则见 [special-admissions.md](special-admissions.md)。其他省份的考生遇到这些类型，由 AI 当场查本省考试院和高校官网，按当年规则单独推理，并在报告里注明没有回测支持。

## 2. 模型

记考生今年位次为 r（出分后已知，数字越小越好）。志愿 j 今年的最低录取位次 C_j 未知：

- log C_j ~ Normal(μ_j, σ_j)
- μ_j：历年最低录取位次取对数后的加权平均，权重 (1, 0.15, 0.05, …)，即以去年为主；每年的数据先按全省漂移 `--drift` 补齐到今年，再乘人工校正系数 `adj`。权重和漂移都来自回测，见 [backtests.md](backtests.md)
- σ_j：历年位次对数的样本标准差，但不低于 `--sigma-floor`（默认 0.10，约 ±10%）；只有一年数据时取 `--sigma-single`（默认 0.25）；最后乘以按省校准的 `--sigma-scale`（见 [backtests.md](backtests.md#校准检验模型说的概率准不准)）
- 相关性：log C_j = μ_j + σ_j(√ρ·Z₀ + √(1−ρ)·Z_j)，Z₀ 是全体共享的"年份冲击"，`--rho` 默认 0.3
- 过线：r ≤ C_j

用位次而不用分数，是因为分数随试卷难度浮动；用对数，是因为位次的波动大致与位次本身成比例（第 1000 名附近波动几十名，第 50000 名附近波动几千名）。

**调剂与退档**（专业组、院校+专业模式）：过线后仍有 `p_adjust` 的概率进不了所填专业（专业组更精细的做法见下文"专业组内的专业分配"）。

- 服从调剂：得到 `utility_adjusted`（调剂去的专业的效用）
- 不服从：退档，结局等同滑档，**且不会再检索你后面的志愿**

**目标**：最大化 E[U]，其中滑档结局的效用为 `--u-fall`。可加 `--max-fall` 作为滑档概率硬上限。

**补位**：基准模型认为已无增益后，剩余位置在"波动 ×2"的压力情景下继续贪心补满（`--stress`），只接受不降低基准期望的补位。它对冲的是历史三年没出现过的大波动、章程或体检导致的意外退档。

## 3. CSV 列说明

UTF-8 编码，一行一个志愿单元（专业组、专业+院校或院校+专业，按本省模式）。

| 列 | 必填 | 含义 |
|---|---|---|
| `id` | 否 | 院校代码 + 专业组/专业代码（仅作标识，跨年匹配不要依赖组号） |
| `name` | 是 | 显示名，如"XX大学·计算机类（专业组 03）" |
| `utility` | 是 | 以原专业录取时的效用，0–100 |
| `rank_2025`, `rank_2024`, … | 至少一列 | 历年最低录取位次，同科类/同首选科目；列名以 `rank_` 开头，按年份自动识别先后 |
| `adj` | 否 | 今年相对历史的校正，默认 1。>1 表示预计变容易（录取位次数字变大）。见第 4 节 |
| `sigma` | 否 | 手动指定对数波动，覆盖自动估计 |
| `p_adjust` | 否 | 过线后进不了所填专业的概率，默认 0 |
| `utility_adjusted` | 否 | 被调剂后的效用 |
| `majors` | 否 | 专业组的组内专业，按考生专业志愿顺序：`专业:效用:去年组内最低位次;...`；填了就由模拟算落点，`p_adjust` 不再使用 |
| `rule` | 否 | 组内分专业规则：`score`（分数优先，默认）/ `gap`（专业级差）/ `first`（志愿优先） |
| `gap` | 否 | `rule=gap` 时每一级级差折算的对数位次，逗号分隔 |
| `obey` | 否 | 1 = 服从调剂，0 = 不服从；留空取命令行默认（服从，`--no-obey` 改为不服从） |
| `note` | 否 | 数据来源、判断依据 |


**专业组内的专业分配**（专业组模式省份必看）。投档进了专业组，不等于读到想读的专业。学校按招生章程里的规则在组内分专业，常见三种：

| 规则 | 做法 | `rule` |
|---|---|---|
| 分数优先 | 进档考生按分数从高到低排队，轮到谁就看他填的专业志愿里哪个还有名额 | `score`（默认） |
| 专业级差 | 非第一专业志愿要减去规定的分数（如 3、2、1 分）再排队 | `gap`，并在 `gap` 列按顺序给出每一级级差折算成的对数位次（用一分一段表：ln(减分后的位次 / 原位次)） |
| 志愿优先 | 先录第一专业志愿的考生，其他人只能分到剩下的名额 | `first`（粗略近似：每往后一个专业志愿，相当于位次难约 25%） |

填 `majors` 列（`专业:效用:去年组内该专业最低位次;...`，按考生的专业志愿顺序）后，模拟会先判断是否进组，再按规则判断落到哪个专业；都不够就调剂（服从）或退档（不服从）。组内各专业的去年最低位次来自高校招生网公布的"分省分专业录取分数"；查不到的专业可以只填前两项，模型会按组线处理（偏乐观，要在报告中注明）。组内专业线在组线基础上另有独立波动（取组波动的一半，不低于 0.08）。这时志愿的"效用"改为过线后的条件期望，`p_adjust` 不再使用。

## 4. 参数怎么定（这些是判断，报告里要写明）

**`adj`：今年相对历史的变化。** 只在有具体理由时偏离 1，并在 `note` 写出理由：

- 考生总数变化：同科类考生人数是去年的 g 倍，最低录取位次大致同比例变化，adj ≈ g（假设录取线的百分位不变）
- 招生计划明显增减：扩招偏向 adj > 1，缩招偏向 adj < 1；幅度凭判断，通常 0.9–1.1
- 专业组重组、新增选科要求、学校更名或合并：历史数据可比性下降，与其调 adj，不如把 `sigma` 调大
- 大小年：去年异常低（或高）不代表今年延续，不要顺着单年趋势外推
- 结构突变：相邻年份位次变化超过约 40% 时，脚本自动把 σ 放大到至少等于该跳变，并给出警告。常见原因是组内专业调整、新增定向或特殊招生条件、组号换了含义。这类组不能凭投档表判断，需查当年章程与招生计划

**`p_adjust`：被调剂概率。** 有该校分专业录取位次时，比较你的位次与目标专业的历年线来估；没有时的粗略经验（仅作起点）：
预计位次余量 ≥ 15% → 0.05；5–15% → 0.2；< 5% → 0.5。专业+院校模式下为 0。

**`--drift`：** 全省录取位次每年的对数漂移。先对本省跑 `backtest.py`，近几年的整体漂移稳定时取其平均（如浙江约 0.02），不稳定或没有回测时保持 0。

**`--rho`：** 默认 0.3。出分后位次已知，共同冲击主要来自全省填报热度的整体偏移。做敏感性时试 0.1 和 0.5。

**`--u-fall` 与 `--max-fall`：** 由考生的风险态度决定，默认值和校准方法见 [profile-analysis.md](profile-analysis.md#风险态度滑档效用)。

**冲/稳/保标签**：单独过线概率 < 40% 为冲，40–85% 为稳，≥ 85% 为保。这是本技能的约定，不是官方分类。

## 5. 读结果

- **单独过线概率**：只看这一个志愿，你过线的概率
- **最终落在此处**：考虑到前面的志愿已经把你录走后，你真正被这里录取的概率。一个 95% 能过线的保底，如果前面已经有 90% 把握，它的"最终落在此处"只有几个百分点，这是正常的
- **对照表**：优化结果 vs "只挑效用最高的 K 个" vs "只挑最稳的 K 个"。这是向家长解释"为什么不能只冲/只保"最直接的证据
- **未入选但效用较高**：人工复核用。若考生对其中某个特别执着，可以把它的效用调高后重算，看代价是多少

**预测分数线**：`rank.py predict --table 今年一分一段.csv` 把预测位次及其 80% 区间换算成今年的分数。分数线是位次的派生量，比较与决策仍以位次为准。

## 6. 数据从哪来

只用一手来源，记录网址与查询日期：

- **本省教育考试院官网**：当年填报办法（模式、批次、志愿个数、投档比例、同分排序）、一分一段表、历年各批次投档线/位次、招生计划。投档表通常只有"院校代码 + 专业组代码 + 计划数 + 最低分 + 最低排位"，**没有组内专业**；一分一段表有时是扫描 PDF
- **专业组组成**：当年本省招生专业目录，或各高校本科招生网公布的"分省分专业组招生计划"。这是判断"想读的专业在哪个组"的唯一可靠来源
- **阳光高考平台**（教育部主办，gaokao.chsi.com.cn）：各校招生章程、专业知识库
- **各校本科招生网**：当年招生章程（体检、单科、外语语种、男女比例、调剂规则）、分省分专业录取情况
- **学科与资格类**：教育部公布的"双一流"建设高校及学科名单；教育部学位与研究生教育发展中心的学科评估结果（以其官方公布为准，网传榜单不算）；推免资格高校以教育部/高校研究生院公布为准；定向选调院校名单以各省组织部门当年公告为准

第三方填报 App、自媒体整理表可以用来**发现**候选，但写入 CSV 的位次要回到一手来源核对；核对不了的在 `note` 标注"未核实"，并调大 `sigma`。

## 7. 模型的局限（报告中如实说明）

- 三年数据估波动，本身误差很大；σ 下限和压力情景只是缓冲，不能消除
- 一次回测（广东 2023 物理类，用 2022 单年数据预测 46 个院校专业组）中，实际对数误差的标准差为 0.249，与单年默认 σ = 0.25 吻合；中位误差 +0.10，即当年整体普遍放松约 10%，说明共同冲击（rho）确实存在。这只是一个省、一年的检验，不代表普遍校准
- 对数正态假设在极端年份（大幅扩招、新专业首年）可能失效
- 效用打分来自问卷和对话，考生本人的偏好会在填报季内变化；显著变化后应重打效用并重算
- 模型不知道章程里的隐藏限制；硬约束筛选必须人工做完再进脚本
