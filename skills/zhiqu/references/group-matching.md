# 专业组内容的跨年辅助对应

`group_match.py` 根据组内专业集合生成相似度候选，供人工核对目录。相似度不是历史可比性的证明：即使为 1，选科、校区、学费/办学路径或招生资格变化仍可改变录取线。建议文件不能直接传给 `pool.py --group-map`；只有经第二步核实的导出文件才能使用。

## 输入：每行一个组内专业

CSV 必需字段如下，组内多个专业用多行表示：

| 字段 | 含义 |
|---|---|
| `province` / `category` / `batch` | 投档省份、科类、批次，必须准确一致 |
| `school` | 学校名称；脚本不自动合并更名或别名 |
| `year` / `group` | 招生年份和组号，组号作为文本保留前导零 |
| `major` | 当年该组的一个专业名称，保留方向、实验班等限定 |
| `requirement` | 当年选科要求；未知留空，不用“无”冒充已核实 |
| `campus` | 当年校区；“主校区”等值必须有目录依据 |
| `pathway` | 普通、中外合作、专项等招生/办学路径；区分影响资格或学费的路径 |
| `complete` | `1` = 已核实列全该组当年专业；`0` = 目录只取得部分；必须显式填写 |
| `source` | 这份目录的实际官方来源 URL，缺失留空并保留待核实状态 |
| `code`（可选） | 当年投档表的学校代码；需要导出按代码匹配的历史表时必填 |

同组的选科、校区、路径、完整性和学校代码须一致；冲突或重复专业会报错，不能静默合并。同组可以有多个真实来源。此表是目录事实，不是投档位次表；位次仍由原投档数据提供。

## 第一步：只生成建议

在技能目录运行，输出文件必须尚不存在：

```bash
python3 scripts/group_match.py suggest groups.csv --from-year 2025 --to-year 2026 --out suggestions.csv
```

仅比较同省、同科类、同批次、同学校的前后年组，专业集合没有交集的组不输出。Jaccard = 两组共同专业数 ÷ 两组专业并集数；只去除空白，不自动改专业名、合并方向或忽略实验班限定。

输出列包括共同、移除、新增专业、前后年条件与来源、完整性、警示。一个旧组与多个新组有重叠时提示可能拆组；一个新组与多个旧组有重叠时提示可能合组。这只是“多组重叠”的候选提醒，不是实际拆合结论。目录不完整、条件未知/变化、专业内容变化与缺来源分别标记。

**全部建议默认 `confirmed=0`，`history_key` 与核验证据留空。脚本不会用高相似度或相同组号自动确认。**

## 第二步：人工核实，再另行导出

逐对查前后年完整招生目录与章程；同时核对计划对应、选科、校区、路径、资格和费用条件。确认后在建议 CSV 中填写：

- `confirmed=1`：人工确认本对具有可直接拼接的一对一关系。
- `verification_source`：实际使用的官方核验 URL，多个用 `;` 分隔。不要填写模型编出的地址。
- `verification_note`：核实了哪些内容、哪些章程限制，以及为何不存在拆组/合组。
- `history_key`：人工分配的稳定历史标识；同一链跨年使用同一个标识，不能在不同学校复用。

```bash
python3 scripts/group_match.py export reviewed.csv --school name --out verified-group-map.csv
```

导出字段兼容 `pool.py --group-map`：`year,name,group,history_key,source`。使用时必须同时给 pool `--school name`。按年度学校代码匹配时改为 `--school code`，输出 `code` 字段，且前后年 `code` 都要有值。

导出器拒绝未完整的目录、专业内容差异、选科/校区/路径未知或变化、缺来源、缺人工说明、重复对应、同年一对多/多对一及跨学校历史键。一次只能导出同省、同科类、同批次，禁止跨省拼接。多组重叠提醒本身不替人工作结论：只有目录与条件一致且最终确认表确实一对一时才可导出。真实拆组/合组应留空历史，不通过重写稳定键规避检查。

导出器只能检查结构与显式证据是否齐备，不能自动证明 URL 内容、来源官方性或人工判断正确。`verified-group-map.csv` 丢弃了省/科类/批次字段以兼容既有 pool 格式，所以必须只与已核实的那一份省/科类/批次投档表共同使用，不把它当跨省通用表。

自动测试完全使用合成学校、专业和 `example.edu` 占位地址，不证明任何真实学校的跨年对应。真实目录缺失时，输出“未核实”比猜对应更有用。
