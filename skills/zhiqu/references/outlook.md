# 就业前景、专业认可度与保研率

"前景"这一项的打分最容易出错：今天的热门，不一定是四年后（读研就是七年后）的热门。这一份讲三件事：前景怎么预测才诚实，学校的专业实力怎么看，保研率怎么读。

## 一、就业前景：写成有条件的判断

**预测的时间跨度比看上去长。** 考生现在选的专业，要到本科毕业（4 年后）或硕士毕业（6–7 年后）才面对就业市场。行业冷热在这个跨度上反转过不止一次：土木、建筑曾是高分热门，房地产下行后就业明显转冷；生物、化学、环境、材料（常说的"生化环材"）当年也被看好。所以不能把"现在很火"直接当成"毕业时好就业"。

**每条前景判断都写成"如果……那么……"：**

1. 写出结论依赖的关键前提（A）。例："若 AI 相关岗位的需求到 2031 年仍在扩张……"
2. 写出前提不成立时结论怎么变。例："……若扩张在 2028 年前放缓，应用层岗位的竞争会先加剧，普通院校毕业生受影响最大。"
3. 写出考生可以观察的信号，以及什么时候还能调整：大一大二的转专业窗口、考研时换方向的机会。
4. 用 `optimize.py` 做一次情景检验：把"前景"分按悲观情景改一版再运行，看志愿表的前段变不变。变化不大，说明结论对这个前提不敏感；变化大，就把两张表都给考生，并在报告里写明分歧点。

**不确定性越大，兴趣和可迁移能力越重要。** 兴趣决定考生能不能坚持学好，而学得好的人在任何行业周期里都更有竞争力。数学、编程、写作、外语这类可迁移的能力，在行业反转时损失最小。前景不确定时，适当调低"前景"的权重，或者给可迁移能力强、转向容易的专业加分，并在报告中说明这样做的理由。

**同一个专业，不同学校的出路不同。** 热门方向的头部岗位（如 AI 研究、算法岗）主要招顶尖高校的硕士、博士，"985 能做 AI"不等于普通本科或专科也能进入同样的岗位。对普通本科和专科，要看这所学校、这个专业的毕业生实际去了哪里：应用开发、测试、运维、实施、本地制造业信息化等。依据是学校的就业质量报告，不是全国新闻标题。

**证据来源（按可靠程度排）：**

| 来源 | 能说明什么 | 注意 |
|---|---|---|
| 目标学校的《毕业生就业质量年度报告》 | 该校该专业的就业率、升学率、去向地区、行业和主要雇主 | 学校自己发布，口径各异 |
| 教育部每年的本科专业备案和审批结果 | 哪些专业在大量新增、哪些在被撤销，反映学校对需求的判断 | 新增多也意味着几年后毕业生多 |
| 国家统计局分行业就业人数与平均工资 | 行业规模与收入的长期趋势 | 行业口径，不等于专业口径 |
| 人社部定期发布的"最缺工"职业排行 | 当前岗位缺口 | 偏技能型岗位，反映的是现在 |
| 第三方就业调查（如麦可思年度就业报告）、招聘平台报告 | 专业层面的就业率和薪资、招聘需求变化 | 第三方数据，只作参考，写明来源 |

AI 必须联网查最新一期的一手资料，不能凭印象写"某行业很火"；写进报告时注明来源和年份。

## 二、专业认可度：名校不等于名专业

学校的整体名气和某个专业的实力可能差很多：有的普通院校的某个专业是全国顶尖（行业特色校尤其常见），也有名校的某些专业很弱。给"学校"打分时，要看目标专业所在学科的实力：

| 指标 | 含义 | 注意 |
|---|---|---|
| 教育部学科评估结果 | 学科（一级学科）的全国档次，A+ 到 C− | 第四轮（2017 年）结果公开；第五轮结果未统一公开发布，不要引用来路不明的"第五轮排名" |
| "双一流"建设学科名单 | 国家重点建设的学科（2022 年第二轮名单） | 只覆盖少数学科 |
| 国家级一流本科专业建设点 | 本科专业层面的认可 | 数量多，区分度有限 |
| 专业认证 | 工程教育认证、临床医学认证、师范类认证等 | 通过工程认证的专业，学历在《华盛顿协议》成员国之间互认；医学、师范影响执业和就业 |
| 行业口碑 | 就业质量报告里的主要用人单位 | 行业特色校的认可度常常高于同层次综合性大学 |

## 三、保研率：看比例，更要看你在那里的位置

保研（推免）按专业内的成绩排名分配名额。所以真正要问的不是"这所学校保研率多高"，而是"我在那里能排进前百分之几"。

- **同学越强，同样的比例越难拿到。** 一所学校保研率 30%，但同学都很强，考生可能仍然排不进前 30%。录取位次可以当作一个粗略参照：如果考生的位次接近这个专业的录取线（在同学里偏后），入学时的相对位置就偏低。不过高考成绩和大学成绩的关系并不强，只能当作参考。
- **拆开看比例。** 推免名额里常包含支教团、辅导员等专项计划，有的只在少数专业里集中使用；要看目标专业自己的比例，而不是全校平均。
- **看去向比看比例重要。** 保研去了哪里（本校还是更好的学校、什么方向）比比例本身更能说明问题。推免名单通常公示，可以直接查。
- 保研率只影响"前景"分，不能单独决定一个志愿的去留。
