### 历史科目组合一分一段复核表（2024—2026）

`yfyd_history_2024.csv`、`yfyd_history_2025.csv`、`yfyd_history_2026.csv` 是上述河北考试院扫描 PDF 中历史科目组合表的**部分 OCR 整理**，分别保留 309、463、506 个可识别且通过分数/累计单调检查的分档，公布分数范围依次为 140–672、140–672、140–671。它们不是完整一分一段表：扫描件 OCR 有漏行或无法稳定辨认的数字，未识别档位不插值、不补行；最高分以上完整性也未据此认证。

列为 `score,count,cumulative`。`cumulative` 仅录入可识别并经排序检查的累计数。`count` 仅在原 PDF 的 OCR 结果对人数给出唯一数值，且与相邻一分累计差完全相符时录入；无法读清、结果冲突、累计数缺失或递推不符的 count 留空，不从累计差反推并填入 count。当前三年分别有 179、376、493 行 count 通过这项 OCR 唯一值及递推交叉核验，其余 130、87、13 行为空。OCR 值未逐项人工校对，抽样原页图留在工作区临时目录供复查。运行 `check_yfyd.py` 无数据错误；仍会对空 count 行提示递推无法核验，并提示最高档覆盖范围未认证。带 `--admissions` 检查时没有错误，但由于 OCR 漏档，一部分已填 rank 所在分数缺少可确定的同分段下界，校验器会告警并跳过该行的并列位次认证；三年分别有 197、88、4 行此类跳过。其余由校验器检查的历史投档位次均落在可确定区间内。

已填 `history_YYYY.csv` 的 `rank` 均可在对应 `yfyd_history_YYYY.csv` 中按相同 `score` 查到相同 `cumulative`：2024 年 3,750/3,750 行、2025 年 5,022/5,022 行、2026 年 6,583/6,583 行。该逐值对应是 CSV 间的一致性核对，不消除扫描 OCR 覆盖不完整或 OCR 数字误识的可能。官方 PDF 的历史科目组合栏标注“历史（含优惠分）”；整理表沿用此口径，不另行扣减加分。投档分与累计位次只能按这一含优惠分口径理解，不能将此处位次视作裸考原始分位次。
