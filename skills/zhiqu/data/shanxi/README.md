# 山西 · 普通本科批院校专业组投档最低分与一分一段（2025—2026）

各文件的来源（发布机构、原件链接、取得日期、整理方式）见同目录 sources.csv，每行数据的 source_id 指向其中一条。

山西 2025 年是首届新高考（3+1+2），按物理、历史两个科目组合分别划线、投档，志愿填报单位是院校专业组。2025 年以前是文理分科的旧体系，与新高考数据不连续，本目录的 CSV 不收；2022—2024 旧体系官方整表已入本机院校库，见文末“阶段3补采”。

## 来源说明（均为山西省招生考试管理中心官方发布，无验证码）

本科最低控制分数线（官方公告）：2025 年历史 443、物理 419（[公告](http://www.sxkszx.cn/news/2025625/n9279125867.html)）；2026 年历史 409、物理 401（[公告](http://www.sxkszx.cn/news/2026625/n4845127211.html)）。

## 投档表（`physics_YYYY.csv`、`history_YYYY.csv`）

列：`code,name,group,major,plan,admit,score,rank,score_raw`。官方表只有院校代号、院校名称、专业组号和“最低分”，没有计划数、投档人数，`plan`、`admit` 留空；`major` 存专业组备注（如“国家专项计划组”）。

- 官方“最低分”形如 `664.256136133`：小数点前是总分（`score`），小数点后三段各三位，依次是语文与数学成绩之和、语文或数学的最高成绩、外语成绩，用于同分排序，原样保存在 `score_raw`。
- `rank` 是**推算值**：同年同科目组合一分一段表中该总分的累计人数（同分并列取上界）。官方投档表本身不给位次。
- 2025 年：物理类 3,462 组、历史类 1,726 组；2026 年：物理类 4,385 组、历史类 1,917 组。没有投档的专业组 `score` 为空（2025 年 42 与 21 组，2026 年 37 与 26 组），不推填。
- 键 `code + group` 在四张表内都没有重复；专业组号每年重编，跨年请按院校和选科要求匹配。
- 只收普通本科批；本科提前批 B 段等有独立 PDF（如[2025 年 B 段](http://www.sxkszx.cn/files/content2025/2025%E5%B9%B4%E6%99%AE%E9%80%9A%E6%9C%AC%E7%A7%91%E6%8F%90%E5%89%8D%E6%89%B9B%E6%AE%B5%E9%99%A2%E6%A0%A1%E4%B8%93%E4%B8%9A%E7%BB%84%E6%8A%95%E6%A1%A3%E6%9C%80%E4%BD%8E%E5%88%86.pdf)），尚未收录。

## 一分一段（`yfyd_*_YYYY.csv`）

列：`score,count,cum,source`，与官方表“分数、本分人数、累计人数”一一对应；官方表分左右两块并排，已合并并按分数降序排列。

- 最高档是合并档（如 2025 年物理“704 分以上”），官方给出 `count`=2、`cum`=12，两者不满足“累计=上一档累计+本分人数”，只有 `cum` 可用；该行 `source` 标明“合并档”。
- 只公布到本科最低控制分数线（2025 物理 419、历史 443；2026 物理 401、历史 409），线下分数没有位次，不要外推。
- 校验：除最高档外，`累计 = 上一行累计 + 本分人数` 逐行成立，分数无缺口；`python3 scripts/check_yfyd.py` 与 `scripts/validate_data.py shanxi` 均无错误。
- 加分口径：官方表未写明是否含政策性加分，整理时按官方表原样，不另行说明口径。

## 阶段3补采（2022—2024 旧体系及 2025—2026 控制线，只入本机库）

来源均为山西省招生考试管理中心网页原表（HTML），已登记在 sources.csv（source_id 以 `official-gk-complete-` 开头）；原件核对后删除，保留指纹、网址、逐行定位和原格摘录。

- 合计 8,126 行：一分一段 1,435 行＋最高档 2 行、普通本科投档最低分 6,565 行、本科控制线 124 行。
- 一分一段分文史、理工两类，为原表全部分数行。2022 年最高档“624以上”“682以上”与同表 624、682 单点并列，单独存为尾桶，不当单点用。
- 投档最低分覆盖一批 A/B、二批 A/B 和二批 C（文、理）。“最低分”小数点前为总分，小数部分是同分比较编码，原串保留；空格未投满，不填。2024 年原表没有表头行，列义按同站同类表的 5 列结构确定。241 行学校名与教育部全称不能唯一精确对应，学校标识留空，不按招生代码猜。
- 控制线来自各年公告第一节：文史/理工（2025 起历史/物理）普通本科、特殊类型、艺术和体育的文化与专业线，每个数值单独一行并保留原句；“校考成绩合格”等不是数字的规则不生造值。二批本科 C 类线（另行划定）和专科线没有收。
