# 按省复核的研究输出

| 文件 | 内容与复现 |
|---|---|
| `model_review_2026.csv` | 各省独立科类系列的年度 v2 分布检验，训练目标年不晚于 2025，2026 为冻结后的回溯比较；训练只在同省同类样本内选波动倍数 |
| `rho_review_2026.csv` | 浙江、河北、山东各自的共同漂移方差与个体方差比例，只用目标年前的变化；不足两次变化时留空，不自动改 rho |
| `factor_review_2026.csv` | 学校拉力、师范、计划变化在浙江/河北/山东/辽宁各自逐年的相关与方向复核，扣除同省年度漂移；分数和位次的单位分开 |

在技能目录执行：

```bash
python3 scripts/evaluate_models.py --holdout 2026 --out data/calibration/model_review_2026.csv --rho-out data/calibration/rho_review_2026.csv
python3 scripts/factor_scan.py --review-long-term --holdout 2026 --out data/calibration/factor_review_2026.csv
```

输入是各省现有官方 CSV，原始来源见各省 README，不新增下载件。研究表不符合投档表 schema，不作为候选池输入。发现独立 `history_年份.csv` 时自动增加 `<省名>_history` 系列；与物理类分别加载、选参、输出。只有一年或没有可比较的位次时输出 unavailable；只有两个可比较年份、没有更早误差时使用既有默认倍数1检验，不用检验年调参，不合并其他科类来补样本。输出 category、series 明示范围。可用 `--series guangdong_history` 单独检验，旧 `--province` 参数作为同义入口保留。

固定厚尾候选为 90% 原正态加 10% 三倍波动正态；每省分别在训练目标年选 NLL 最小的倍数，再检验 2026。浙江、河北的 NLL 与区间误差均下降，山东仅 NLL 下降而区间误差上升；专业组号匹配的检验一律标 `group_number_exploratory`，不能替代目录核实。没有跨省合并选参或用总体平均证明某省有效。

**未启用新的生产分布。** 此前参与旧 v2 开发的2026系列已经揭盲，当前结果只标作新候选冻结后的一次回溯比较，不冒称独立新留出；新补历史类也保留这一研究标记。正式启用还需独立年份或事前冻结的未来验证；失败系列保留，不反复用2026调参。辽宁、湖北缺可用位次，黑龙江因加分口径未认证撤销精确位次，均输出 `unavailable`，不借其他省的结果填补。湖南物理2023/2024的统一加分列换算亦已撤销，仅使用后续合格年份。河北历史类含部分OCR位次，覆盖与未认证限制必须同时参照本省README。

rho 的年际样本很少，低估值不能证明组合风险足够小；留用 0.1/0.5 敏感性，不替换正式默认。因子相关只作定性提示，计划字段可能来自事后投档调整，不满足事前可得性，不能机械并入预测。新的外部因子、结构修正、组内专业波动与志愿优先精确模型，尚缺足够的同省、同科类、同规则留出样本。

逐年历史行的 drift 和波动倍数只使用该目标年以前的变化与误差；没有先前误差时倍数为 1。2026 比较参数仅从 2026 前选定；其他省的数据不参与选参。`rolling_history` 行不是用最终全年参数倒拟合的结果。

## 学校拉力是否逐年变弱

年度相关如下，正负和强弱都在本省口径内比较：

| 省份 | 年度相关 |
|---|---|
| 浙江 | 2023：-0.247；2024：-0.021；2025：-0.362；2026：-0.401 |
| 河北 | 2022：-0.009；2023：0.169；2024：-0.091；2025：-0.091；2026：-0.034 |
| 山东 | 2024：-0.084；2025：-0.172；2026：-0.255 |
| 辽宁 | 2022：-0.197；2023：0.132；2024：-0.286；2025：-0.252；2026：-0.030 |

现有短序列没有一致的逐年变弱规律，浙江后两年反而增强。它们是相关系数，不是套利收益，更不能把变化归因于志愿 App；没有 App 使用普及的可比观测与反事实对照。保留“是否变弱”的复核问题，不新增时间衰减修正。
