# 公务员职位表：各专业能报多少岗位

| 文件 | 内容 | 来源 |
|---|---|---|
| `guangdong_2026_undergrad.csv` | 广东省 2026 年考试录用公务员（省考），每个本科专业能报考的职位数与录用人数 | 广东省委组织部公告附件 1（职位表）、附件 3（专业参考目录）：<https://www.gdzz.gov.cn/public/广东省2026年考试录用公务员公告附件.zip>，转载页 <https://zfsg.gd.gov.cn/zwgk/gggs/content/post_4786683.html>，下载日期 2026-09-29 |

生成：`python3 scripts/civil_service.py 职位表.xls 专业参考目录.xls 输出.csv`。某专业"可报"= 职位学历含本科，且本科专业要求列出了该专业、所属专业类或门类。

口径与局限：

- 广东 2026 年省考共录用 11,779 人，本科可报的职位录用 9,089 人，其中**不限专业的只有 386 人（4.2%）**。
- 统计的是"能报"，不是"好考"：岗位多的专业，报考的人通常也多；公安、法院、检察院岗位还有性别、法律职业资格、体能等其他要求。
- 只有一个省、一年。国考职位表的下载需要网页验证码，江苏、浙江的职位表所在页面有访问验证，均未抓取；需要时请考生或家长自己下载，再用上面的脚本统计。
