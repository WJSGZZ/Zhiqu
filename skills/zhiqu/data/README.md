# 数据目录与年度更新

## 目录

| 位置 | 内容 |
|---|---|
| `<省份>/` | 各省本科批投档数据，统一为 `code,name,group,major,plan,admit,score,rank`（缺的列留空）；来源、口径和加工方式写在各省 `README.md` |
| `<省份>/yfyd_*.csv` | 由官方一分一段表整理（河北） |
| `<省份>/early_*.csv` | 提前批、专项计划（广东、浙江、江苏） |
| `schools.csv` | 教育部全国普通高等学校名单（2025 年 6 月）：代码、所在省市、办学层次、民办/合作办学备注 |
| `calibration/` | 按省年度校准、厚尾比较、rho与因子描述检验；复现与未启用边界见该目录 README |
| `scau_guangdong_physics_2025.csv` | 华农广东物理本科2025组组成/选科/发布计划（120专业，含无历史的新方向）与2024专业线；并列2025省投档组线。非统一投档表，不可直接传给 pool |
| `gdut_guangdong_physics_2025_groups206_207.csv` | 广工2025广州普通物理206/207两组5专业录取线，完整性限这两组，选科未知 |
| `school-name-changes.csv` | 教育部批复的更名对照样本，pool按稳定学校标识关联教育部名单元数据，不改省级招生代号 |
| `transfer-policy-samples.csv` | 两校2026实际转专业方案的专业实例，名额、门槛、考核与未知申请次数，不代表全校统一政策 |
| `civil_service/` | 公务员职位表的各专业可报岗位统计 |
| `births_by_province.csv` | 分省年末常住人口（万人）与出生率（‰），2016—2024 年。来源：国家统计局国家数据库 data.stats.gov.cn「地区数据 → 分省年度数据 → 人口」，2026-09-30 在浏览器中查询整理。核对：2016、2023 年出生率与《中国统计年鉴》表格一致；2023、2024 年分省出生合计（901.3 万、953.8 万）与全国公布数（902 万、954 万）一致。2016 年分省合计比全国少约 6%，年鉴注明全国数据做过抽样误差修正、分省未修正，属各省同比例的口径差 |
| `cohort_coverage.csv` | 从各省官方一分一段表整理的表内分数覆盖量：广东 2022/2025 历史、物理（≥100 分下限）；河北 2021—2026 物理；江苏 2023—2026 物理等科目类；湖南 2023—2026 首选物理；上海 2024—2026 不分科类；黑龙江 2024—2026 物理类。字段记录公布分数范围、最低分累计覆盖数、加分口径、来源和整理方法。范围外人数与总报考人数没有证明，不能直接传入 `--cohort`。 |

各省官方来源：广东 eea.gd.gov.cn，浙江 zjzs.net，江苏 jseea.cn，山东 sdzk.cn，河北 hebeea.edu.cn，辽宁 lnzsks.com，湖南 jyt.hunan.gov.cn，湖北 jyt.hubei.gov.cn，上海 shmeea.edu.cn，黑龙江 lzk.hl.cn。

`cohort_coverage.csv` 目前共有 24 条覆盖记录，其中 20 条来自仓库已有的河北、江苏、湖南、上海、黑龙江一分一段表。河北 2021 年官方表在 281 分处截断；上海官方表限定为本科录取控制分数线上考生；其他记录也只代表各自公布的分数区间。黑龙江官方表明确不含照顾政策分，湖南 2023 选用“含全国性加分”统计口径，广东 2025 表题注明含本、专科层次加分；其余未在现有省级说明中明确的加分口径记为 `unknown`。`max_score` 仅反映表内最高公布分数，不表示覆盖所有高分考生；空值表示现有整理记录未保留该边界。

## 每年 7 月的更新步骤

各省本科批投档线一般在 7 月中下旬公布，一分一段表在 6 月下旬出分时公布。

1. **下载**：到各省 `README.md` 里列出的同名栏目找当年的投档表和一分一段表，只用官方发布的文件。下载后核对文件大小或能否正常打开，官网文件常被截断。遇到验证码、反爬验证或需要登录，不绕过，在该省 `README.md` 记为缺口。
2. **整理成统一列**，存为 `<省份>/<科类>_<年份>.csv`：
   - 按表头关键词定位列（院校代码、院校名称、专业组 / 专业、计划数、投档人数、最低分、最低位次）；
   - 专业组省份的 `group` 填组号，`major` 列可存选科要求；专业+院校省份的 `major` 填专业名；
   - 只有分数没有位次的省份，用当年一分一段表换算位次，并在 `README.md` 注明"由一分一段表推算"；
   - 扫描件先识别文字，再用"累计人数 = 上一行累计 + 本行人数"、投档表"最低分 + 最低位次"对照等约束核对。
3. **校验**：`python3 scripts/validate_data.py <省份>`。分数与位次不一致比例高，多半是列错位或识别错误；代码匹配率低，先查是否有院校更名或新设；同一代码出现多个校名，多半是 PDF 水印字或识别噪声混进了校名（江苏、上海、湖北都出现过），按同代码的干净校名改正后再提交。
4. **回测与校准**（按同省、同科类、同批次分别检验）：
   - `python3 scripts/backtest.py ...` 得到当年的全省漂移、误差与突变比例，更新 `references/backtests.md` 的变化记录；
   - `python3 scripts/calibrate.py ...` 以正式模型的同一规则重新检验校准（默认 v2，旧记录重现用 legacy），只用训练年份提出建议，再用独立年份验证，更新建议的 `--drift` 和 `--sigma-scale`，同步改 `SKILL.md` 中各省的取值；
   - `python3 scripts/factor_scan.py` 复核长期因子的方向是否保持。
5. **测试**：`python3 -m unittest discover -s tests`，全部通过后提交。示例数字如因数据或模型变化而改变，重跑 `examples/` 下的重现命令，并更新各示例 `README.md`。
6. **名单类数据**：教育部高校名单每年 6 月更新，下载新版后重新生成 `schools.csv`；公务员职位表在每年省考公告发布后（通常 10—12 月）更新统计。
