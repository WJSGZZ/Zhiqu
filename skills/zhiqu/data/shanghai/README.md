# 上海 · 本科普通批次平行志愿院校专业组投档分数线（不分科类，只公布分数）

各文件的来源（发布机构、原件链接、取得日期、整理方式）见同目录 sources.csv，每行数据的 source_id 指向其中一条。

列：`code, name, group, major, plan, admit, score, rank`（缺的留空）。

- 校名为官方简称（如"华东师大"），不能直接和教育部名单匹配。2024—2026 年 PDF 抽取时水印"上海市教育考试院"的单字混进了校名开头（如"市华东师大""上上应大"）；2026-09-30 按同一院校代码的干净简称去掉，共改约 790 行，分数等其他列未动。
- 580 分及以上的专业组只写"580分及以上"，不公布具体分数，已记为缺失；因此只能比较 580 分以下的部分。
- 2023 年此前只找到第一次征求志愿的表，口径不同，CSV 未收录；2022、2023 年本科普通批正式投档表后来已取到，只入本机库（见文末）。

## 阶段3补采（2022—2023，只入本机库）

来源均为上海市教育考试院原件，已登记在 sources.csv（`official-gk-complete-` 开头）；原件核对后删除，保留指纹、网址、页码和原格坐标。

- 合计 3,300 行：考生高考成绩分布表（本科控制线上，作一分一段）676 行、本科普通批院校专业组投档线 2,616 行、本科各批次控制线 8 行。
- 投档线原表 580 分及以上只写“580分及以上”，共 38 行，分数记为未公布，不填数；其余行的语数合计、语数较高分、外语和三门选考分等同分比较项原样存在范围字段里。院校代码取专业组代码前 3 位，与库内 2024—2026 同口径。原表多用简称，与教育部全称能唯一对上的才挂学校标识。
- PDF 有斜向水印，抽取只用横排文字；每份按 3%、至少 3 行按原格坐标独立重读，共 108 行，全部一致。
