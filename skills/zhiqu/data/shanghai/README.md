# 上海 · 本科普通批次平行志愿院校专业组投档分数线（不分科类，只公布分数）

各文件的来源（发布机构、原件链接、取得日期、整理方式）见同目录 sources.csv，每行数据的 source_id 指向其中一条。

列：`code, name, group, major, plan, admit, score, rank`（缺的留空）。

- 校名为官方简称（如"华东师大"），不能直接和教育部名单匹配。2024—2026 年 PDF 抽取时水印"上海市教育考试院"的单字混进了校名开头（如"市华东师大""上上应大"）；2026-09-30 按同一院校代码的干净简称去掉，共改约 790 行，分数等其他列未动。
- 580 分及以上的专业组只写"580分及以上"，不公布具体分数，已记为缺失；因此只能比较 580 分以下的部分。
- 2023 年只找到第一次征求志愿的表，口径不同，未收录。


## 位次（2026-09-30 补充）

`general_<年份>.csv` 的 `rank` 列由同年官方《考生高考成绩分布表》（本科录取控制分数线上考生）换算：位次 = 该投档分对应的累计人数。整理为 `yfyd_<年份>.csv`：

| 年份 | 形式与核对 |
|---|---|
| 2026 | 文本 PDF，累计关系 213/213 成立 |
| 2025 | 扫描件，OCR 识别：双重确认 177/222 行，其余由累计读数单调确认或相邻插值（`source` 列标明） |
| 2024 | 文本 PDF，累计关系 216/216 成立 |
