## 位次（2026-09-30 补充）

`physics_<年份>.csv` 的 `rank` 列由同年官方《普通高考物理类文化课一分段统计表》（xls，按不含照顾政策分统计）换算：位次 = 该投档分对应的累计人数。整理为 `yfyd_physics_<年份>.csv`，三年的"累计 = 上一行累计 + 本段人数"全部成立。

原 `rank` 曾直接按不含照顾政策分的一分段表累计数换算，未与投档分的加分口径对齐。本次已清空 2024—2026 物理类 `rank`；新增 `rank_bound` 仅保存原先换算得到的累计数以供追溯，它不是可认证的精确位次，也不是数学上的上下界。2026 一分段发布说明明确统计表按不含照顾政策分生成，不能把累计表分数直接视作含照顾政策分的投档排序分；2024/2025同年口径亦未完成可复核认证，因此一并撤销精确位次。各年招生规定的官方来源供后续核查：[2024 招生规定](https://www.hlj.gov.cn/hlj/c107857/202404/c00_31727753.shtml)、[2025 招生规定](https://www.hlj.gov.cn/hlj/c107857/202504/c00_31834455.shtml)、[2026 招生规定](https://www.hlj.gov.cn/hljapp/c116058/202604/c00_31936434.shtml)、[2026 一分段表说明](https://jyt.hlj.gov.cn/jyt/c110476/202606/c00_31952462.shtml)。保留各年 `yfyd_physics` 原表，不再据此宣称历史 `rank` 精确。
