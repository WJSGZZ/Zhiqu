# 浙江 · 普通类第一段平行投档数据

各文件的来源（发布机构、原件链接、取得日期、整理方式）见同目录 sources.csv，每行数据的 source_id 指向其中一条。

浙江实行"专业 + 院校"平行志愿，每行是一个院校的一个专业，跨年按"院校代号 + 专业名称"匹配（去掉括号内注释）。

`general_2017.csv`：站点无单独 2017 年投档表页面，取自官方书《浙江省普通高校招生投档及专业录取情况（2017 年）》，一、二、三段同表，取一段最低分 > 0 的行；`major_code` 空，`plan` 为各段合计录取人数；782 行在二段或三段也有录取（一段未录满），`rank` 留空。2022 年的表为 rar 内 xls；2021 年页面另有同文页面 art_155_7768。

列：`code` 学校代号，`name` 学校名称（已去掉"（一流大学建设高校）"等后缀），`major_code` 专业代号，`major` 专业名称，`plan` 计划数，`score` 分数线，`rank` 位次。

- 位次为空表示该专业本轮投档人数未满（官方表注），回测时排除。
- 2018—2020 年原表用 0 表示未满，已改为空位次。2018—2021 年 xls 行数与原表一致；转换脚本在 2022、2023 年 xls 上重跑与已入库文件逐字节相同。外购对照（专业级）：分数一致 99.4%—100%，位次一致 96.4%—99.4%，位次差异都在官方一分一段同分区间内（2021 年 3 条外购在区间外，外购错）。
- 官方原表自身：2019 年 1 行、2023 年 6 行投档分比该位次对应的分数高 3 分，照原表保留。


## 提前录取（`early_general.csv`）

列：`year, code, name, loc, major, subjects, admit, years, avg, score, rank`。来源：浙江省教育考试院《浙江省普通高校招生投档及专业录取情况》2023—2025 年中"普通类提前录取各专业录取情况"一节，PDF 文本提取。按书中说明，有政审、面试、三位一体、综合评价、定向等特殊要求的提前录取不在其中；2026 年的书尚未出版。

## 一分一段（`yfyd_YYYY.csv`，2018—2026）

官方为文字版 PDF，无验证码。浙江不分科类，一张总分表。列 `score,count,cum,source`；首行为“XXX↑”合并档（官方未给本段人数，`count` 取累计人数），已标明。校验：除首行外累计 = 上一行累计 + 本段人数逐行成立，分数无缺口，`check_yfyd.py` 无错误。2022 年表来自官方页面（Word 文档，经 macOS `textutil` 转文本后整理，408 行，687↑ 到 280 分，累计 268,996）。2023 年的全表官方页面未找到：官方只发布了[“普通类二段线上考生成绩分数段表”](https://www.zjzs.net/art/2023/7/22/art_45_2119.html)，表注“表中数字不含录取考生”，累计人数不是全省位次，不能当位次表，未收。官方另有《2023—2025 年浙江省普通高校招生投档及专业录取情况》（[页面](https://www.zjzs.net/art/2026/6/22/art_45_12416.html)），含各专业投档与录取数据，可用于核对外购库的专业级列。

## 省份层规则文件（`rules.json`）

机器可读的本省填报规则（志愿数、投档方式、比例、同分规则、退档情形、选考要求版本、填报时间）、数据集状态（历年投档表、一分一段、2027 届选考要求表的位置；2027 计划未公布）和校准参数，每项带官方来源与核实日期，`volatile` 项每单须复核。字段约定见 [case-workflow.md](../../references/case-workflow.md)。2026-10-07 由单份报告流程的取数建立，规则来自浙江省教育考试院 2026 年 6 月的两份官方通知。



**2018—2021、2023 年一分一段（2026-10-16）**：官方文字版 PDF——2018（只印到 344 分）、2019、2020、2021、2023（此前记为“全表官方未发布”有误）。逐行递推全部成立；2019、2023 年首行原表人数栏与累计不等，照原表保留并在 `source` 注明。与外购逐分对照 100% 一致。2017 年一分一段在站点栏目中没有找到；官方书里的成绩分段表注明不含已录取考生，不是全省位次，未收。
- **2017 年一分一段内部补充（2026-10-16，不提交）**：外购“历史数据”浙江 2017 年一分一段（686 行，逐行递推一致）已入本地内部库 `purchased/internal_yfyd/zhejiang/general_2017.csv`；同一文件 2018—2022 年与官方表逐行相同（0 差异）。
