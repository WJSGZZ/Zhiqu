# 求职权益、合同与应届身份

<!-- 核实：2026-10-19；复核期限：2027-03-31 -->

用于识别选择的代价与待核条款。以下是官方法条和当届指南的摘要；合同效力、补偿和争议结果需结合实际材料由人社部门、法律服务或有权机构确认。不能仅凭岗位名称判定劳动关系；公务员、事业单位、军队文职的录聘规则另按 [public-sector.md](public-sector.md) 查，不能直接套企业劳动合同。

## 一、先分文件：offer、三方、劳动合同

- **offer/录用通知**：核发出主体、岗位、薪资、工作地点、入职日、有效期、背调/体检/获证等条件及撤回/违约约定。名称不能决定法律性质；如果尚有前置条件，就不能把它写成已落实入职。
- **三方/就业协议**：读学校当届协议模板、本人实际签的全文及单位补充条款，列出签约主体、就业条件、违约触发/金额/解约流程、继续升学或考录情形、档案办理。若还有目标机会未定，就在签前比较答复与解约期限并由本人向学校就业处/单位确认能否延期；否则不要为换取“先占名额”忽略责任。电子签约也要留存完整文本。
- **劳动合同**：实际用工之日起建立劳动关系（《劳动合同法》第7条）；应订立书面劳动合同，未同时订立的应在用工起一个月内订立（第10条）。所以三方、签了合同、实际用工是不同事实，不能说只有签劳动合同才有劳动关系。
- **违约的边界**：劳动关系中的劳动者违约金受《劳动合同法》第22—25条限制（专项培训服务期、竞业限制等法定情形）；不能直接推出尚未建立劳动关系的就业协议可以随意毁约或一定无效。《民法典》第495条规定预约合同不履行预约义务的违约责任，第585条规定约定违约金及请求调整规则，**个案是否适用要看协议性质与履行情况**。金额不是全国统一价，也不是学校印了多少就当然有效。争议前保留签署、沟通与实际损失材料，由本人咨询学校就业部门及法律服务，不由AI宣布必赔/免赔。

## 二、试用、离职与服务约定

依据文末《劳动合同法》及其实施条例，签约前逐条对照，入职后若实际安排不同再复核：

| 项目 | 原文边界与核对点 |
|---|---|
| 试用长度 | 合同3个月以上不满1年，试用不超1个月；1年以上不满3年，不超2个月；3年以上固定期限或无固定期限，不超6个月。同一单位与同一人只能约定一次。合同不满3个月或以完成一定任务为期限，不得约定试用；试用包含在合同期内（第19条） |
| 试用工资 | 按实施条例第15条：不低于本单位同岗最低档工资的80%或者合同约定工资的80%，并不低于单位所在地最低工资标准。核工资基数与当地当期标准，不能只听“试用八折” |
| 试用解除 | 企业也须符合法定解除情形，并向劳动者说明理由，不是“试用随时辞退”（第21条） |
| 主动离职 | 通常提前30日书面通知，试用期提前3日通知（第37条）；法定特殊情形依第38条等另核，不一律要求等批准，也不一律建议立刻不去上班 |
| 交接证明 | 解除/终止时单位出具证明，并在15日内办理档案和社保关系转移手续（第50条）。本人核最后工作日、交接、工资奖金结算和下家入职要求，不把辞职通知日当实际离职日 |
| 培训服务期 | 核是否由单位提供专项培训费用、培训及费用凭证、约定期限和剩余期；违约金上限及分摊受第22条约束，普通入职培训不能只凭“培训”两字就套用 |
| 竞业与保密 | 竞业人员限高级管理、高级技术和其他负保密义务者；核范围、地域、补偿及期限，法定期限不超2年（第23—24条）。换行业/下家可能冲突时先请专业服务核验；保密义务不能当不存在 |
| 长期合同与未签合同 | 满足第14条条件的无固定期限合同也不等于永不解除；超1个月不满1年未签书面合同的二倍工资责任见第82条，具体请求期间和证据另核，不把“没签”当无权益 |

如果节点与下家要求冲突，就由本人先协商入职/交接时间并保留确认；否则按已确认顺序办。不得为了保应届身份或赶入职日期伪造经历、离职证明和参保记录。

## 三、直签、劳务派遣、外包

签前把**谁招、谁签合同、谁发工资缴社保、谁排班考核、实际在哪工作**分别写清。若不同，就逐项追问，不能看工牌和办公楼推断身份。

| 类型 | 看什么 | 判断与坑 |
|---|---|---|
| 与工作单位直签 | 合同甲方完整名称、主体资格、实际岗位、工作地和管理关系 | 如果与本人想进入的单位一致，就按该单位条件比较；否则集团下属公司仍需单独判断，直签不自动等于编制 |
| 劳务派遣 | 派遣单位资质、劳动合同中的用工单位/派遣期/岗位、工资社保责任及退回后的安排 | 《劳动合同法》第58条将派遣单位列为用人单位，要求订立2年以上固定期限劳动合同；第63条规定同工同酬，第66条限定适用岗位。派遣不等于没有劳动权益，也不等于自动转成用工单位正式员工 |
| 外包/驻场 | 外包服务商合同、实际管理与交付方式、项目结束/更换驻场地点后的安排 | 如果只是合同写“外包”，实际按派遣形式用工，《劳务派遣暂行规定》第27条要求按该规定处理；否则也需核劳动关系和责任主体。不能靠名称或办公地点自行判案 |

如果岗位只承诺“以后转正/进编”，却没有对应公开规则或书面条件，就把它排除出保证收益；否则仍核转入条件、期限及未转入退路。是否接受第三方合同由本人按收入、内容和保障选择，不把所有派遣或外包都写成骗局。

## 四、五险一金、最低工资与加班

- **五险**：《社会保险法》第2、10、23、33、44、53条区分养老、医疗、工伤、失业、生育。企业职工养老/医疗/失业按规定由单位与个人共同缴，工伤和生育的法定缴费主体是单位。不能把单位成本全部从本人税前工资扣掉；具体基数、费率和当期医保合并实施口径查当地社保/医保/税务部门。
- **参保**：该法第58条要求单位自用工起30日内为职工申请社保登记。试用期不是单位免参保的理由，也不能为保留某类报考资格要求单位不依法参保。
- **公积金**：按2026年修订条例第16—18条核基数与比例；第18条规定不低于5%、不高于国家规定的最高缴存比例，具体比例按批准程序确定。实际核算须查目标城市当期缴存通知和其引用的国家最高比例规定，逐项核上下限、比例与适用情形；经批准的降比/缓缴按第20条另核，不能只见低比例就判违法。新参加工作与新调入的缴存起算按第17条分别核，不默认首月相同。
- **最低工资**：去目标省市人社官网取当前有效标准、适用地区、执行日起和计入项目；若没有当期原文，就不拿旧年数字判offer违法。最低工资是合规底线，不是市场起薪或应届生应得工资。
- **加班**：《劳动法》第44条分别规定延时不低于150%、休息日不能补休不低于200%、法定休假日不低于300%。应用前先核工时制度、计薪基数、加班事实和当地规定，不把补休、包薪或“弹性工作”一句话当全部免付依据。

取信息的时点是比较offer、签合同、首份工资/缴存记录出现时；如果书面承诺与实际记录不一致，就列证据差额，由本人向单位和经办部门核对。计算流程只在offer-compare维护。

## 五、个人所得税：核算输入

按居民个人的工资薪金等综合所得口径：《个人所得税法》第6条规定年度收入额扣除费用6万元以及专项扣除、专项附加扣除和其他依法扣除后的余额为应纳税所得额；税率见该法“税率表一”。专项附加扣除及优惠是否适用须按本人实际和当期官方办法确认，不擅自填满扣除。

国家税务总局公告2018年第61号第6条规定工资薪金累计预扣法；**年度最终税负、每月预扣和实际现金到账不是同一个量**。如果有年中换工作、实习劳务收入、非居民身份或奖金计税选择，就回税务总局/当地税务的适用规则逐项核；否则也不能把年度税额简单当每月工资单税额。到手估算与首年/全年情景见offer-compare，本文件不维护个人税单或固定税费总比例。

## 六、应届身份：按每个机会单独认定

应届没有一张适用于所有机会的“身份保留证”。国家公务员招录、地方机关事业单位、企业校招、人才补贴/落户分别认定；“仅限当年毕业”和“应届”也可能不同，逐字看本次公告/指南与岗位备注。

### 已核的具体实例，不能外推

<!-- 核实：2026-10-19；复核期限：2027-03-31 -->
[2027国考报考指南](https://shanghai.chinatax.gov.cn/xxgk/rsxx/202610/t481764.html)第一章第3问：2025、2026年国家统一招生的普通高校毕业生，离校及择业期（国家规定二年）内未落实单位，户口、档案、组织关系仍在指南列明学校或机构的，可按应届对待。第4问另列留学回国人员的取得学位/认证窗口与未落实单位条件，第11问另列参加基层项目前无工作经历、期满考核合格后的政策。**这些是该届国考的条件，不能推成所有单位两年、所有往届/已就业人员都能报。**

### 怎么判断与保留可用机会

1. **列本人时间线**：学历取得方式、毕业与学位/认证年月，实习和全职工作的起止及性质，已签三方/合同、实际用工、参保类型/月份，档案及组织关系目前在哪里。只记判定需要的时间与状态，不要求上传完整证明、身份证或账号。
2. **列机会原文**：当次招录单位、年份/批次、“当年/应届/择业期/初次就业”的原句、毕业窗口、工作/社保/档案要求、认定截止时点、咨询渠道。企业看招聘官网FAQ，机关事业单位看组织部/人社公告及指南；相互不替代。
3. **逐项结论**：如果所有明示条件已有证据满足，就写“按已取公告初步符合，仍由招录方审核”；如果明确不满足，就写哪条不符；否则由本人把自己的事实向有权招录单位书面问清，标待确认。社保记录与实际工作经历分开看，不能一律写“交了就失去”或“不交就一直有”。
4. **保留的是机会**：如果目标政策限未就业，就在签约、实际入职和报名之前比较“现在就业”与“等待该窗口”的收入、资格和失败退路；否则不为传言放弃可接受的工作。依法就业如实记录，不靠不签合同/断社保/虚假未就业声明来保资格，辞职也不会自动恢复。
5. **复核节点**：毕业、继续学习获新学历、签约、实际入职、换工作及每次招考前重新核。曾经符合的公告不等于下一届仍符合；资格不明的机会不能当保底。

哪些机会值得查：仅限应届的公务员/事业单位岗位、选调、国企及企业校园招聘、限定毕业时间或首次就业的人才政策。普通社招和不限身份岗位也要保留候选，不能让“保应届”成为全部规划的唯一目标。

## 七、收费、安全与争议信息

《劳动合同法》第9条禁止用人单位扣押身份证等证件、要求担保或以其他名义收取财物；第60条也禁止派遣单位和用工单位向被派遣劳动者收费。若要求向招聘方交押金、买课办贷款才给岗位，就先停下核主体和依据，不因“保证入职”付款。

官方考试费用、按规则安排的体检与向中介购买服务，要区分收款主体、公告依据、退款条款；不能把所有体检/考试费一律写成违法，也不能因为收据写“服务费”就当安全。遇争议保留公告、合同、支付和沟通证据，由本人向当地人社、劳动保障监察、仲裁或法律服务核实适用途径；AI不代签、不付款、不发送材料。
