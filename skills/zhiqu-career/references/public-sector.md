# 体制内与大型国企：逐条判资格，再比较路线

<!-- 核实：2026-10-19；复核期限：2027-03-31 -->

本文件管公务员、选调、事业单位、教师、电网/国企、银行、军队文职和基层项目的**查证与取舍方法**。它们不能只归为“有编制的稳定工作”。具体条件、考试和日历从目标年度原文取；历史公告只帮助找字段，不替下一届定资格或日期。应届定义、劳动权益、到手算法各只在 [labor-rules.md](labor-rules.md)、[offer-compare.md](offer-compare.md) 维护。

## 一、从哪条路进去、查哪里

入口按发布机关官网导航到当届公告、职位表、报考指南/问答、考试大纲和后续更正。学校就业网可帮助发现公告，条件仍核发布单位原文或其官方原文转载；付费课程、公众号与经验帖不作依据。

| 路线与官方入口 | 看什么才能判断能否进入 | 何时做、最容易混淆什么 |
|---|---|---|
| 国考：[国家公务员局](https://www.scs.gov.cn/)当年度专题 | 公告基本资格、职位表学历学位/专业/政治面貌/基层经历、指南中的应届口径、备注与限制；考试看公共/专业科目及职位进面规则 | 公告发布后先筛，提交前核更正，资格审查/复审前核证件期限。达到公告基本学历不等于有适合职位；合格线不等于岗位进面分 |
| 省考：目标省组织部、人社/公务员主管部门及官方考试网 | 本省公告与专业目录、职位备注、户籍/生源、获证和经历截止、试卷类别、进面比例；不借另一省目录判专业 | 公告后与国考分别排窗口；若未取当年公告，下一步是复查而非按去年日期报名。相同岗位名不代表条件、科目和工资相同 |
| 选调：目标省组织部选调公告及附件 | 是否定向/常规、哪类高校/专业名单、培养方式及教育经历限制、党员、干部职务级别/任职时长、奖项/排名、校方推荐、培养和服务安排 | 在校方推荐和省报名各自截止前核；若学校在名单只满足学校一项，不能省掉其他条件。普通班委不自动满足干部要求；“选聘人才”不自动等于公务员选调 |
| 事业单位：省/市人社、主管部门与招聘单位官网 | 统一招聘还是单招、应届/社会人员范围、专业证书、岗位类别和考试、聘用/编制/备案/编外/派遣性质、服务期与试用规则 | 公告后核正文与岗位附表，报名前核调整，聘用前核获证及合同。单位是公立不证明每个岗位在编；职测/综合应用与当地“综合知识”不能当一套考试 |
| 教师招聘：当地人社、教育局及学校官方公告 | **招聘新教师还是选调在岗教师**；学历专业、师范要求、教师资格的学段/学科、普通话等证书、最晚取得日；笔试、试讲/技能、服务期及岗位性质 | 准备路线时先核教师资格报考条件，再在招聘公告出来时核岗位条件。若只符合考证条件，不推出符合教师编招聘；“先上岗后考证”必须有本次原文，不能沿用旧政策 |
| 电网与其他国企：集团与实际招聘单位官网；[国家电网招聘平台](https://zhaopin.sgcc.com.cn/)、[南方电网招聘平台](https://zhaopin.csg.cn/) | 总公告 + 省公司/子公司/批次需求，专业按主修还是允许其他经历、学历层次与取得方式、年龄/外语/证书、成绩/体检等要求；对应专业考试大纲、志愿/笔试确认规则、实际签约单位 | 总公告公布后等/查单位本批具体需求，选志愿和确认笔试前再核；不能把某省公司本科要求推给全部电网，也不把“财会类”推成全部财经专业可报。第三方驻场与集团招聘分开 |
| 银行：银行总行及实际分行官网招聘入口 | 校招/社招/实习、境内外毕业窗口、初次就业/应届定义、专业/学历/外语、证书取得日；柜面、客户经理、科技、管培的实际内容、营销任务、轮岗定岗与地点 | 接受笔试/面试前核岗位，签约前核定岗和轮岗条件；分行与总行、银行与外包合同分开。不把“银行岗”都当坐办公室、不销售，也不把某分行条件套全行 |
| 军队文职：[军队人才网](https://81rc.81.cn/) | 当届统一招考、专项招录或专业技能岗位招聘是否适合本人；学历/专业/年龄/职称资格、政治考核、体检、实际驻地、考试/技能考核、聘用与服务要求 | 先认招聘类别再读附件与大纲，报名前核条件，体检/考核按公告安排。文职不是现役军人，不能把统一招考一套条件套全部技能岗位，也不能只看工资宣传 |
| 基层项目：当地人社“三支一扶”、团委西部计划、教育主管部门特岗的当届正式通知 | 招募对象与专业证书、地点、服务期、实际生活补贴/社保及退出、考核与期满政策；哪些优惠还要满足无既往工作等前提 | 报名前比较服务工作和地点，服务期满前再核优惠。中央给项目的补助不等于本人到手；期满优惠不等于自动入编或一定录用 |

医疗、科研等事业单位的专业准入同样逐岗查。已有 [选调高校范围和省考竞争汇总](../data/README.md)只提供所列省份年度的样本与口径，不能替代当届原文；不为本方法扩成全国职位库。

## 二、资格怎么判：一条条件对应一条证据

先从「你现在的位置」「能力与经历」与体制内追问取最小事实，不先收证件扫描件：毕业与学位时间、专业全名及代码、学历取得方式、需要时的境外认证、政治面貌、出生年月、户籍/生源、干部级别及起止、奖励/排名、证书、基层/工作经历。问卷未问或未答的，按目标岗位补问，不把留空当不符合。

对每条候选做表：**原句及条款位置 → 本人事实 → 符合/明确不符/待确认 → 谁能确认 → 最晚确认日**。若有明确不符的硬门槛，就退出该岗位的可报清单；若只是材料未补或口径含糊，就记待确认，由本人向招录单位问，不替资格审核下最终结论；否则才比内容、地点和准备成本。

必须拆开的几组信息：

- **学历与教育经历**：最高学历、要求用哪段学历/专业报考、全日制/统招、学位、专升本/境外等限制分别核；不能只写“本科”就跳过路径条件。
- **专业**：用本次职位表指定目录；名称相近、主修/辅修、专业类/一级学科的对应不明就咨询，不自行扩大。简章只写大类时仍核备注。
- **应届、首次就业与既往工作**：唯一判断流程见labor-rules；签三方、实际入职、社保、档案是不同事实，不能用一项一刀切。
- **干部与奖项**：班委/班长、院系/校级、正副职、任满多久、哪段在读期间、奖学金与综合表彰分开；学校名单中的同名/更名/校区按原文处理。
- **年龄、经历、证书时点**：直接取原文出生区间和截止日，按本人事实核；“报名时”“面试前”“入职前”不能互换。没有明确允许延期，就不能承诺考上再补。
- **政治、体检与服务安排**：按目标公告和官方规定核，不基于问卷健康描述诊断能否通过体检；不收无关家庭私密资料，不承诺考察/体检结果。

**境外与一年制硕士**：如果已取规则明确学历、认证与时间要求，就逐项对照；否则不能从“未写学制”推成必然认可，也不能从没找到规定推成一律不认。读研继续学习的决策另交读研版，不能拿校名或留服认证本身替代具体招录资格。

## 三、时间和准备：能并行不等于都值得报

每条可行路线写一张卡：下一次可用批次及原文、报名/确认/缴费/笔试/面试/获证/到岗节点、考什么、本人基础、要补什么、本人可投入时间与费用、合同/服务条件、失败退路、下次复查。日期和比例只取本次官方原文并加核实与复核标记。

- 如果尚未取到当年日期，就用最近一届的窗口**提醒复查**，明确是历史参考；否则按实际日期排。国考、省考、选调、国企、教师与事业单位窗口不能靠“都在秋招/春招”混排。
- 如果两条路线的考试内容、准备负担或实际日期冲突，就按优先级选主线与备选，注明放弃的节点；否则也先核本人时间够不够，不以“大多错开”要求全部报。
- 如果马上要收入，就保留可接受的企业/当前工作，比较在职准备与等待考试到录聘的无收入时长；否则才评估能否集中准备。考试通过到实际入职的时间未知，也要留出等待情景。
- 如果考证或补资格来不及，就转下一批/其他路线，而不是先按资格已满足写推荐。编外过渡、基层项目、合同岗也各自比较内容与机会成本，不当作必经跳板。

## 四、选岗位与估竞争：只说证据支持的范围

1. **先资格、再意愿、再竞争**：筛能报的岗位，再排本人愿去的地点、任务和服务期；若不愿接受，即使历史分低也不叫保底。条件多不必然竞争低，还取决于合格人群和吸引力。
2. **分清人数口径**：计划招录、待审/过审、缴费、实考、面试入围是不同数。若取得同一时点完整字段，就算对应“人数÷计划”的群体比值；否则只列已有字段与缺口，颜色/阈值不能填成精确人数，未公布或未取到不能填零。
3. **分清分数**：公告合格线、岗位首次入围末位、递补后的名单最低、最终录用分分开；核年度、地区、试卷/职位类别、分制、专业加试和加权规则。岗位更名或条件变化时，不按相同名称硬接历年。
4. **本人水平**：如果有同类、限时、完整的多次练习及稳定范围，可以和对应历史分数作差距提示；否则只写基础未测。模考难度/评分与正式考卷不等价，不能用一次行测+申论直接给“稳上”的档或个人概率。
5. **证据不足怎么写**：报名样本和往年线只能说明已观察到的竞争。若当前计划、条件、科目或本人表现未知，就列未决项和补证节点；否则也只说与过去哪些岗位相近，不承诺本次进面。无可比数据就做资格与成本分层，不硬分个人“冲稳保”。
6. **院校去向的用途**：本校就业报告可帮助找招聘渠道和访谈对象；若有人进入，仍要查其具体条件与本人差异；若没有记录，也可能是未披露或本人没走这条路。两种情况都不证明本人能过或该校不能报，不能因此判“保”或“冲”。

## 五、体制内还是企业：没拿到offer也能比较

在offer-compare的底线和收入方法之外，先把比较对象写实：**具体招录路线/可核资格与准备方案**，对比**具体企业方向、手中offer或留下**，不能拿“想象的公务员待遇”对比现实企业缺点。

| 取舍 | 需要的证据 | 条件判断 |
|---|---|---|
| 内容与地点 | 职责、基层/轮岗安排、实际驻地、服务或最低工作年限、退出与调动条件 | 如果不能接受服务地和流动限制，就不当可行主线；否则仍不承诺以后调回想去的城市 |
| 钱与等待 | 可取得的待遇文件/单位书面构成、公积金及年金适用、录聘等待与本人现金时间 | 如果个人待遇未披露，就列未知及保守支出情景，不用财政预算总额除人数算个人工资；否则也按到手、首年与全年比较，不拿全国平均数 |
| 进入成本 | 能否报、考试范围、既有基础、取证/准备投入和时间冲突 | 如果资格与投入超出可承受范围，就转备选；否则设阶段复盘日，不能因备考已久就无限继续 |
| 稳定与退出 | 行政/参公、事业聘用/备案/合同制、企业直签/派遣等实际性质和服务约定 | 如果只是“国企/公立”招牌，保障仍待核；否则说明具体保障与退出条件，不能笼统写“都稳” |
| 失败后的选择 | 企业窗口、当前工作、基层项目的资格与内容、继续备考需要的现金 | 如果主路线失利或到约定节点仍无进展，就按预先约定的备选切换；否则到新证据出现再重比，不替本人规定必须考几年 |

“很想考”是偏好，“符合条件”是资格，“模考表现”是能力线索，“能等到录聘”是约束，四者不能互相代替。家人偏好与本人不同，按共享direction-and-state处理；本人明确认可并可承受后再定主线。

## 六、报告里的最小交付

在候选方向与时间线里为每条**本人相关**的路线写上述卡片；优先列下次检查点前会关闭的节点。岗位与时间尚未取证时，报告只能给方法和待查清单，不能交一份仿佛已经完成职位核验的可报名表。每条结论标已证实/有证据待确认/目前无证据/明确不符及原因，不把“没找到”写成“不存在”。
