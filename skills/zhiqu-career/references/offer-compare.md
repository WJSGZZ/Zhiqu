# 比较 offer、留下与继续找

先核资格与不能接受的条件，再算钱，最后按本人优先级取舍。签约、付款、违约由本人决定。法律数值、社保公积金和个税规则只在 [labor-rules.md](labor-rules.md) 维护；本文件是比较方法，不预存地方费率或工资。体制内额外条件见 [public-sector.md](public-sector.md)。

## 一、先排除，再列未知

读「钱与城市」「现实约束」「优先级排序」。若收入低于底线、内容或地点明确不想要、作息/出差冲突、资格不满足或存在未解决的违法风险，就说明触发哪条并退出推荐，除非是本人可自主调整的偏好且本人明确调整；否则进入比较。

**收入底线要同时看税前和必要支出后的结余**。如果只给出税前底线，就追问每月必要生活、债务/家庭支出和最晚需要收入的时间；否则不因月薪高于某数就说够生活。资格、合同或收入关键条件未知的，列待确认及确认截止，不能当作已满足或打零分。

## 二、向单位要哪些书面信息

| 项目 | 具体看什么 |
|---|---|
| 工资 | 税前/税后，基本/固定津贴/绩效各多少，试用期间和转正后是否相同，哪天发；口头总包逐项拆开 |
| 保证月数与奖金 | 多薪/年终/提成是保证还是目标值，有无在职、考核、入职月份和发放日限制；往年发过不证明今年保证 |
| 社保与公积金 | 参保/缴存城市、基数、个人及单位比例、开始月份、基数上下限；二金逐项分清企业/职业年金、补充公积金，别把名称当现金 |
| 补贴 | 现金还是报销/实物、领用条件、是否计税、持续多久、离职是否退；政府补贴查获批和兑现条件 |
| 股票/期权 | 归属、行权或出售条件、离职处置、流动性和税费；基准现金按不兑现处理，权益单列 |
| 工时与成本 | 实际班次、休息、出差、驻场/办公地、通勤；搬家押金、租房、餐食、交通及取证成本 |
| 合同与截止 | 合同甲方、期限、试用、到岗条件、offer答复日、服务期/竞业、违约/退出约定 |

如果单位只肯口头承诺，就列未保证，不转成确定收入；否则保留确认日期和适用文件，以便签约前再核。应届三方与劳动合同的边界只见labor-rules。

## 三、算到手：同一个口径比较

至少分**入职首个自然年**和**完整工作年度**。如果首年从年中开始、试用薪资不同、多薪按入职月份折算，就按真实月份和条件计算；否则也要注明按全年持续在职的假设。不能把完整年总包当首年能花的钱。

1. **税前现金**：各月固定工资 + 明确保证且满足条件的奖金/现金补贴。浮动绩效、提成、未经批准的政策补贴单列情景，不计保证额；有条件的“保证奖金”在不满足条件时也不能计入。
2. **个人缴费**：各险种/公积金按各月适用基数 × 个人费率计算，考虑上下限与起算月份；单位缴费不从个人工资再扣。费率未知就写待查，不默认社保合计比例。若书面基数与当地规定疑似冲突，核合规性，不以少缴得到的高到手当优势。
3. **税**：按labor-rules所指的居民综合所得规则、税率表和本人实际扣除估年度税负，核是否还有其他综合所得。薪酬的现金/报销/福利计税不明就记待核。奖金其他计税方式只在取得当期适用规则、确认本人符合后另算情景，不套最省税的假设。
4. **年度到手现金** = 年度税前现金 − 个人社保公积金 − 归属于该情景的税。再列实际到账月份/每月固定工资到手；用年度到手除以工作月数只是平均值，不等于每张工资单，首年换单位预扣与汇算可能不同。
5. **公积金与年金**：个人公积金已在上一步扣过；账户增加额（本人+单位）单列，受提取条件影响，不再加进可花现金。本人若想给福利赋价值，先确认用途与折算方法，避免既算现金又重复算账户福利。
6. **生活结余与时薪**：到手现金 − 房租通勤/必要生活 − 债务家庭支出；另列搬迁等一次性现金占用（可退押金不等于永久成本）。时薪 = 对应期间到手 ÷ 同期间实际工作小时，小时含约定/估计加班；若作息只有口头描述，列工时范围。通勤时间单列，不能只比较名义时薪。

**检查点**：offer比较时先算，签约前补齐关键未知，入职首份工资/缴存记录与承诺核对；与承诺不同就更新比较和权益问题，不悄悄改原假设。

## 四、给得高还是低：先找可比参照

这是**市场相对位置、本人是否够用、这份工作是否值得**三个问题，分别回答。

- **找同类**：做个人案例时取同城市、相近日常任务/级别、相同经验与学历入口、同用工性质的单位原始招聘公告及本人offer；去重，记时间、是否保证、样本范围。若职位都只给很宽的区间，就不能用上限当常见工资，也不能用区间中点冒充实际成交价。
- **条件匹配再比**：如果有可比固定年现金，就比较保证收入、小时收入、城市生活结余及福利；否则只说资料不足，不能定“低于市场”。直签研发、外包驻场和销售提成岗不能因都叫“工程师”混成工资表。
- **工资价位的边界**：人社的工资价位可作官方背景，但须读调查对象、职业分组、年份与经验口径；在岗人群的低分位仍不是应届起薪。若没有应届分组，就保留该限制，不用低分位给应届生定价。
- **个人判断**：如果给得相对高但必须搬迁、加班或波动超本人底线，就不因此排第一；否则若收入够用、内容和成长更匹配，可以选择名义薪资较低的。没有统一的“跳槽必须涨多少”或“本科应得多少”。

在决定答复、谈判目标或跳槽前完成参照核验；不能拿公众号薪资、招聘App截图或未证实的“同学总包”作结论依据。它们只能指向需回单位/官方核实的问题。

## 五、钱以外、排序与不确定性

| 维度 | 看什么与向谁确认 |
|---|---|
| 工作内容与成长 | 主管说的日常任务/产出、带教、定岗/轮岗、晋升实际规则；是否对应本人的能力和目标 |
| 稳定与流动 | 合同主体与类型、业务经营信息、试用与服务期、工作/驻场地是否可调整；不能从预算总额推个人工资，也不能承诺编制永不变化 |
| 城市与生活 | 房租通勤、离家、以后可进入的岗位；落户和人才政策的唯一查证方法见job-search |
| 继续找/留下 | 手中机会的截止、继续寻找的现金时间、现职能否改进、离职和再试用代价；没有新offer时不要假装比较的是两个已落实选项 |

1. 回到本人优先级，先确认哪些是不可交换的底线，再说明每个选项的优势和缺口。若用0—10评分，逐分写证据与理由；这只是整理偏好的工具，不能将资格未知、工资未知用中间分填平。
2. 如果当前只做路线规划，就比较资格、准备成本、收入等待、可接受地点和失败退路；否则才对具体offer作收入排序。体制内和企业选择的补充见public-sector。
3. **做两种情景**：只拿保证现金、浮动收入未兑现；在可信的书面目标/规则下兑现浮动部分。工作时长、租金、入职推迟也按本人可接受的范围变动。若结论因此翻转，就写触发条件，并请本人决定愿承担哪项不确定性；否则说明在哪些已核条件内排序稳定。
4. 同时把前两项偏好权重对调核一次；若结果变了，就把选择交回本人，不能用总分替他作价值取舍。
5. 对照“继续找/留下/先就业”的最晚决策点：如果再等会超过现金承受或错过手里可接受offer，就把放弃的代价写清；否则可以在明确复核节点前继续查，不无限等待想象中的更好机会。
