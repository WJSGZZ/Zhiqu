# 报告结构（固定 12 节）

每份报告都用同一目录，缺内容的节写明原因，不删节。封面标语与其他版本统一：「知其所往，方行其衢。」

| 节 | 内容 | 要点 |
|---|---|---|
| 01 摘要 | 当前阶段；首选方向和两个备选；下一步最重要的三件事及截止日期；下一个检查点 | 只读这一页也能行动 |
| 02 你的画像 | 事实、偏好、约束、有待核实的自我判断；「性格与传统视角」一节有作答时，加"性格"与"传统视角：八字"两个小节（后者按 `../zhiqu-shared/references/bazi-lens.md`，含三方对照） | 引用原话，不贴标签；八字不进入打分和排序 |
| 03 你看重什么、卡在哪 | 优先级排序的含义；若填了"方向与状态"，写卡点类别和小步骤；当前就业形势对本人的含义 | 见 `../zhiqu-shared/references/direction-and-state.md`、`../zhiqu-shared/references/job-market.md` |
| 04 候选方向 | 3—6 个具体职业方向：日常内容、入门要求、收入区间及来源、进入路径、前景条件句、匹配点与差距 | 见 `fit.md` |
| 05 方向比较 | 按优先级给每个方向打分，写理由；做敏感性检查 | 结论不稳时交给本人判断 |
| 06 目标岗位清单 | 按"冲 / 稳 / 保"列出具体的单位类型或岗位名称 | 保底必须是本人真的愿意去的 |
| 07 时间窗口与检查点 | 按月列出各类招聘和考试的窗口、截止日期；标出检查点，到时更新问卷重算 | 见 `references/job-search.md` |
| 08 行动路线 | 各方向对学历、技能、证书、经历的要求和本人的差距；大致怎么补（课程、项目、实习、证书）、先后顺序、要投入多少；**里程碑与切换条件**（如"秋招结束前没有进入任何面试，就调整目标层次或换备选方向"） | 给路线图，不逐句改简历、不做面试训练 |
| 09 offer 比较（有 offer 时） | 到手收入、时薪、城市调整后结余、钱以外的维度、排序与敏感性 | 见 `offer-compare.md`；没有 offer 时写"暂无" |
| 10 风险与权益 | 合同、试用期、社保、三方协议、骗局提醒；跳槽的代价 | 见 `labor-rules.md` |
| 11 追问清单 | 要本人去问 HR、在职的人、学校就业处的问题 | AI 只准备问题 |
| 12 方法、数据来源与声明 | 匹配方法、打分规则、每条数据的来源和日期、可信度；不保证录用 | — |

求职与继续学习的路线结构见[共用规则](../../zhiqu-shared/references/shared-rules.md)。
