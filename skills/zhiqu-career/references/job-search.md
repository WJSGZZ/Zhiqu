# 求职窗口、企业校招与信息查证

本文件管“选哪批机会、看什么、什么时候决定”。找方向、专科与转行见 [fit.md](fit.md)，体制内见 [public-sector.md](public-sector.md)，应届口径和合同见 [labor-rules.md](labor-rules.md)，收入比较见 [offer-compare.md](offer-compare.md)。不在这里存职位库和工资表；选定方向后才为本人取证。

## 一、先排个人时间线

先读「你现在的位置」「现实约束」：预计取得毕业证和学位证的年月、最早到岗日、课程与实习安排、多久必须有收入、已经签过什么。留学人员另记毕业与认证时间；不要只记“2027届”。

以下是**规划顺序，不是统一招聘日历**。各单位何时开、何时关，从本年度官网公告、FAQ及通知逐项抄录；没有当年公告时写“待公布/本轮未取到”，只把往年窗口用于提醒复查，不写成当年截止日，也不把没找到写成没公布。

| 阶段 | 怎么安排 | 什么时候复查、怎么切换 |
|---|---|---|
| 毕业前、实习和提前批前 | 如果有时间验证方向，就先看目标单位的实习/校招入口、毕业时间范围和岗位内容，再决定是否争取实习；否则先选能兼顾学业的正式校招路线 | 在目标单位发布新一届公告时核对；实习不能覆盖毕业/考试安排时，比较收益与冲突再选 |
| 秋招开放至各岗位截止 | 如果满足资格且愿意去，就按实际截止日、准备差距与优先级排顺序；企业招聘和招考可并行，但要核笔试、面试、实习到岗冲突 | 每个批次结束或收到结果时复盘；别等所有公司都开了才开始，也别把“滚动招聘”理解为一直有名额 |
| 秋招之后至春招 | 如果没有可接受的offer，先分清是没看到机会、资格不符、能力差距还是目标过窄，再关注单位的补招/春招公告；否则重点解决签约和选择 | 春招是另一批机会，不能假定是秋招原岗位再次开放；未见公告就不承诺还有名额 |
| 毕业与离校后 | 如果还需要找工作，就同时看允许本人毕业时间的校招、初级社招和官方就业服务；否则按入职安排核合同和证书期限 | 毕业、签约、实际入职前分别复核应届资格，规则只在labor-rules维护 |
| 在职 | 如果离开原因尚能内部解决，先验证改善方案；否则在职核对下一份机会和交接成本 | 社招按岗位实时看，不把“金三银四”等说法当规则；离职时点见fit |

每条候选路线都记：**公告年度/批次、毕业时间范围、报名关闭、笔试/面试、最早到岗、签约答复、资格取证期限、下次核对日**。若两个节点冲突，就把请假、延期是否获书面确认和放弃哪一边写出来；否则保留并行，不写逐日备考或投递计划。

## 二、挑公司和岗位：先看工作，再看名字

每个候选做一张简卡：官网链接及取文日、公司/业务/部门、岗位与地点、合同甲方、日常任务、必需条件、偏好条件、已符合证据、缺口、截止与待问事项。分公司、子公司、供应商不能只用一个集团名代替。

| 要判断什么 | 看什么、去哪里查 | 条件判断与常见坑 |
|---|---|---|
| 是否真的有这个机会 | 从单位官网进入招聘网站，核公告/岗位编号、招聘主体和状态；学校就业网作发现入口，回单位原文 | 如果当前仍招且主体一致，才进入候选；否则记已截止或待确认。群聊截图和第三方“内推”不是公告 |
| 业务和岗位是否适合 | 单位官网业务介绍、岗位原文、公开年报；请本人向HR/直属主管问工作产出、客户、班次、驻场地点和带教 | 如果喜欢的是实际任务且有证据能胜任，就保留；否则不能因公司名气直接推荐。管培生要问定岗规则，运营要拆成内容/销售/流程等具体任务 |
| 经营与组织风险 | 公开财报的经营和现金流、国家企业信用信息公示系统的登记和异常记录；非上市公司拿不到经营数据要留空 | 如果有异常，核日期、主体和实际影响后再判断；否则也不能据“未见异常”宣布稳定。国企或大厂的某一子公司不等于集团担保 |
| 是否值得投入 | 必需门槛、本人差距、截止、工作条件；已披露的薪酬按offer-compare核算 | 如果硬门槛满足、差距能在节点前补上且本人愿去，进入目标；否则转更匹配的岗位或列待确认。招聘未披露薪资就写未知，不编区间 |

### 把招聘要求拆成三类

1. **不能靠表达补的门槛**：学历/学位、专业、毕业时间、到岗、证书等。逐项抄原句，对照本人材料。若不满足明确的“须/仅限”，就不按可报推荐；若“相关专业”等含糊，就列出本人专业名和课程，由本人向招聘方确认，未答复前保留“待确认”。
2. **需要证明的能力**：把“熟悉数据分析/沟通能力强”对应到本人做过的任务、产出、可解释的项目。若只有课程名称而没有产出，就列能力证据不足；否则写具体匹配点。不能把“学过软件”当熟练，也不能替本人编经历。
3. **偏好条件**：“优先/加分”与“必须”分开。若满足所有硬门槛、缺一项偏好但其他证据匹配，可以保留尝试；否则先补必需条件。没有列出的门槛不自行脑补，筛选结果也不冒充公开规则。

做个人案例时，可先读少量目标岗位；若出现不同口径再扩到足够比较的样本。只统计同城市、同岗位层级和同渠道的要求，并标样本数、时间和去重方法；不要为满足固定条数凑库。没有目标岗位原文，就只给探索方法，不给录用概率。

### 提前批、实习与转正

- 如果提前批与正式批是否互通、是否有冷却期/投递次数限制尚不明确，就读该单位当届FAQ或由本人问HR；否则按已核规则排。不能承诺“提前批失败不影响秋招”，也不能默认失败就没机会。
- 如果实习明确有转正通道，继续核适用毕业届别、最低实习时长、部门名额、考核内容、考核/发offer时点和未转正时能否参加正式批；否则按普通实习评价，不把口头“有机会转正”当offer。
- 如果实习能验证方向、形成真实成果且时间可承受，就比较值得争取；否则优先不冲突的机会。对在职转行者，先看是否接收非在校生，不能默认可以用学生实习补经历。
- 在接受实习或提前签约前，核实际任务、报酬与保障、退出约定，合同性质见labor-rules；不要只为“转正率”放弃全部其他机会。公布的群体转正率不等于个人机会。

## 三、没有回音、面试受挫与状态

共享的 [direction-and-state.md](../../zhiqu-shared/references/direction-and-state.md) 管迷茫、家人分歧、怕选错和状态边界；这里仅补求职的定位方法，不另建心理判断体系。

| 观察到的事实 | 怎么区分、下一步看什么 | 何时调整 |
|---|---|---|
| 找不到想投的 | 如果岗位名太宽或只认知名公司，就按日常任务、城市和合同类型扩候选；否则核真实门槛是否需要升本/换入口 | 完成一轮岗位原文比较后重定方向，不因招聘少便说本人“不适合工作” |
| 投递后无反馈 | 先确认岗位仍开放、申请状态、是否满足硬门槛；未回音原因未知，不自动归因学历或能力 | 若不同单位的同类岗位都明确卡同一门槛，就调整目标或补门槛；否则只列假设，不能把无反馈当拒绝理由证明 |
| 笔试或面试未过 | 如果有单位明确反馈或本人可回看的表现，就区分知识、任务能力、表达与岗位选择；否则不猜淘汰原因 | 方向与要求不符就回fit；表达训练和试题辅导请找学校/当地就业指导服务或其他资源，不在这里陪练 |
| 失败后不想继续、反复比较 | 如果日常状态尚可，就把当期工作缩成一项能增加信息的小验证，按本人可承受程度设置下一次检查点；否则先降低任务密度，采用共享文件的支持边界 | 在离校/在职者的报告中，支持入口应包含当地公共就业服务和适合本人的心理健康专业服务，不能只写学校资源 |

不从投递次数或拒信推断人格、诊断心理问题或计算录用率；状态细节不经本人同意不写进报告。

## 四、城市、落户与人才政策

先问：目标城市/区、户籍或生源、学历取得方式和时间、是否有境外学历、已有工作与参保时间、预计单位、最晚迁入时间；落户是必须、偏好还是尚不清楚。只问判定所需事实，不收身份证号、户口页或完整社保记录。

**查证链**：城市政府官网/政务服务网的当期办事指南 → 公安户政的落户条件 → 人社/人才部门的引进政策 → 对应区县的补贴实施细则与申报入口。优先从官方主页导航，检索“城市名＋应届毕业生落户/人才引进/租房补贴”，核页面主体、发文机关、有效期、配套细则和废止通知；宣传页不能代替办理条件。

每项政策只记一处：适用人群、申请主体（本人还是单位）、学历/毕业/就业/参保条件、单位资格、工作与居住区、受理窗口、材料、服务期、到账条件、能否叠加和离职退回条款；附原文与核实/复核日期。字段缺失就记待确认，由本人向官方受理部门核实，不把HR口头“帮落户”当批准。

- 如果落户是硬约束，先确认本人和单位的资格、办理期限与可用路线，再比较offer；否则把政策兑现的不确定性单列，不能只按“可落户”打高分。
- 如果补贴尚未获批或未满足兑现条件，就不计入保证到手现金；否则按实际到账时间计入对应年度，避免把一次性补贴当永久工资。
- 如果城市选择还没定，就比较可进入的岗位、房租通勤、剩余现金、家庭联系和再次换工作的空间；否则只查目标城市需要的政策，不批量做一线城市政策大全。
- **上海只引用既有的 [school-research.md“城市与落户：上海”](../../zhiqu/references/school-research.md#城市与落户上海)**，不抄评分和学校名单。那里是特定年度的毕业生政策参考，并已明示基本条件尚缺；做求职决定仍要回上海政府当期办法补本人、单位和受理条件。其他城市也逐城核，不类推上海。

**时点**：选城市时初筛，接受offer/签约前核资格和单位承诺，入职或申报前核最新指南，换单位/区县前核迁移与返还影响。不能承诺政策到毕业或入职时仍不变。

## 五、按问题取证的入口

| 信息 | 一手入口与使用边界 |
|---|---|
| 招聘要求、窗口 | 用人单位官网招聘页与当届FAQ；学校就业网、[国家大学生就业服务平台](https://www.ncss.cn/)、[中国公共招聘网](https://job.mohrss.gov.cn/)用于发现，关键条件回发布单位原文 |
| 公司主体 | [国家企业信用信息公示系统](https://www.gsxt.gov.cn/)、公司官网及公开财报；未取到记录不解释为没有风险 |
| 工资/税费/合同 | 工资价位找当地人社，核算与来源统一见offer-compare和labor-rules |
| 招考 | 国家公务员局、各省组织部/人社厅、招聘单位官网；分路线查法见public-sector |
| 行业与迷茫 | [全国就业形势](../../zhiqu-shared/references/job-market.md)、[有条件前景](../../zhiqu-shared/references/outlook.md)、共享方向与状态；用前核时效 |

报告中的时间线只写本人会用的窗口。规则、日期、比例回原文核对，写核实日与复核期限；来源取不到就列未知、影响和下一次查证节点，不用经验帖补结论。
