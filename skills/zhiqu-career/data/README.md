# 求职数据

只整理能直接用于[体制内与大型国企方法](../references/public-sector.md)的官方数据。学校在选调名单内，只满足高校范围这一项；学历、专业、应届、党员、干部经历、年龄及职位要求仍须逐项核对当年公告。

## 2027 年选调高校范围

[selected-universities-2027.csv](selected-universities-2027.csv) 收录江苏、浙江、山东三省 **2027 年度**选调高校范围，共 787 行。它是“省份、类别、学校及限定专业”的关系表，一所学校出现在多个类别或对应多个专业时分别记行。

| 省份 | 行数 | 原文校名去重数 | 覆盖 |
|---|---:|---:|---|
| 江苏 | 223 | 180 | 名校优生第 1—5 组，乡镇（街道）类别 I、II |
| 浙江 | 394 | 68 | 常规 59 校；39 类紧缺专业对应的 335 条学校关系 |
| 山东 | 170 | 149 | 第一批 21 校；第二批定向 50 校及另 99 校的限定专业 |

“原文校名去重数”按字符串计算，不当作高校实体数量：附件可能使用旧校名，或者不区分同名异地高校。本表保留原写法，例如山东手册的“上海体育学院”、江苏附件的“上海体育大学”，不自动改名或扩展成多个校区。山东第二批常规选调面向全国普通高校，不属于列举高校名单，未展开全国高校，也未造一条名为“全国普通高校”的学校记录。

### 字段

| 字段 | 含义 |
|---|---|
| `province`, `year` | 招录省份及选调年度；2027 年度公告实际在 2026 年发布 |
| `category` | 公告或附件的批次、类别、组别；不同类别不互相替代 |
| `school` | 附件原校名，去掉排版空白；不另作校名标准化 |
| `major_restriction` | 名单逐校限定的专业原文；浙江附专业代码。空白只表示名单没有逐校列专业，不表示职位不限专业 |
| `source_url` | 官方附件直链；山东第一批为列出 21 校的官方公告正文 |
| `published_date`, `retrieved_date` | 官方来源的发布日、实际取文日，均为 `YYYY-MM-DD`；附件未单列日期时采用其所属公告日期 |
| `review_deadline` | 再用前应复核的日期；不能将 2027 范围当作以后年度承诺 |
| `source_locator` | 附件号、组别或专业序号，便于回原件查找 |
| `notes` | 校名、专业适用和公告层级限制等必要补充 |

### 官方来源与取文

下列原件均于 **2026-10-18 用普通 curl 完整下载**。PDF 使用文字层提取，并对照渲染页；WPS、DOC 用 macOS `textutil` 读取正文和表格，未使用搜索摘要。浙江 ZIP 只使用附件 1、6 的高校范围，未将同包其他职位表整理入本批。原始附件核对后删除，不入库。

| 来源 | 发布日期 | 使用部分 |
|---|---|---|
| [江苏省委组织部 2027 选调公告](https://www.jsxf.gov.cn/tzgg/art/2026/art_06122f61eef24054b136a55aa116fc0d.html)的附件 1、2 | 2026-10-13 | 附件 1 五组分别 22、5、9、4、6 校；附件 2 类别 I 为 144 校、II 为 33 校。附件官方直链逐行见 CSV |
| [浙江 2027 选调公告及附件（中国科学技术大学官网原文转载）](https://job.ustc.edu.cn/selectedtrainee/info.aspx?itemid=11374)；[附件 ZIP](https://job.ustc.edu.cn/uploadfiles/2026/10/20261009091518252.zip) | 2026-10-09 | 附件 1 常规院校范围；附件 6 紧缺专业与对应院校 |
| [山东 2027 选调公告（济南市人社局原文转载）](https://jnhrss.jinan.gov.cn/col/col18309/art/2026/art_8d9982b4a5154d3bb8ed50cbeb642a94.html) | 2026-10-09；公告落款 2026-10-08 | 正文第一批 21 校；CSV 发布日记本转载页日期 |
| [山东 2027 选调报考手册（中国科学技术大学官网附件）](https://job.ustc.edu.cn/uploadfiles/2026/10/20261008112854764.doc) | 2026-10-08（随公告） | 第二章“部分高校”和“部分高校的相关专业” |

整理方法：江苏按原件组别拆校名；浙江常规按四种学校分组拆行，紧缺专业按表格的每条“专业代码、专业名称、对应学校”展开；山东第一批取公告列名，第二批前 50 校不加名单之外的专业限制，后 99 校保留各校整组限定专业。仅删除排版换行、空白和页码，不推断相近专业可报。浙江 `0307 中共党史党建学` 条目附带的“中共党史、党的建设专业毕业生也可报考”已逐校保留在备注。

使用时还须注意：

- 浙江常规的省市、县乡及“同时面向 15 所省重点、5 所政法大学”的职位范围不同。5 所政法大学的扩展针对公告列明、要求法律专业背景的岗位，不是所有常规职位；该限制记在备注，专业字段不伪造成逐校专业目录。
- 江苏乡镇类别 II 本科生的干部、任职时间和奖励要求另查公告；不能仅凭在表内就判断可报。
- 山东第二批直接列校也须符合具体职位专业要求；限定专业学校的范围不外推到其他学校或同名异地高校。

随机抽核使用固定种子 `20261018`，抽 5 行回到原件核对学校、类别和专业；格式检查另由仓库根目录的 `python3 skills/zhiqu/scripts/validate_data.py` 执行。格式合格不代替资格审查。

## 已有广东数据

广东 2026 本科专业可报职位数与录用人数统计仍在[高考数据目录的公务员样本](../../zhiqu/data/civil_service/README.md)，原文件未移动。它是按专业汇总的职位统计，与本目录的高校名单不是同一种数据，不能直接拼接成竞争率。
