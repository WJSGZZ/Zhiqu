# 逐路径比较，避免整套理由复用

新封存画像的不同有效比较对象，不能完整复制支持、反证、成本、失败去向、切换条件五项判断；阶段7拒绝这种整套同文。共同约束放推荐的共同前提，成本和进入条件逐路径核，就业调查不套招生学费。检查只抓整套重复，不能替代语义复核；旧无封存码的迁移报告保留冻结分析，不据此认证其判断充分。

检查读取实际封存原答，不以可删的工作副本标记决定是否启用。新封存报告中，矩阵或主备推荐的每个有效对象须恰有一条已登记ID的判断；五项理由均为非空文字或文字列表。字符串与单项列表按相同内容比较，中文与标点旁排版空白不算差异，英文词间空白仍保留。

每条路径分别核用途、进入条件、时间与真实成本：先工作涉及求职通勤、搬迁与收入空窗；读研涉及学费、学制、生活及资金落实。共同限制可以相同，不能借小幅改词冒充已做语义比较；独立会话仍须核对原答、证据、成本范围和改变结论的条件。

规则在阶段7及正式生成前检查。旧无封存码的迁移报告保留原分析，复核快照可作纯兼容更新，但不重新认证内容或审批。
