# 考研候选学校按需取数
<!-- 核实：2026-10-24；复核期限：2027-04-30 -->

出报告前何时调用，统一见 [报告工作流程的交付时效](report-workflow.md#交付时效)。这里说明工具和限制。

考研由800多个单位分别发布，格式差别大；每个考生通常只比较5—15所学校。常用原表预存，其余候选按需取。覆盖表的 `not fetched` 与“被拦”“未公布”是不同事实，`deferred_reason=按需取：用户问到时再取` 表示收集安排，不冒充失败记录。

在仓库根目录运行（默认本机院校库）：

```bash
python3 skills/zhiqu-shared/scripts/kaoyan_on_demand.py \
  --school 燕山大学 --program 081200 085404 --years 2024:2026 \
  --layers lines catalog stats --minutes 30
```

学校可用规范名、已有别名或名录实际研招单位代码；不从教育部标识码截取代码。年份不传时取运行当年及前两年；先处理较新年份，避免历史缺口占用当前届原表的核验时间。`lines/catalog/stats` 分别是复试线、招生目录或专业计划、拟录取初试统计。`--db` 指定本机院校库，`--output` 指定中文小结和验收结果目录。每次用新的输出目录。`--coverage` 可指定独立覆盖表；自定义 `--db` 默认不写共享覆盖表，离线测试显式使用隔离路径。`--entry` 可补充已证的本校公开入口，不能让第三方域名变成官方。

先检查数据库和覆盖证明：完整取得的官方范围直接返回，第三方行或未证明取齐的部分行不冒充缓存命中。按需取得的专业范围单独登记；它不会把整个学校的覆盖格改成完整。入口按研招网、研究生院/学校、学院文档找；入口表保存936个真实研招名录链接和原文依据，空的研究生站地址不猜。

取文沿用本机 xik-crawler 的全局/同站配额、TLS校验和停止记录，单进程顺序取文。业务原件与名单正文只在内存；固定公共DNS解析协议仍走爬虫原有受限传输，其临时响应由爬虫自行清理。仅当前目标hostname对应的完整固定解析请求可走该内部通道，不把协议中的name参数误作个人姓名；业务网址、跳转里的姓名参数仍拒绝。不使用登录态、解验证码、伪装或绕过403/412、环境检测。公开页面仅有办事流程中的“登录”字样，不等于该原表需要登录；实际阻拦由传输层判定。外层进程严格控制单校总时间，包含解析、候选、验收、发布，到时终止整个任务进程组。

停止分类读取实际HTTP状态和明确失败原因，网址或指纹里的数字不能当状态码。TLS、非公网目标和跳转策略拒绝分别记原因，不冒称验证码；真正的登录、验证码、403/412和限流入口继续停止。跳转后的最终网址也须确认属于官方入口范围，否则不解析、不入库；通过确认后用实际原文网址记来源。

已存在但尚未证明取齐的官方记录，先沿其来源表中实际公告页和附件网址重新核验；有记录不等于缓存取得，不借第三方来源或未确认域名。名录网址只去掉首尾空白，不改写路径。发现链接时兼容原页的二级标题、截断链接的完整提示和招生计划分配用语，这些仅作找原表的线索，学校、年份、硕士层次与业务类型仍须在取得的原表里核实。

原表明写“复试分数线”时按原总分列读取；复试表的“类别”只有明确写出学术/专业硕士及全/非全日制时才拆列，原文同时保留，未知类别或与独立列冲突整份拒绝。同一原锚点跨行的表头不算数据行或随机样本；其他读法已带抽核证明时不重解释沿用。原件指纹若已登记于另一来源编号，保留候选和证明，存量核验关联未完成前不重复新增来源/事实，也不升级为已取得；这道停止检查不等于已经完成存量去重或核验回填。

名录中已记录的官网依据页也进入取文队列，不只使用旧首页。导航优先研究生院、硕士招生入口，博士专用栏目不作为硕士入口；仍最多6个导航链接。已定位业务页的附件和正文原图优先于概况、相关归档链接，业务链接仍最多12个。正文图片覆盖WebPlus等既有发布系统的明确正文容器，不取页眉标志或相似类名里的布局图；发现原图不等于识别通过，图中学校、年份、格值和归属仍逐项核验，失败整份不入。

普通同站301/302也消耗一次请求；单次取文允许总计3次请求，避免第一跳用尽预算而永远到不了附件。跨站白名单、HTTPS降级、TLS和拦截停止规则保持不变，不换身份或传输重试。登录、验证端点包含signin.aspx等常见后缀时，也在请求前拒绝。历史被拦站点不能换路径再请求，最终网址也再次核查停止名单。取数评测必须把已有缓存、新原表提取通过、实际验收入库分开计数；快返回缺口不算成功提速，只读评测也不算已入库。

文字HTML采用 lxml 和 html.parser 两套独立表格读法，逐格及合并锚点一致后按固定种子抽3%（至少3行，不足则全取）；原行数和定位绑定指纹。只有表头明确的列自动映射。计划人数跨多个专业时不分摊、不复制；学习方式、方向、专项、志愿不明确时保持未知。名单只在内存聚合，按原学院/专业/方向/学习方式/专项/志愿分别统计；n<3不保存，仅保存n/min/median/max与匿名定位。

杭州师范大学2026目录另有公开JSON适配：从当届官方简章的实际目录链接，核对前端路由与列映射的已审核指纹，再按公开专业字典的唯一六位代码查询方向；不执行网页脚本、不生成签名、不带登录态。Python与Node两套JSON解析逐值一致，固定种子抽3%至少3行（不足全核），每行绑定API指纹和JSON路径。现阶段仅支持已核“全日制／专业学位／统考”标签组合；其他组合、版本变化、重复业务方向或错误年份留待核。页面“拟招生名额(含推免)”不能根据后端字段名改称纯统考名额；未独立核实公开标签的推免字段不使用，专项接收标志不代表专项人数，欢迎报考不等于资格仅限。运行需Node，缺失时返回缺口。所得范围只记所问专业，不升级全校覆盖。

文字PDF现在可自动处理：pdfplumber按原格线取格，PyMuPDF另读格线和字符位置，全部格值、合并锚点、边界一致后，用全页可见专业代码核对归属。四位代码的复试线只挂原四位范围，不推成六位专业。跨页只接受格线未封口、下一页首格为空且列边界一致的连续关系，不能按“上一个专业”补值。随后固定种子抽3%原行（至少3行，不足全取），把原格文字区域渲染为图片，以macOS Vision第三读逐格比较；任一格不符整份拒绝。学校、年份、硕士层次与数据类别必须同时在真实标题/页眉出现，文件名或父页不能替代。

带可靠完整格线的图片和扫描PDF可走原图识别：Vision整图字符位置分格，与逐原格切块再识别逐格一致，抽10%原行（至少5行，不足全取）再读。标题外的范围说明、缺边界、斜图、未闭合专业归属、跨专业共享计划及有歧义备注都返回缺口，不降标准。全部识别内容只在本机内存；隐私列不送抽核输出，名单只输出n≥3的匿名组。运行需pdfplumber、PyMuPDF、Pillow、NumPy，以及macOS的Swift/Vision；缺依赖返回未取得，不绕过核验。Swift小工具首次编译后按源码和二进制指纹校验复用。

自动适配不意味着所有学校的PDF、长图和范围文字都已解决。遇到不明确的表，工具返回具体缺口；Agent用既有取文及入库工具完成两种独立读法，再以 `--reviewed 清单.json` 续取：清单需包含 layer、原件sha256、manifest，以及 proof（original_rows、extracted_rows、两种不同methods、dual_read_equal、status=approved、read_method=text/image、sample_passed、sample_locators）。文字抽3%至少3行，读图10%至少5行；原件指纹、实际入口、每行source_id均须对应，本轮仍重取核对指纹，不能仅凭清单自称已核。图片有任何格核对不过，整份不入。

候选库只增不改：新增行按真实列类型独立回读，逐项比较值、类型、身份及定位；旧表结构和旧行身份/类型/值不变，本地及跨库外键全部通过，再跑validate_data。纯取数不重复跑代码单测和12例回归；改代码时仍运行全套unittest、check_family、check_demos、validate_data及12个高考案例311文件逐字节回归。

旧值核验会比较配对文件的全部页面字节：只有B-tree/overflow页归属明确且每页完全未变的表才跳过重复SQL扫描，其余退回逐值及类型核对。基线外键证书必须绑定查询库/审计库双指纹、代号、表结构和全部关系登记；先证明旧行未变，再检查新增行所属关系。无证、证书失效或关系变化均退回全量外键检查。证明不依赖文件修改时间。timings.json逐阶段记录克隆、写入、回读、只增核验、关联与发布耗时。已取得候选后，剩余不足210秒时先停止新的网络发现，为核验发布留时间；已在内存的原件仍可处理，未访问入口如实列缺口。使用本轮一份回滚配对，审计库先持久化、查询库最后原子替换；正式库指纹变了就停止。验收失败或时间不足不发布。取得的原件不进Git，不留正文副本；只留指纹、网址、取文日、最小摘录、页表行与匿名核对证明。

## 同一原件的存量核验

同原件SHA已有其他来源编号时，只在来源唯一且官方、网址一致、学校/年份/学院/专业/学习方式、全部数值及原始范围备注逐项一致后复用旧编号。现阶段仅支持整表双DOM及抽核闭合的文字HTML；图片、方向/联培/专项/调剂、科目槽、混合新旧行或身份不明仍留缺口，不以总分相同合并。

旧数字、原始来源日期和旧核验状态不覆盖。独立新核验及物理页表行绑定追加到配对审计库既有`ky_check_sample`，字段`on_demand_line_verification_v1`，形成可回读的事件；事件指纹只校完整性，不是数字签名。每次缓存命中重核事件、当前范围及候选值，失配不得由来源级覆盖凭据兜底。单行核验不认证同来源邻行或学校整表，不给覆盖表写来源级已取得；查询返回实际核验事件与学习方式。

原始范围不靠关键词猜等价：仅允许扣除双DOM原格明确的学位/学习方式类别，其余未解释范围原词必须为空，完整旧范围快照绑定事件；有额外未解释原词就保留缺口，不能只因总分一样升级核验。

现有总分复核只认证年份与总分。比较范围时只扣除已观察的逐字公告前言、原格类别、转录说明及明确的“单科线执行国家A/B类基本要求”附注；原词全留事件和返回记录，单科国家线执行条款不因总分核对而获认证，不补单科数值。非这些确切句式仍有剩余范围/备注就拒绝复用，即使新旧相同也不替它解释；未知原词不靠关键词猜掉。


## 嵌入原件与坏地址

正确年份、业务类型的官方页，可沿同站实际`iframe/embed`的`src`、`object`的`data`发现PDF/图片；已知PDF/OFD浏览器页面只解析唯一的`file`参数，不执行其脚本，也不猜补扩展名。附件仍独立核学校、年份、类型和原格；父标题只是发现线索，不替代附件核验。外站/多个file参数/未知查看器/空引用保留缺口，非名单请求不跟随文件名明确写名单的附件。

残缺百分号等不合法地址在DNS/HTTP前拒绝，原页给了坏嵌入地址时说明“地址不完整”，不写没公布或凭标题猜文件名。编码的登录路径同样拦截；合法编码的百分号文件不变。没有取得真实PDF时，离线发现与编排测试通过也不能称真实原表已入库。

实际资源属性及单个同站HTML基址共同决定链接：object取data，iframe/embed取src；正文链接、原图与导航也按已声明base解析。外站或歧义base不猜相对路径；这项离线格式修补不能反推某次403就是基址造成。

## 取文收据的格式提示

共用内存HTTP适配器的 `public_receipt` 在原件仍在内存时补 `format_hint`：有限白名单的声明MIME、字节前缀签名及匿名HTML标签布尔；至多检查前256KiB，并标是否截断。没有取得返回体就不补造格式信息；未知MIME只记固定标签，不留原值或参数。提示不保存标题、正文、属性、联系资料、cookie或头字节，也不解释验证码/保护页。字节前缀不证明完整PDF、ZIP或表格有效，HTTP200与格式提示均不能升级为业务“已取得”；仍须两读、抽核和逐值回读。新字段只用于诊断，不改变停止/冷却或发布规则。
