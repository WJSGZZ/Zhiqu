# 求职候选按需取证

<!-- 核实：2026-10-30；复核期限：2027-04-30 -->

先明确城市、岗位方向、招聘年度、在校实习或应届校招，以及需要回答的条件。先查本机库，缺项才取少量候选单位的官方原页，不遍历所有企业。工资调查、院校去向、公考竞争统计各有口径，不能替代具体岗位报酬或个人录用机会。查库未命中也不等于没有岗位。

## 运行

在仓库根目录的本机暂存区准备入口文件：

```json
[{"publisher":"毕马威","url":"https://kpmg.com/cn/zh/careers/campus.html"}]
```

这只是已确认单位的公开入口，不代表其中有指定城市的当年实习表。单位名称须与[官方域名清单](official-domains.csv)登记相符；新单位先核官方身份并补清单，不能仅因为域名看起来像单位名称就认证。最多给六个实际入口，不猜栏目编号、不填搜索摘要。

```bash
python3 skills/zhiqu-shared/scripts/career_on_demand.py \
  --region 杭州市 --direction 软件 --years 2026 \
  --stage internship --layers duties requirements pay schedule \
  --entries .cache/career-entries.json \
  --minutes 5 --output .cache/career-request
```

`internship` 为在校实习，`graduate` 为应届校招。年度最多三个，默认当年；年度取原表明确的招聘年度，不能从页面发布日期换算届别。城市按原格精确匹配，不把省份、单位地址、转载学校所在地当工作地；应届校招必须有原表“招聘类型”明确列出校园招聘或应届毕业生招聘。岗位方向是原岗位名关键词，只筛线索，不认定本人资格。单位名称、工作地点、职责、条件和报酬是否适用本人，仍须按报告流程判断。

输出 `result.json` 和中文小结；默认只产生候选。加 `--publish` 才会在候选通过回读、来源、抽核、外键、旧值不变及项目数据检查后，以新文件原子替换本机就业库。没有新候选不复制库。既有读者仍读旧文件；不重跑历史全量重建。成功保留本轮一份回滚和提交收据，批后清候选/中间文件；回滚归属不明时不擅删别人的副本。不要把候选状态写成“已入库”。

## 当前自动化边界

- 郑州航空工业管理学院就业网的具体校招职位：工作城市取原字段，招聘年取任职要求明确届别，不借发布日期或单位地址；逐业务块DOM/流式两读及保留原格全核。发布者为高校平台，页面登记招聘单位另列，非雇主自有官网、非主体或当前在招认证；摘要与正文的学历措辞分别保留，证书“优先”不改必需，原薪酬不推币种/税前税后。
- 规则表继续按原门禁；另已适配宁波东方理工大学的岗位正文、TNGD的具体岗位静态弹层，双读并全段转录核对，仅取明确业务段，不取联系人或相邻岗位。正文只有发布日期时保存 year_basis=publication_date：查询年指公告发布年，招聘届别另按要求原文。发布者不等于合同甲方，静态弹层取得不冒称浏览器实显核验。
- 自动表格要求为 UTF-8 的规则 HTML 文字表：实际标题须明确招聘或实习，原页有登记单位，表内有城市、招聘年度、岗位列。lxml 按 DOM 取格，标准库 HTMLParser 独立流式取格，逐格一致；再从原始 HTML 标签抽 3%、至少三行，不足三行全核。任何抽核失败整表不入。抽核只证明转写一致，不证明事实仍有效。
- 合并格、嵌套表、显式隐藏表、两读不一致、缺城市/年度/阶段口径、其余未适配文字页、PDF、图片、动态接口和登录页面返回缺口，不把无表格写成未公布。外部样式是否改变可见性尚未浏览器验证，不能冒称人工看图确认或真实 OCR 准确率。
- 名单不在这个工具范围。标题或表中出现显式姓名、考号、身份证、联系资料或疑似号码时拒收；这不是通用中文人名识别器。正文只在内存，两读后的匿名业务原格、来源指纹及表/行定位可保存；没有原件文件，不复制整页作审计。不得用此工具整理个人简历、投递信息或逐人录用名单。
- 已核记录仅在同城市、方向、年度和阶段复用，核验后七天内免重取。未公布的字段保留“来源未提供”，不填零、不推算收入；再核同指纹时只追加核验记录，不复制旧事实。期限只表示复用窗口，不能保证窗口内仍在招聘；签约、报酬与时间等关键条件在出报告前仍回原页确认。
- 网络沿用本机 `xik-crawl` 的共享限速、冷却、公开地址和跳转检查。默认串行，多个任务总并发不超过三路。登录、验证码、401/403/412、环境检测及证书错误即停该站；不换浏览器绕过，不改代理、DNS或系统。到期启动终止本轮进程组，最多再等三秒强杀；事务核查与恢复随后完成。若发布时被强制中断，按提交标记和正式库指纹分清“已发布 / 未发布 / 状态待核”，不能把超时一律说成未发布；工作进程结束后，父进程持锁核指纹并恢复未完成的本轮事务；若正式库或字典已被别的任务改变，则标状态待核、保留证明和回滚，不覆盖、不重复写。

## 入库与报告使用

复用现有 `source`、`recruitment_notice` 与 `check_sample`，不新建职位库或把岗位职责塞进工资统计。每个原件按指纹建来源，每个匹配原行仅一份事实；`note` 保存具名匿名范围和原文条件，`excerpt` 保存两读/抽核证明与真实表行，`check_sample` 追加核验日期和原格指纹。这里的“官方原值”只说明来自已确认单位的原文，不能当官方统计口径或本人的 offer。

`zhiqu_db.py jobs` 能显示入库的职责、条件、报酬原文和等级，`source` 可查指纹与行定位；工资数字不自动去掉税前/税后、日/月/年或币种信息。按需工具的小结同样列出出处及缺项。写报告时将实际依赖的原句按[证据规则](report-workflow.md#二证据只有一份)登记到证据表，来源过期、无可比报价的继续写“未取到”，不能把格式核验自动升为结论支持。

离线测试：`python3 -m unittest discover -s skills/zhiqu/tests -p test_career_on_demand.py -v`。它覆盖合成输入，不认证真实雇主表格、市场覆盖或任意网页可取。

高校职位的 `html-class:类名/nonempty-descendant-text:序号` 是自定义原文定位：在唯一 class 业务块内，按文档顺序取全部后代文本，统一空白后去掉空文本，从 1 编号；它不是 XPath。证明的 `locator_basis` 固定声明该口径，业务值须按保留的 token 原文复原。
