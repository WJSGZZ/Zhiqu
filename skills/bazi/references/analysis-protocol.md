# 八字分析、裁决与输出协议

本协议用于完整命盘、单一主题、流派比较、出生时辰校验、古籍解释、教学及审计他人断盘。目标是让事实、规则、推断和不确定性可追溯，不承诺命理结论具有科学预测效度。

## 一、输入与任务边界

用户已经给出四柱时，先确认采用哪组四柱、所问主题、是否要看岁运，以及是否要求独立复核历法。没有要求复核时直接解盘；不要为了形式完整强迫补出生地、经度和钟表时间。可简要声明“本次按所给四柱分析，未独立复核历法”。

只有用户给的是出生资料、要求校时／排盘，或已知误差可能改变四柱时，才确认：

- 出生地当地日期时间、IANA 时区、地点或经度；
- 时间来源和误差范围；
- 法定时间／地方平太阳时／真太阳时；
- 子初换日／零点换日；
- 大运顺逆所采用的传统性别参数；用户未提供时同时输出两个方向，不猜测身份。

缺失信息若会改变四柱，不得默认为唯一盘。无论输入形式，先明确用户要完整分析、单一主题、比较流派、校时、解释古籍，还是审计既有结论。

## 二、可选的排盘与候选盘

本节仅在需要计算或校核四柱时执行；它是输入检查，不是解盘主体。

1. 记录历法引擎版本、时区数据库版本、采用的经纬度、时间校正和换日口径。
2. 输出四柱、藏干、十神、节气前后距离及大运算法参数；所有派生项保留机器可读结果。
3. 检查边界：交节、立春、23:00／00:00、时辰界、夏令时重叠／缺失、真太阳时校正、输入误差范围。
4. 误差区间跨越任一边界时枚举候选盘。每个候选盘给出成立时间区间和发生变化的柱，不凭经历先挑“最准”的盘。
5. 对所有候选盘运行相同分析。优先报告跨盘稳定结论，再列只在某候选盘成立的结论。

候选盘超过合理数量时，先缩小最能改变结论的边界，不堆砌大量断语。

## 三、客观结构层

不下人生结论，只记录：

- 四柱、藏干、十神映射；
- 月令、季节和可见的寒暖燥湿背景；
- 各干支得令、根气、透藏及明显气势；
- 合、冲、刑、害、破、会局的“出现事实”；
- 哪些作用满足成局／成化条件，哪些只是候选；
- 排盘与规则层不确定性。

每项分为：`计算事实`、`采用口径`、`尚未解释`。禁止在本层写“必富贵”“婚姻差”“性格孤僻”等。

## 四、分轨分析

完整操作顺序和综合优先级见 [interpretation-engine.md](interpretation-engine.md)。先形成“形—势—源流”的客观结构主线，再分轨；不要一开始就搜索一个无条件的“喜用神”。

分轨主要在推理阶段完成。面向用户时不默认逐轨汇报；只有某一轨改变了主判断、形成必要约束或构成最强反例时才写入答案。用户明确要求流派比较时，才完整展示各轨。

按固定顺序分别运行，前一轨不得修改后一轨的定义：

### A. 月令格局与制化

列候选格局、取用规则、成格条件、败格因素、救应、相神与无法立格的原因。标注所据文本／谱系。

### B. 旺衰扶抑

列日主和主要五行的得令、得地、得势；给强弱区间而非虚假精确分。写明扶、抑、泄、耗各自收益与代价。

### C. 调候

只处理寒暖燥湿。写清调候问题、所需因素、该因素是否有根有力、是否与其他轨冲突。

### D. 气势、从格与化气

分别检查专旺、从强／从弱／从财／从杀／从儿和化气的封闭条件。普通格与从化均可成立时保留双模型，不以已知经历倒选。

### E. 病药与通关

给出唯一或排序后的主要“病”，说明药如何作用、何时无效及副作用。无明确结构病时写“本轨不成立”，不强造病。

### F. 神煞、纳音、宫位

最后运行；注明来源、查法和是否获主结构支持。只能辅助，不得推翻前五轨。

每轨统一输出：`问题`、`命盘证据`、`规则及来源`、`结论`、`置信度`、`成立条件`、`失败条件`、`竞争解释`。

## 五、岁运与主题

1. 先说明大运顺逆、起运算法与交运时间误差，再看流年、流月。
2. 岁运不是单独的吉凶标签；说明它引动原局什么、增强／破坏哪一轨的什么条件。
3. 对事业、关系、财富、学习、健康等主题，把十神象义写成候选机制，不写成确定事件。
4. 时间判断使用窗口和条件：`在 X 时间窗，若 Y 现实条件存在，Z 类事件／体验的相对可能性按该模型上升`。
5. 不把用户提供的既往经历当作独立验证。用于校准的资料与用于评价的留出资料分开。

## 六、综合裁决

### 1. 先排除不可裁决

若出生时间、历法口径或核心规则分歧足以翻转结论，先输出不确定性，不给伪确定答案。

### 2. 对各轨评分而非投票

依次比较：

1. 排盘是否稳定；
2. 定义、成立和失败条件是否预先明确；
3. 命盘证据是否直接满足条件；
4. 文献是否可追溯且文本层次清楚；
5. 是否给出具体、可区分、可失败的预测；
6. 是否有独立留出验证；
7. 是否依赖大量例外或事后补丁。

不同古籍重复同一句不等于经验验证；复杂度更高而未增加区分力的模型降级。

### 3. 形成自己的主模型

裁决不是从流派中选一个名字，而是建立对本盘最简洁、最有约束力的机制模型：

1. 先写一句不含派名的结构判断；
2. 列出它直接解释的盘面事实；
3. 检查是否需借用未满足的假设、特殊格或事后经历；
4. 用其他路线主动攻击该判断；
5. 攻击后仍成立，才作为当前主模型；
6. 若两模型接近，仍给暂时排序，并写出会使第二名反超的具体证据。

优先级不是“格局派永远赢”或“调候派永远赢”，而是：季节与月令提供背景，正常结构提出主模型，旺衰检验承载，调候在气候成为瓶颈时取得前置权，气势从化只在严格证据下改写普通模型，病药最后定位主结构中的具体障碍。

### 4. 固定裁决格式

- **我的主判断**：一句话直接说明本盘最合理的结构机制，不以“某派认为”开头。
- **置信度**：高／中／低，并列出限制该置信度的事实。
- **证据链**：命盘事实 → 明确规则 → 中间推理 → 有条件结论。
- **主要异议**：只给最强竞争解释，不罗列所有小众说法。
- **分歧点**：指出两种解释在哪一步分叉。
- **改变结论的证据**：出生时间核实、版本核对、某类未揭晓岁运或留出经历等。

不得以“多法一致”代替证据链；若多法共享同一前提，它们并非独立支持。

## 七、时辰校验

校时只能比较候选，不得凭“像不像”反造唯一出生时刻：

1. 由原始时间误差和历法边界生成有限候选盘；
2. 预先选定各候选盘真正不同的、具体可核验命题；
3. 将经历分为训练资料与留出资料；先用训练资料生成候选，再冻结规则；
4. 用留出资料比较命中、失败、模糊和无法判断；
5. 报告似然排序和不确定性，不把小样本最高分写成确定时辰。

严禁用外貌、性格套话、性取向、家庭创伤等高可塑象义单独校时。

## 八、审计他人断盘

逐句标记：

- `P` 排盘事实；
- `R` 有来源且条件明确的规则；
- `I` 由规则推出的解释；
- `H` 可检验假说；
- `V` 模糊陈述／巴纳姆句；
- `A` 事后适配；
- `U` 无法追溯。

检查：是否偷换用神定义、只报命中、时间窗无限扩张、用用户反馈迭代套话、忽略基准率、把同一证据重复计数、由神煞覆盖主结构。审计结论评价的是论证质量，不自动证明相反断语正确。

## 九、标准输出

推荐结构：

1. **排盘口径与不确定性**
2. **命盘客观结构**
3. **我的主判断**
4. **关键机制与证据链**
5. **一个最强异议与分歧点**
6. **岁运／主题的条件性解释**
7. **什么证据会改变结论**
8. **传统解释与现实边界**

引用古籍时给书名、卷／篇、版本或稳定链接；引文与现代转述分开。无法核页时写“转录本待核影印”，不要编造页码。

## 十、安全与隐私边界

- 医疗、心理、法律、投资、生育、生死灾祸不得给确定性判断或替代专业意见；如讨论传统说法，明确其历史语境与证据限制。
- 不预测具体死亡、重大灾害、犯罪、绝症，不用恐惧促成付费、仪式或人生决定。
- 不从命盘推断敏感身份、性取向、道德品质或第三方隐私。
- 命理建议只能作为反思提示；教育、关系、职业、财务与健康选择优先依据现实信息和相应专业证据。
- 个人命盘、经历和校时资料默认不写入长期研究库；只有用户明确授权并约定去标识方式时才保存。
- 用户显著焦虑或寻求绝对保证时，减少断语，回到可控的现实信息、不确定性和求助资源。
