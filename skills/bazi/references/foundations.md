## 一、分析对象

- **四柱**：年、月、日、时各由一个天干和一个地支组成。子平法通常以日干为关系坐标，以月令为时令和结构入口。
- **日主／日元／日干**：同一技术对象的常见称呼。它是十神关系的参照点，不等于完整人格或现实中的“本人强弱”。
- **三元**：天元指干、地元指支、人元通常指支中所藏之干。使用这个词时注明所据文本，避免与其他术数中的“三元”混淆。
- **命局、岁运**：原局是出生四柱；大运、流年、流月是后续时间层。先完成原局分析，再判断岁运如何引动或改变已有结构。

### “天地人三才”不能直接等同三种术数

- 《易传·说卦》所谓三才，分别以阴阳、柔刚、仁义说明天、地、人之道，并以“兼三才而两之”解释六爻；这里没有把天定义成八字、地定义成风水。
- 子平文本谈“三才／三元”时，常指命式内部的天干、地支、支中藏干。《渊海子平》可见“以干为天，以支为地，支中所藏者为人元”；这仍不是“八字—风水—个人努力”的三分法。
- 将八字视为先天与时间条件、堪舆视为空间环境、人的选择视为能动性，是一个可用的现代综合框架，但必须标成现代重构，不能冒充古典“三才”的唯一原义，也不能声称三者各占固定比例。

## 二、五行与旺衰术语

五行生克是关系语法，不是物理因果。记录以下层次，禁止只数五行个数：

1. **得令**：某五行在月令所代表的季节条件中得时。旺、相、休、囚、死是传统时令分类，不是连续测量值。
2. **得地／有根**：天干在地支藏干中有同类或生助来源。根的远近、强弱与是否受冲合，各派定义不同，必须注明口径。
3. **得势**：同类、生助或会局形成全局趋势。不得把地支合会一见即作“化成”，先检查季节、透干、阻隔及本派成化条件。
4. **透干与藏支**：显露与潜藏在传统解释中权重不同；不得把一个藏干与一个得令透干等量计分。
5. **进退、寒暖燥湿、清浊流通**：这些是结构或气候描述，与简单“强／弱”不是同一维度。

旺衰可以是定性比较，也可以是某流派内部的量化辅助；任何分数都必须公开算法，并承认其不是古籍中的客观测量。

### 关系改道不等于任意“元素转换”

把五行理解为动态关系，比理解成五种静止物质更接近古典中的进退、制化与源流语言，但必须区分三件事：

1. **作用路径改道**：甲原本克乙，丙能承接甲之生并再生乙时，局部主路径可能由直接相克转为连续相生；原来的克并未因此自动消失。
2. **功能随结构改变**：同一五行或十神在旺衰、主客、位置、制化不同的条件下，可能由可用转为有害，或由阻断转为救应。这是关系功能改变，不是物质变成另一物质。
3. **合化／成局**：只有满足所据流派关于月令、透干、根气、阻隔、争合和破化的条件时，才允许说“化”；只见合、会或生链不得宣布已经转化。

每次声称“转化”时，写明：`原路径 → 中介或条件 → 新的主路径 → 原路径残余 → 新增副作用`。若中介无力、受制、位置不能接触双方，或只是进一步增强被生一方，降级为“有转化可能，未完成通关”。

## 三、十神是关系标签

以日干为“我”，先依五行生克分五类，再依阴阳同异分十神：

| 与日主关系 | 同阴阳 | 异阴阳 |
|---|---|---|
| 同我 | 比肩 | 劫财 |
| 我生 | 食神 | 伤官 |
| 我克 | 偏财 | 正财 |
| 克我 | 七杀／偏官 | 正官 |
| 生我 | 偏印／枭神 | 正印 |

“正偏”的阴阳配法以常用子平口径为准；若来源采用异名或异配，保留原文并注明。十神先是关系名，后才可能按主题映射为资源、权责、表达、亲属等象义。禁止把“财”等同财富、把“官杀”等同职位、把“桃花”等同必然关系事件。

## 四、月令、透藏与根气

月令至少承担三种不同工作：

- 历法层：以节气定月支，提供寒暖燥湿与季节背景；
- 力量层：判断五行得时、失时及根气；
- 格局层：在月令格局法中，考察月支藏干何者司令、透出以及能否立格。

三者相关但不等同。“月令最重要”不能直接推出“只看月令”；“月令藏干透出”也不能未经条件直接推出格局成立。藏干分日用事歌诀、月令司令细分存在文本差异，若无法确认所采用版本，宁可只记录月支本气、中气、余气，不伪造精确到日的权重。

教学时分清：**通根**是天干在地支藏干中有同干或同五行的依托，强弱还看本气／余气、位置和时令；**透干**是某藏干出现在天干。无根不等于无力，藏而不透也不是不能作用。若一干透出且坐在含同干的月支上，那是同一来源得到显现与支撑，不能当两份独立力量相加。月支还决定季节背景，所以其重要性不是占全盘某个固定百分比；日干、日支与月支也不能用普适的“各占几成”替代关系分析。

日支在传统六亲宫位法中又称配偶宫，可作为亲密关系结构的一个观察位置；它的藏干和与他支的作用须放回全局。不能仅由日支推定当事人喜欢的对象类型、性取向或现实关系结果；传统男命财星、女命官星的婚配映射也不能直接套到现代关系偏好上。

## 五、干支作用的记录原则

1. 先列事实：天干五合、地支六合／三合／三会／冲／刑／害／破等是否出现。
2. 再列条件：是否得令、透出、成局、受阻、被冲破或发生争合。
3. 最后解释：区分“有合”“合绊”“合去”“合化”；区分“有冲”“冲动”“冲开”“冲破”。这些结论不能仅由名称自动生成。
4. 同一组合若不同流派规则不同，分别运行并保留结果，不在中途混用。
5. 作用顺序和远近权重若无明确来源或预注册规则，标为未决，不为贴合经历临时发明。

## 六、用神、喜神、忌神与体用

这些词不是天然同义：

- **格局用神**：月令所用或格局得以成立的核心十神；再看相神、成败与救应。
- **扶抑用神**：为处理日主或全局偏强偏弱而取的生扶、泄耗或克制因素。
- **调候用神**：为处理时令寒暖燥湿而取的关键五行或天干。
- **病药用神**：针对已明确的结构性“病”而取能去病、制病或通关的“药”。
- **喜神／忌神**：只有在已声明模型和目标函数后才有意义；帮助该模型目标者为喜，破坏者为忌。
- **体用**：体与用是相对关系，须按具体文本或流派定义，不默认等于日主与用神。

每次出现“用神”必须带限定词。多路线给出同一五行，不代表论证相同；给出不同五行，也不应强行统一。

## 七、证据状态

为每条重要规则或判断标注一种状态：

| 状态 | 含义 |
|---|---|
| 文献可证 | 能定位到具体版本、卷章或页码，只证明该说见于该来源 |
| 体系内成立 | 按预先固定的流派定义可推出 |
| 跨文本共识 | 多个相对独立文本在定义与条件上高度相近 |
| 经验上暂有支持 | 有预注册、可核验且包含失败样本的测试支持 |
| 未决 | 资料或区分证据不足 |
| 存在反例 | 已有案例不符合，尚不足以否定全部适用域 |
| 当前测试否定 | 在预先限定的测试和阈值下未获支持；不外推为终极结论 |

来源等级另行记录：影印／可靠校勘原典优先承担原文核对；转录本用于检索；学术研究用于文献史；现代术者材料用于记录实践流派。不得用大量低可追溯网页制造“共识”。

## 八、基础层的禁止事项

- 不以五行齐全或数量平均为默认理想状态。
- 不把象义写成确定事实，不由命盘猜测性取向、道德、疾病、死亡、违法或他人隐私。
- 不在得知经历后改换格局、用神、换日法或真太阳时口径来追求命中。
- 不因一句古诀应验就跳过版本、适用条件、反例与基准率。
- 不声称八字已被科学验证；可把它作为传统解释系统、假说生成工具或经预注册检验的研究对象。
