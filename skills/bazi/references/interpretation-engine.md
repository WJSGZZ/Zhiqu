# 八字解盘主引擎

本文件只负责解释四柱，不负责历法计算。它把各条传统路线放在不同问题层，避免把格局、扶抑、调候、从化和病药压成一句含混的“喜用神”。规则在文献中出现，不等于现实预测效度已经成立。

## 一、先确定问题，不先找答案

解盘开始先写清四件事：

1. **分析对象**：原局、某步大运、某年，还是一个具体主题；
2. **所给事实**：四柱、性别排运参数、采用的大运和用户已知的不确定性；
3. **待解释目标**：结构能否成立、日主能否承载、气候能否生化、全局是否顺势，还是某个矛盾如何解除；
4. **证据边界**：四柱事实与传统规则分开；用户经历只用于理解，不自动成为验证。

不要一上来问“用什么五行”。先问：**这盘究竟在完成什么，最先卡在哪里？**

### 控制推断分辨率

按以下四层输出，越往后所需的盘外证据越多：

1. **结构事实**：月令、透藏、根气、合冲及生克链；
2. **机制假说**：承载、制化、流通、调候或阻断；
3. **主题倾向**：资源、表达、约束、竞争、关系或风险偏好等宽主题；
4. **具体实现**：职业、收入方式、婚姻事件、疾病、地点或精确时间。

命盘可以在传统体系内提出前两层，并有条件地产生第三层假说；不得仅凭命盘越级锁定第四层。同一结构可由不同职业、制度、家庭背景和个人选择实现，同一职业也可由不同结构进入。把古代官职、六亲身份或行业类象直译为现代职业，属于过拟合。

需要讨论“命是否固定”时，分开回答：

- **文本层**：古典同时包含原局、岁运、制化、救应和源流等动态语言，也包含强决定论断语；不能只摘一边代表全部传统。
- **体系层**：较稳妥的解释是原局给出关系约束与候选倾向，岁运改变条件，但不提供现实结果的唯一映射。
- **经验层**：把结果写作 `命局结构 × 时间条件 × 环境制度 × 个人选择 × 偶然事件` 的研究框架；这是现代限制过度断言的模型，不冒充古籍原句，也不宣称已经科学验证。

## 二、三遍读盘

### 第一遍：季节和事实

只记录，不断人生：

- 月令、节气区间和寒暖燥湿背景；
- 日干及四柱藏干、透干、坐支、根气；
- 哪些五行得令、得地、得势，哪些只是出现而无力；
- 干支合冲刑害破、三合三会的出现事实；
- 合化、成局、冲去等尚需满足的条件；
- 候选盘之间哪些事实稳定，哪些会变。

禁止数五行个数后直接判强弱；禁止把“有某字”等同“某字有效”。

本引擎把“有效”最低限度定义为：该因素至少具有可说明的根、源或生助链，能接触目标关系，并且没有被更强作用完全合住、制尽或隔断。一个字只要还有本气根、直接坐根或可工作的生助链，就不能仅凭一次冲、合或失令宣告为零；若所据谱系认为它已经失效，必须列出额外条件和竞争判法。这里不用虚假精确分数，但也不允许随经历任意升降权重。

### 第二遍：形、势、源流

依次问：

1. **形**：盘面组成了什么主要关系或候选格局？是否混杂、阻隔、争合或破局？
2. **势**：月令、根、透、党众和会局共同把主导权交给谁？是否达到普通扶抑应让位的极端程度？
3. **源流**：气从何处发动，经什么生化链，流到哪里停止？哪个节点承上启下，哪个节点截断？
4. **清浊**：关键关系是否各得其所；还是几个候选用神互相牵制、药反助病？清浊是关系质量，不是五行多少。

输出一条不含人生事件的“结构主线”，例如：`月令财星主事 → 财生杀 → 日主有根但承载有限 → 印能否化杀成为关键节点`。

源流是对盘内关系的定向描述，不是守恒的物理能量。允许多条路径同时存在；只有在比较得令、根气、位置、制化和阻隔后，才能称其中一条为当前主路径。不得把“甲生丙”写成甲已经不能克乙，也不得把“有中介”写成矛盾已经解决。

### 第三遍：逐轨检验

对同一结构分别运行下列模型。每轨必须给：`它回答的问题`、`所见事实`、`成立条件`、`反证`、`本轨结论`、`置信度`。前一轨不得偷偷改写后一轨的定义。

## 三、五条主分析轨

### A. 月令格局：这盘由什么关系组织

1. 以所采用谱系的月令取用规则提出候选格局；
2. 看月令藏干何者透出、何者有力，杂气如何处理；
3. 检查顺用／逆用、成格、败格、相神、救应、清纯混杂；
4. 建禄、月劫及特殊外格按专门规则，不因普通格难解而临时转格；
5. 写出破格因素若消失、或救应因素若受损时，结论怎样变化。

这里的“用神”是格局所用的结构核心，不自动等于扶身五行或调候之字。

### B. 旺衰扶抑：日主及关键角色能否承载

按得令、得地、得势分开判断：

- 得令不等于全盘必旺，失令也不等于无根可用；
- 透干、坐支、远近、通根、受制和党众不能等量相加；
- 先给强弱区间，再说明扶、抑、泄、耗分别会改善什么、牺牲什么；
- 极端盘先过从旺、从弱、从财、从杀、从儿等反证门槛。

扶抑只能回答承载与偏颇，不能单独决定格局成败，也不能代替调候。

### C. 调候：这个结构在此季节能否生化

先诊断“候病”，再提出候选字：

1. **寒暖**：寒到不能发动，还是热到焦枯？
2. **燥湿**：燥到不能滋生，还是湿到滞塞漂荡？
3. **物性任务**：木要生长还是修削，火要引发还是制烈，土要疏润还是止水，金要锻炼还是淘洗，水要发源还是堤防？
4. **原局是否已经解决**：不能只看月份，忽略已有强力调节；
5. **候选能否工作**：检查根、透、坐、位置、合、制、泄、隔及节气前后；
6. **结构代价**：改善气候时，会不会破格、助病、削弱承载或使另一方太过？

调候输出必须写成：

`候病 → 候选调节因素 → 有效条件 → 原局有效程度 → 对其他轨的收益与代价`。

同一月令内部仍可能随节气前后、支局和透藏换法；具体日干也不能被“同属一个五行”抹平。若候选只出现而不得地、无根或受制，写“有字无功”，不能因字面出现就宣布调候完成。

### D. 气势、从格与化气：普通主客关系是否应让位

分三个问题，不混称“特殊格”：

- **专旺／一行成势**：主导五行是否取得近乎封闭的全局趋势；
- **从格**：日主是否没有有效根援、无法保有独立承载，且所从一方真正成势；
- **化气**：天干五合之外，是否同时满足月令、化神、根气、妒合争合和破化条件。

操作上先列反证：暗根、比印援助、逆势字、争合、月令不助、化神无力。反证未排除，普通格应保留为竞争模型。不能因为某段已知经历好看，倒推“原来是真从／真化”。

### E. 病药与通关：最关键的阻断怎样解除

先画关系，再命名：

`结构目标 → 主要病神或阻断 → 候选药 → 药的作用路径 → 新增副作用`。

病必须具体，例如夺财、杀重无制化、枭夺食、两行交战、寒湿使通关失效；“不平衡”“缺某五行”不够具体。药必须能触及病且有力，不能一个字包治所有问题。若没有唯一优先矛盾，本轨写“未发现足以主导全局的病”，不要为了套病药法强造病。

## 四、把不同“用神”放回各自位置

每次使用“用神”都加限定词：

| 名称 | 所回答的问题 | 典型失败方式 |
|---|---|---|
| 格局用神 | 月令结构以谁为核心、怎样成败 | 用扶弱抑强倒写月令用神 |
| 相神／救应 | 谁保护或修复格局核心 | 只见某字便称救应，不查能否作用 |
| 扶抑用神 | 什么改善承载或力量偏颇 | 数量打分、忽略格局代价 |
| 调候用神 | 什么改善寒暖燥湿与物候功能 | 冬火夏水查表化、无根也算有效 |
| 病药用神 | 什么解除已定义的主要病 | 先选喜欢的字，再反造病因 |
| 通关之神 | 什么把交战转成可流通路径 | 中介太弱、受合或加重寒湿 |

最后可以得到一个“综合优先因素”，但它必须说明是在哪些目标下的折中，不得假装古籍中所有“用神”本来就是同一个概念。

## 五、综合裁决，不用多派投票

### 1. 先找层次兼容

不同路线可能同时成立，因为它们回答不同问题。例如：

- 格局决定结构目标；
- 旺衰决定日主能否承载；
- 调候决定这套结构在季节中能否发动；
- 病药指出当前最窄的瓶颈。

只有当它们要求同一岁运出现相反效果时，才是真冲突。

### 2. 冲突时的层级

不是所有盘都由同一模型永远居首，采用下列条件式优先级：

1. 若寒暖燥湿已经极端到候选结构无法发动，调候是**必要前置条件**，但只能说明“先能工作”，不能单独证明格局结果；
2. 若不存在上述生化否决，月令格局和形势源流决定主要结构目标；
3. 旺衰决定日主及关键角色能否承载该目标，不能承载时降低格局实现度；
4. 真从、真化条件封闭满足时，普通扶抑让位；未封闭时普通格保留优先；
5. 病药法在上述层次中寻找**最窄瓶颈**，不能另造一个与结构无关的目标；
6. 两轨仍给出相反岁运方向时，不强行折中，冻结各自的可区分预测再比较。

### 3. 真冲突用固定标准裁决

依次比较：

1. 定义是否预先固定；
2. 成立和失败条件是否真正满足；
3. 是否直接解释盘面主线，而不是只解释一两个字；
4. 文本层和版本是否可追；
5. 能否提出与竞争模型不同、可失败的岁运命题；
6. 是否有未参与建模的留出证据；
7. 是否需要大量事后补丁。

不要因古书数量多就投票。晚书转抄早书不是独立证据；两个模型共用同一月令判断，也不是两份独立支持。

### 4. 固定输出裁决

- **结构主线**：全盘最有解释力的气势和关系；
- **当前最优模型**：哪条轨负责主解释，其他轨负责哪些限制；
- **综合优先因素**：第一、第二优先；每项强制写 `功能、适用条件、失效条件、副作用`，禁止脱离本盘复用成喜忌表；
- **主要代价**：一个因素改善什么、同时损害什么；
- **最强异议**：竞争模型在哪一步分叉；
- **置信度**：受哪些排盘、文本或经验缺口限制；
- **改变结论的证据**：什么未揭晓岁运或事实可以区分。

## 六、岁运只引动原局条件

分析一段岁运时逐项写：

1. 它增强、削弱、合住、冲开、通关或激化了原局哪条关系；
2. 它对格局、承载、调候和病药分别有什么影响；
3. 这些影响是否同向，若不同向，哪个更可能成为瓶颈；
4. 只有在现实条件存在时，可能出现哪类主题变化；
5. 什么情况算该判断失败。

不要把“财、官、冲、合”直接翻译成钱、升职、灾祸或婚姻。时间判断应是有边界的条件命题，不是确定事件。

## 八、文献边界

- 《滴天髓》本地快照支持以体用、形势、源流、清浊和从化观察全局，但歌诀、散文、括注和后按仍有混层风险。
- 《穷通宝鉴》本地快照支持逐干逐月、节气前后和条件式调候；它同时含大量结果断语，不能把后者当成已验证规律。
- 《子平真诠》的月令用神、成败救应、相神体系必须与民国评注及现代扶抑重释分层。
- 《神峰通考》的病药语言应回到具体结构矛盾，不以后世“一病一药”口号替代全书语境。

详细的逐书研读证据不随本技能公开发布。引用关键规则时回到绑定版本和具体 PAGE；本文件是操作综合，不是原典本身。
