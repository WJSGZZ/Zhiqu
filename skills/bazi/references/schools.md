# 八字主要分析路线与冲突地图

这里的“流派”更准确地说是**分析路线／模型族**。一位作者可能同时使用多条路线；同一名称在不同著作中也可能异义。运行时必须分轨，不得为得到满意结论而临时切换规则。

## 一、比较方法

对每条路线固定六项：

1. **问题**：它试图解释什么；
2. **输入**：它优先读取哪些命局事实；
3. **成立条件**：何时允许给结论；
4. **失败条件**：何时必须降级或停止；
5. **输出**：它实际能给什么类型的判断；
6. **可区分预测**：与竞争路线在何处会给出不同、可核验的结果。

若文本没有清楚的成立／失败条件，只能作为解释材料，不能冒充稳定算法。

## 二、月令格局与制化

**核心问题**：月令形成了何种主要关系结构，该结构如何成、败、救应或转化？

**优先输入**：月支藏干与司令、透干、日主承载能力、官杀财印食伤之间的制化、合冲与清纯混杂。常用概念包括用神、相神、忌神、成格、败格、救应。

**成立条件**：

- 先声明所据格局谱系及月令取用规则；
- 月令之气与透藏关系足以确定候选格局；
- 以该谱系预先规定的成败条件检查全局，不只看格名；
- 特殊外格必须满足其专门条件，不能因内格难解便转入外格。

**失败／降级条件**：月令取用不明；多个藏干争用而规则不能决断；格局关键条件被破且无本派认可的救应；必须借用另一流派的“补缺”才能维持结论。此时输出候选格局和分歧，不强立一格。

**典型冲突**：格局法的“用神”可能是官、财、印、食等月令核心，不等于扶抑法中补强或泄弱日主的五行；格成未必追求五行均衡。

**可区分预测**：相同旺衰条件下，格局成败因素不同的岁运应呈不同方向；应事主题应与成格、破格的具体关系一致，而非只说“好运／坏运”。

## 三、旺衰扶抑

**核心问题**：日主和全局各方力量是否偏强、偏弱或形成失衡，何种生扶、泄耗、克制能改善该模型中的平衡？

**优先输入**：得令、得地、得势、透藏、根气、会局、制化、位置与季节。月令权重通常最高，但不能机械等同全部力量。

**成立条件**：

- 公开强弱判据和权重；
- 区分日主旺衰、某五行旺衰与全局气势；
- 同一套规则先后适用于所有案例；
- 极端命局先排查专旺、从格等竞争解释，再使用一般扶抑。

**失败／降级条件**：仅以数量或软件分数定强弱；权重可随案例改变；把藏干、透干、得令等量相加；遇到反例便追加未预设的“特殊情况”。临界强弱应给区间或双模型结果。

**典型冲突**：扶抑所喜可能损害格局清纯或调候；“身强用泄克”不能覆盖官印相生、杀印相生、从化等结构问题。

**可区分预测**：同类扶抑五行到来时应呈相对一致方向；若效果强烈依赖某一具体十神组合，则格局／病药模型可能解释力更高。

## 四、调候

**核心问题**：特定日干处于某月令时，寒暖燥湿是否妨碍生发、锻炼、润泽或流通，需要何种条件调节？

**优先输入**：月令、日干、季节极端、全局水火燥湿、调候之干是否有根有力及是否被合伤。《穷通宝鉴》常按日干与月份逐项讨论，不能缩成“冬喜火、夏喜水”。

**成立条件**：确有可说明的寒、热、燥、湿病；所取调候因素在命局或岁运中能实际发挥；保留具体日干、月令与组合条件。

**失败／降级条件**：只凭月份套固定五行；忽略原局已有强力调节；调候之神虽出现却无根、受制或反成另一结构之病；以调候直接取代格局成败或日主承载分析。

**典型冲突**：调候所需之火水可能在扶抑模型中为忌，或破坏格局。先分别记录“气候改善”和“结构代价”，不能一句“喜火”吞并两者。

**可区分预测**：调候模型应对极端季节与相应水火燥湿变化更敏感；若所有月份均可事后解释，则模型失去区分力。

## 五、气势、专旺、从格与化气

**核心问题**：命局是否已形成不可逆或高度集中的全局趋势，使一般扶抑、格局逻辑需要让位于顺势？日干合化是否满足化气体系的条件？

**必须分开**：

- **专旺／一行成势**：某一方局或五行取得主导；
- **从强／从弱及从财、从杀、从儿等**：日主放弃独立承载而顺从强势一方；
- **化气格**：日干参与天干五合，并满足本派关于月令、化神、根气、妒合争合与破化的条件。

**成立条件**：使用所据文本或师承的封闭判据；检查日主是否仍有有效根援、逆势力量是否足以破局、季节是否支持、岁运能否提供反向检验。真从、假从、真化、假化不得只凭结果好坏倒推。

**失败／降级条件**：一般身弱便称从；只见天干合便称化；一见三合字全便忽略月令、透干与破局；为了贴合已知经历在正格和从格之间切换。条件临界时必须并列普通格与从化候选盘／候选模型。

**典型冲突**：普通扶抑倾向救弱扶身，从格倾向去逆从势，方向可能相反。这是最有价值的可区分分歧之一，必须用未揭晓岁运或留出经历检验。

**可区分预测**：扶身岁运与助势岁运应给出相反方向；若两边均以新增解释判为吉，则该比较无效。

## 六、病药与通关

**核心问题**：命局中哪一个具体矛盾阻断结构或流通，什么因素能去病、制病或让交战双方通关？

**病药**：先定义“病”为可定位的结构性损害，例如用财而比劫夺财、杀重而无制化、土重埋金等；“药”必须针对该病，不是泛称缺少的五行。《神峰通考》明确把病药与单纯中和、财官论区分。

**通关**：两方交战时，引入能承接生化链条的中介。例如金木相战是否可用水转化，只是关系模板；是否真能通关仍看水的力量、寒湿副作用、位置和原结构目标。

**成立条件**：病可观察且优先级明确；药能实际作用于病；去病后不会产生更大的、未计入的结构损害；同一规则可事前说明何时失效。

**失败／降级条件**：把任何不喜欢的字叫病；一个药同时被宣称能解决所有问题；病消失后仍以“无病不贵”硬造新病；通关元素太弱、被合化或造成严重寒暖燥湿问题。

**典型冲突**：病药可能选择尖锐制衡而非平均；所取之药可能与扶抑或调候相反。综合时比较哪个模型提出了更具体、风险更高、可证伪的预测。

## 七、神煞、纳音与宫位辅助

**定位**：辅助索引和传统象义层，不得覆盖干支生克、月令、格局或气势结论。

**适用条件**：能说明算法、来源和版本；同一神煞的查法稳定；主结构已有独立证据；只用于增加主题候选或文本解释。

**失败条件**：神煞定义冲突；同盘吉凶神煞堆叠而无裁决规则；只列命中例；用纳音年命直接取代四柱；由桃花、羊刃、华盖等单项断性格、关系、疾病或灾祸。

**输出规则**：写“按某书某法出现 X，传统象义为 Y；本盘主结构是否支持：是／否／未决”。主结构不支持时不得强断。

## 八、冲突裁决矩阵

| 分歧 | 必须分别回答 | 首选区分证据 |
|---|---|---|
| 格局用神 vs 扶抑用神 | 成败救应是什么；强弱改善是什么 | 对应十神组合与单纯力量变化的岁运差异 |
| 扶抑 vs 调候 | 强弱方向；寒暖燥湿方向 | 非极端季节与极端季节中的相对表现 |
| 普通格 vs 从格 | 有效根援是否足以不从；逆势字是否破从 | 扶身与助势岁运的相反预测 |
| 合而不化 vs 化气 | 合、绊、去、化各自条件 | 化神得令／得地及破化岁运 |
| 中和 vs 病药 | 平衡目标；具体病与药 | 药是否只在病存在时有效 |
| 主结构 vs 神煞 | 不用神煞能否得出结论 | 神煞在主结构控制后的增量解释力 |

综合裁决按以下优先顺序：排盘口径稳定性 → 规则定义清晰度 → 成立与失败条件是否满足 → 文献层级 → 可区分预测的具体性 → 留出验证表现 → 复杂度惩罚。不得以“古书更多”或“说得更好听”裁决。
