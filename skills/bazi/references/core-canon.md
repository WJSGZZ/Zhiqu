# 七部子平主干：运行规则与文本边界

本文件把七组主流原著转成可执行的解盘约束。详细的逐书研读证据不随本技能公开发布。

## 绑定的七组文本

| 文本 | 主要贡献 | 运行时风险 |
|---|---|---|
| 《渊海子平》 | 日主、月令、十神、六格及赋诀汇编 | 正格与大量外格混列，口诀互相冲突 |
| 《三命通会》 | 四时、格局、制化、岁运及早期材料总汇 | 十二卷多来源并置，不是单一算法 |
| 《神峰通考》 | 病药、雕枯旺弱、杀的制化 | 作者强论与所收旧诀不总一致 |
| 《滴天髓》 | 气势、源流、清浊、真假、从化 | 歌诀、旧注、任注和命例容易混署 |
| 《子平真诠》 | 月令用神、成败、相神、救应 | “用神”常被后世扶抑义倒写 |
| 《穷通宝鉴／栏江网》 | 逐干逐月调候 | 版本链不清，处方容易机械套用 |
| 《命理约言》 | 简化法度、正变格辨析、驳杂法 | 当前见证是韦千里精选本，不是原十卷全本 |

## 必须遵守的共同约束

1. 日干是十神关系坐标；月令是季节与结构入口。
2. 有效力量由得令、根气、透藏、位置、党势、制化与寒暖共同决定，不数五行字数。
3. 生克本身不带固定吉凶：有用之克可以成事，有害之生可以加病。
4. 优先解释正常月令结构；从格、化气、暗冲、虚邀等必须使用更严格的成立条件。
5. 六神先判断是否有效、服务何种结构、是否过度，再谈象义。
6. 原局定义结构可能性，岁运只增减、触发、通关或破坏。
7. 神煞、纳音和单柱口诀不得推翻主结构。

## 本技能自己的解释立场

原著提供概念、反例和竞争规则，但不代替裁决。本技能采用以下层级，不因某位名家声望或某句口诀流行而改变：

1. **正常结构是默认模型。** 先由月令、透藏和实际制化寻找全局主要关系；普通结构能够充分解释时，不另立奇格。
2. **旺衰是承载检验，不是总司令。** 它判断日主及关键十神能不能工作、作用能到什么程度，但不能单凭“身强身弱”吞并格局、调候和源流。
3. **调候是条件约束，不是固定处方。** 寒暖燥湿严重到妨碍五行发挥时，其优先级上升；原局已有有效调节时，不重复加药。
4. **气势源流负责整体一致性。** 它检查力量从哪里来、流向哪里、在哪里阻断；任何“气势”判断都必须还原为根、透、位置和生克链，不能只凭感觉。
5. **从化属于高门槛例外。** 有效根援或逆势结构尚存时，默认不从不化；不能因为从格解释更漂亮便降低门槛。
6. **病药是定点诊断。** 先有可观察的结构损害，才谈药；它不能凌驾于所有命局，也不能把没有戏剧性矛盾的中和局判成无用。
7. **神煞纳音只提供低权重象义。** 它们没有资格逆转前六层结论。

当这些层次冲突时，优先选择：直接盘面证据更多、因果链更短、附加例外更少、失败条件更明确的解释。若两个模型仍难分，给出暂时排序和翻转证据，而不是用“各派都有道理”结束。

### 最终表达规则

- 第一段先给自己的主判断，不先报书名或派名。
- 古籍用于支撑或反驳判断，不以引书数量投票。
- 默认只讲决定主结论的两至四个关键机制。
- 只保留一个真正有能力推翻主判断的异议。
- “未决”是自己的认识边界，不是把所有意见并排后拒绝裁决。

## 禁止使用未限定的“用神”

每次必须选择一个有类型的字段：

- `pattern_use`：月令格局的核心对象；
- `support_use`：旺衰承载的扶、抑、泄、耗因素；
- `climate_use`：寒暖燥湿的调节因素；
- `remedy_use`：针对具体结构之病的药；
- `flow_mediator`：交战双方之间能真实承接的通关中介。

不同类型同指一行，只表示多条理由汇合；不同类型相冲，分别写功能收益与结构代价，不强行合并成一个喜忌。

## 关键冲突的默认裁决

- **病药 vs 中和**：只有病可定位、药能触及且副作用可控时运行病药；不以“无病不贵”强造问题。
- **调候 vs 格局**：极端气候可成为前置运作条件，但调候字出现不等于格局成立，更不等于现实富贵。
- **七杀先论**：仅当七杀得令／有根／受生并实际形成支配压力时提高优先级。
- **普通格 vs 从化**：任何有效逆势根援先作为从化反证；临界盘并列模型，不依已知经历选择。
- **藏干分日**：默认只用本中余气、节令深浅和透藏；不用某一分日表制造伪精确。
- **运干支五五分**：不机械采用。整柱、原局与流年共同判断。
- **奇格神煞**：只有主结构无法解释且特殊格封闭条件完整时列低置信候选；神煞只作附注。

## 《三命通会》后三区的特殊处理

- 卷十《看命口诀》《巫咸撮要》《玉井奥诀》来源不同；后者仍含年命、纳音、神煞等较早坐标。
- 卷十一同时包含《气象篇》《六神篇》《消息赋》、旧注、万民英解及题属徐子平的赋篇。
- 卷十二汇集多种赋诀，存在相反奇格和硬结果断语。

可以提升的原则：先月令后日主、先气象规模后用神出处、察源流与位置、太过不及须有救应、岁运扶损原局。

不得提升的内容：查表式寿夭、疾病、贞淫、职业、克亲、单柱结果及互相冲突的奇格断语。

## 证据等级

文本重复前先查依赖关系。晚书转抄早书只算一条传承链，不算独立共识。裁决顺序：

`版本与文字层 → 规则定义 → 成立／失败条件 → 相对独立的跨文本支持 → 事前可区分预测 → 留出表现 → 复杂度惩罚`

文献存在、体系自洽和现实有效必须分别报告。
