填志愿、要不要考研、该接哪个 offer，这些决定的后果，往往要过好几年才看得清。

知衢是一组装在 AI 助手（Claude Code、Codex 等）里的规划技能。你花二十分钟填一份问卷，AI 按你自己在乎的东西，用官方公开数据把几条路放在一起比：能去哪里，有多大把握，要付出什么，走不通退到哪，什么时候该再看一次。最后交给你一份 12 节的报告，第一页就是结论和接下来要做的事。

- **按你的排序来算。** 学校、专业、城市、前景，哪个排第一由你定，不按别人的标准替你选。
- **概率经得起对答案。** 高考版只用往年数据排志愿表，再拿当年真实投档线逐条核对，每个省准不准都公开评级。
- **没依据就不编数字。** 读研、求职拿不到可靠数据时，只给分数情景和收入测算，不说“你有 X% 的把握”。
- **问卷替填的人着想。** 填到一半关掉，下次打开还在；高一高二用不上的题会自动收起；作答只存在你的浏览器里。交给顾问时复制出来的是加密内容，只有顾问能打开，中途被改动或截断也能发现。

## 案例

人是模拟的，数据是真的。十二位模拟考生分布在浙江、山东、河北、江苏、湖北，有普通家庭、复读生、高分考生、卡在本科线边缘的，也有不缺学费的。每个人的设定在看到 2026 年数据之前就写好存档，志愿表只用 2025 年及以前的官方数据排，排完再拿 2026 年真实投档线对答案。结果不好也照实写。

**能判定的 8 个案例全部被录取，没有滑档，其中 7 个正好落在报告说的“最可能”那个志愿。** 另外 4 个无法判定：报告里有的志愿在 2026 年投档表里对不上号，主要是江苏、湖北的专业组每年重新编号。

### 小雅 · 山东 · 普通家庭

> 分数中等，不知道学什么好：计算机、会计、当老师都想过。哪个好就业，又是我能上的？

父亲在潍坊的机械厂做技术员，母亲在超市做会计，家里一年收入约 15 万，还有一个上初中的弟弟。530 分，全省第 135,253 名。父母希望她当老师或学会计，稳定，离家近。

- **按她自己的排序**：就业第一、专业第二、城市第三。计算机的前景分只比师范高半分，在她的排序下拉开了约 10 分，所以表以计算机为主。报告写明了这半分怎么来的、改了以后表会怎么变。
- **7 个志愿**：冲刺青岛农业大学的计算机类，最可能落在山东政法学院计算机科学与技术（约 76%），保底是山东女子学院的软件和数据科学。
- **2026 年真实结果**：两个冲刺没过，第 3 志愿山东政法学院计算机录取，余量约一万五千名，正是报告说的最可能去向。

## 快速开始

### 1. 安装

电脑上要有 Python 3.10 以上，以及 Claude Code 或 Codex 其中之一。打开终端，运行：

```bash
git clone --depth 1 https://github.com/WJSGZZ/Zhiqu.git
bash Zhiqu/install.sh
```

脚本会找到你电脑上的 Claude Code 或 Codex，把技能装进去，下载大约 34MB。以后更新，进 `Zhiqu` 文件夹运行 `git pull`，再运行 `bash install.sh --update`。

不熟悉终端也没关系，把这句话发给你的 AI 助手，它会替你装：

```text
请按 https://github.com/WJSGZZ/Zhiqu 的 README 安装知衢技能。
```

用的是别的 AI 助手？只要它支持 `SKILL.md` 格式的技能，运行 `bash Zhiqu/install.sh --dir 它的技能文件夹` 即可。报告会导出 PDF，这一步需要电脑上有 Chrome 或 Edge；没有的话会导出网页版。

### 2. 填问卷

打开[在线问卷](https://wjsgzz.github.io/Zhiqu/)，选高考、读研或求职，大约二十分钟。拿不准的题可以先空着。

填完以后，**自己交给 AI 分析，就点按钮下面的“复制未加密版本”**。复制出来的是一段 JSON 格式的文字，AI 读起来最准，你不用看懂，也别改动，原样粘贴就行。上面那个大按钮“复制我的画像”复制的是加密内容，给知衢顾问用的，你自己的 AI 读不了。

### 3. 交给 AI

把复制的内容粘贴给 AI 助手，再说一句你现在的情况和最想解决的问题，比如：

```text
这是我的知衢画像。我是 2027 年浙江考生，已出分，位次 58000。
请先跟我确认专业偏好和调剂态度，再帮我排志愿表。
（这里粘贴刚才复制的内容）
```

AI 会先问清几处影响结论的缺项，再去查官方数据，最后给你一份 PDF 报告。到了出分、拿到 offer 这些节点，改几道题再发一次就行。

## 能做什么

| | 回答什么问题 | 报告里有什么 |
|---|---|---|
| **高考** | 志愿怎么填 | 用各省官方投档位次预测录取线，算出每个志愿的录取概率和滑档风险，排出整张志愿表 |
| **读研** | 保研、考研、出国、中外合作办学，还是先工作或考公 | 几条路的比较；按年级和专业排名判断保研还现不现实；把可能的初试分数放进目标院校往年录取分布里对照；时间线和检查点 |
| **求职** | 找什么工作，选哪个 offer，考公考编还是进国企 | 按兴趣、能力和收入底线找方向；考公、选调、事业单位、电网和银行等国企的报考条件对照；算出到手收入、时薪和扣掉房租后每月剩多少；合同里要留意的地方 |
| **八字**（可选） | 换一个传统视角看看自己 | 问卷里自动排盘，和性格自评、现实条件放在一起对照；不参与打分和排序 |

知衢只给路线图：不代写文书和简历，不代为填报，不承诺录取。

## 数据准不准

**高考**用 12 个省的官方投档数据（浙江、山东、河北、江苏、湖北、湖南、福建、广东、山西、辽宁、上海、黑龙江），除辽宁外都配了一分一段表；河南只有一分一段表。全部来自各省考试院公开发布的原表（[数据说明](skills/zhiqu/data/README.md)）。

十个重点省份逐省、逐科类做过“对答案”：每一年只用之前的数据预测，再和当年官方位次比，按结果评级（[评级方法和逐年明细](skills/zhiqu/data/calibration/README.md#十省可信度体检2026-10-16)）。

| 等级 | 意思 | 省份 |
|---|---|---|
| A | 说“八成把握”的区间，回头看大约八成真落在里面；说“95% 稳”的，失手不超过 7% | 山东、河北、江苏（物理类）、湖北 |
| B | 基本吻合，误差大一些，报告会写明 | 浙江、江苏（历史类）、福建、湖南、广东 |
| C | 新高考只考了两年，能对答案的次数太少 | 山西 |
| D | 官方投档表要登录才能看，没有收录，没法检验 | 河南 |

数据少的省份也能排表，只是会把不确定性算大、多留保底，报告会写明为什么更保守。

**读研和求职**没有统一的全国数据库，所以先定方向，再按具体学校和岗位去查：教育部和研招网的规定、各校拟录取名单、人社部门的工资价位和最低工资、劳动法规。报告里每个数字都标出处；遇到验证码或要登录的页面不绕过，直接写明“没取到”。

想知道具体怎么算的，看[模型说明](skills/zhiqu/references/volunteer-game.md)和[回测记录](skills/zhiqu/references/backtests.md)。

## 局限

- 录取概率、分数情景和收入测算都是估计，不保证录取或录用。模拟里没出现滑档，不等于没有风险。
- 高考有官方投档数据的是 12 个省，其他省份要现查。江苏、湖北这类按“院校专业组”投档的省份，组号和组内专业每年会变，填报前必须用当年招生计划逐组核对。
- 2026 年对答案时，有的方向整体变热，录取线比预测更高。表能稳住，靠的是保底留得足，不是冲刺概率算得准。
- 八字没有经过现实预测检验，只作自我对照。
- 一切以考试院、教育部、学校和用人单位当年的正式文件为准，最后怎么选由你自己决定。
