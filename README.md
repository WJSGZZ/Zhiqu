「衢」是四通八达的路口。知衢帮高考考生做两件事：

- **看清方向**：用一份 15–20 分钟的问卷盘点分数、目标、兴趣、性格和现实约束，生成一段「画像」
- **算清志愿**：AI 读取画像，给出适合的专业方向；再根据历年录取位次估计每个志愿的录取概率，排出一张**期望收益最高、滑档风险可控**的志愿表

"收益"不是学校排名，而是按考生自己排出的优先级（学校、专业、城市、前景、稳妥）来计算的。

> 知衢不是官方工具，也不保证录取。一切以本省教育考试院和各校当年的招生章程为准。

## 使用教程

按你的角色看对应部分就行：

| 你是 | 需要做的 | 看 |
|---|---|---|
| 考生 / 家长 | 填问卷，把画像交给 AI 或顾问 | [第一步](#第一步填问卷生成画像) |
| 用 AI 帮人填志愿 | 安装技能，把画像发给 AI | [第二步](#第二步让-ai-分析方向排志愿) |
| 只想用计算器 | 自己准备数据，运行脚本 | [第三步](#第三步只用计算器) |

### 第一步：填问卷，生成画像

1. 打开 **[在线问卷](https://wjsgzz.github.io/Zhiqu/)**，手机和电脑都能用。
2. 先准备好：**全省位次**（比分数更重要，查本省"一分一段表"即可）和**选科组合**。
3. 按顺序填完十节。拿不准的题可以留空；选了"出国""考公"这类选项，下面会自动出现追问。
4. 第九节"排个序"最关键：按你真正在乎的程度，依次点选五项，它决定了后面怎么计算收益。
5. 点页面底部的 **「生成我的画像」** → **「一键复制」**。复制出来的是一段以 `【高考志愿 · 自我盘点】` 开头的文字。

作答会自动保存在当前浏览器里，中途关掉页面再打开还在。换设备或清理浏览器数据后会丢失。

### 第二步：让 AI 分析方向、排志愿

**安装技能**（需要 [Claude Code](https://claude.com/claude-code) 或 Codex 这类能运行本地脚本的 AI Agent，以及 Python 3.8+）：

```bash
git clone https://github.com/WJSGZZ/Zhiqu.git
```

把 `Zhiqu/skills/zhiqu` 整个文件夹放进 Agent 的技能目录：

| Agent | 放到 |
|---|---|
| Claude Code（所有项目可用） | `~/.claude/skills/zhiqu/` |
| Claude Code（只在某个项目用） | `<项目>/.claude/skills/zhiqu/` |
| Codex | `~/.codex/skills/zhiqu/` |

以 Claude Code 为例：

```bash
mkdir -p ~/.claude/skills && cp -r Zhiqu/skills/zhiqu ~/.claude/skills/
```

**开始对话**。把画像粘贴给 AI，并说明你想要什么，例如：

```
这是我的知衢画像，帮我分析适合的专业方向。
【高考志愿 · 自我盘点】
……
```

```
按这份画像帮我排本科批的志愿表，我是 2027 年 XX 省考生。
```

AI 会按以下顺序工作，每一步你都可以打断或纠正：

1. **查缺**：只追问会影响结论的信息，比如位次、选科、体检、学费上限、是否服从调剂。
2. **找方向**：给出 2–4 个专业方向，每个都附上证据、反证，以及怎么验证（通常是去读目标院校的培养方案）。
3. **核实数据**：查本省当年的填报规则（志愿个数、专业组模式）和候选志愿的历年最低录取位次，并注明出处。
4. **打分**：给每个候选志愿的学校、专业、城市、前景打分，按你的第九节排序加权，并请你确认。
5. **计算**：算出志愿表，同时和"只冲名校""只求稳"两种填法对比。
6. **交付报告**：给出按顺序排好的志愿表，每一格都写明理由、录取概率和冲/稳/保标签，并列出还要核实的事项。

**用好它的几个建议**：

- 数据越实，结果越可靠。如果你手上有考试院的投档表、学校的分专业录取表，直接发给 AI。
- 觉得某个打分不对就直接说，比如"我其实很想去成都"。AI 会改权重重新计算。
- 家长和你想法不一样时，可以让 AI 按两种排序各算一版，对比两张表的差别。

### 第三步：只用计算器

不用 AI 也能直接运行优化脚本。它只依赖 Python 标准库。

**1. 准备候选志愿表**（CSV，UTF-8 编码），每行一个志愿：

```csv
name,utility,rank_2025,rank_2024,rank_2023,p_adjust,utility_adjusted
甲大学·计算机类,95,13500,12800,14100,0.10,65
乙大学·软件工程,80,21500,20300,22800,0.05,60
丙大学·通信工程,66,32500,33800,30900,0.10,45
```

| 列 | 含义 |
|---|---|
| `name` | 志愿名称 |
| `utility` | 你有多想去，0–100 |
| `rank_年份` | 该志愿当年的最低录取**位次**（同科类），至少填一年 |
| `p_adjust` | 过了线却进不了所填专业的概率（可不填，默认 0） |
| `utility_adjusted` | 被调剂到别的专业时，你有多想去 |

还有 `adj`（今年相对往年的变化）、`obey`（是否服从调剂）等可选列，完整说明见[数学模型 · CSV 列说明](skills/zhiqu/references/volunteer-game.md#3-csv-列说明)。

**2. 运行**：

```bash
python3 skills/zhiqu/scripts/optimize.py 我的候选.csv --rank 22000 --slots 45 --u-fall -60 --max-fall 0.01
```

| 参数 | 含义 |
|---|---|
| `--rank` | 你的全省位次 |
| `--slots` | 本批次最多能填几个志愿（看本省当年填报办法） |
| `--u-fall` | 滑档有多糟，和 `utility` 用同一把尺子，通常取负数。越怕滑档，数值越低（如 -100）；宁可复读的，可以取 -10 左右 |
| `--max-fall` | 滑档概率上限，如 `0.01` 表示最多 1% |

加上 `--json 结果.json` 可以另外保存一份完整结果。

**3. 读结果**。仓库自带一份虚构示例，可以先跑一遍看看效果：

```bash
python3 skills/zhiqu/scripts/optimize.py skills/zhiqu/examples/candidates_demo.csv --rank 22000 --slots 6 --u-fall -60 --max-fall 0.01
```

输出包括：

- **推荐志愿表**：已经按填报顺序排好。其中"单独过线概率"是只看这一个志愿你能过线的概率；"最终落在此处"是考虑前面的志愿可能已经录取你之后，你真正被这里录取的概率。
- **汇总**：期望收益、滑档概率，以及录取线比往年波动更大时的结果。
- **对照**：和两种直觉填法的比较。示例中的结果如下：

| 填法 | 期望收益 | 滑档概率 |
|---|---|---|
| 知衢优化 | **76.4** | **0.00%** |
| 只挑最想去的 6 个 | 67.6 | 6.85% |
| 只挑最稳的 6 个 | 63.9 | 0.00% |

## 填志愿的几个常见误区

- **"把保底的放前面更安全"**：在平行志愿下这是错的。表内应该按喜好从高到低排，冲刺志愿放在后面等于白填。
- **"用分数和往年比"**：分数随试卷难度浮动，应该用位次来比。
- **"不服从调剂，大不了去下一个志愿"**：错。投档后被退档，通常会直接掉出本批次，不会再检索你后面的志愿。
- **"去年线低，今年去捡漏"**：录取线有大小年，单年异常不能当成趋势。

## 原理

一句话：平行志愿下，你会落到表中第一个"位次过线"的志愿，所以表内顺序应该按喜好排，真正要决定的是**选哪几个**。知衢用历年位次模拟今年录取线的波动（包括各校一起涨落），再逐个挑出让期望收益增加最多的志愿。在各志愿互相独立的情况下，这种挑法被证明是最优的（Chade & Smith, 2006）。详见[数学模型](skills/zhiqu/references/volunteer-game.md)。
