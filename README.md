「衢」是四通八达的路口。高考填志愿，就是站在这样一个路口。**知衢**想做两件事：帮考生看清自己想往哪条路走，再帮他们算清楚怎么填，才能让期望收益最大、又不至于滑档。

## 它由两部分组成

### 1. 自我盘点问卷（`index.html`）

一份约 15–20 分钟的网页问卷，共十节：

| | 内容 | | 内容 |
|---|---|---|---|
| 一 | 分数坐标（位次、选科） | 六 | 你是个什么样的人 |
| 二 | 根本目标（就业/考研/保研/考公/出国…） | 七 | 现实约束（体检、语种、学费…） |
| 三 | 专业：想学什么，绝不学什么 | 八 | 风险偏好与填报心态 |
| 四 | 院校：想上什么样的大学 | 九 | 排个序：到底谁最重要 |
| 五 | 城市与地域 | 十 | 你心里的话 |

- 每节开头说明"为什么问这个"；选了"出国""考公"等会自动追问细节
- 纯前端单文件，无需后端；作答自动保存在本机浏览器，刷新不丢
- 填完一键生成一段文字「画像」，复制给 AI 或顾问即可

### 2. 志愿顾问 Skill（`skills/zhiqu/`）

给 Claude Code、Codex 等 AI Agent 使用的技能。读入画像后：

1. **找方向**：把兴趣、能力、目标和硬约束交叉，给出 2–4 个专业方向，每个都附证据、反证和验证办法
2. **算志愿**：把平行志愿当作一场决策博弈——
   - 用官方历年**位次**估计每个志愿今年的录取概率（蒙特卡洛模拟，考虑各校录取线的共同涨落）
   - 用考生自己在第九节的**优先级排序**构造效用
   - 选出**期望效用最高**、且滑档概率在考生可接受范围内的志愿组合，并按喜好排好顺序
3. **讲明白**：和"只冲名校""只求稳"两种直觉填法对比，让考生和家长看到差别在哪

示例（虚构数据，6 个志愿位）：

| 填法 | 期望效用 | 滑档概率 |
|---|---|---|
| 知衢优化 | **76.4** | **0.00%** |
| 只挑最想去的 6 个 | 67.6 | 6.85% |
| 只挑最稳的 6 个 | 63.9 | 0.00% |

## 快速开始

**考生**：打开[在线问卷](https://wjsgzz.github.io/Zhiqu/)，填完点"生成我的画像"，复制文本。

**使用 AI Agent**：把 `skills/zhiqu/` 放进 Agent 的技能目录（如 Claude Code 的 `.claude/skills/`），然后把画像发给它。

**只用计算器**：准备一份候选志愿 CSV（列说明见[数学模型](skills/zhiqu/references/volunteer-game.md#3-csv-列说明)），只需 Python 3.8+，无第三方依赖：

```bash
python3 skills/zhiqu/scripts/optimize.py skills/zhiqu/examples/candidates_demo.csv \
  --rank 22000 --slots 6 --u-fall -60 --max-fall 0.01
```

## 设计原则

- **位次比分数金贵**：分数随试卷难度浮动，位次不会
- **硬约束一票否决**：选科、体检、语种、学费不满足的，不进候选池
- **期望的是"效用"，不是排名**：好不好由考生自己的优先级决定，模型不替人选
- **事实、偏好、判断分开**：每个概率都注明数据来源，每个打分都写明理由
