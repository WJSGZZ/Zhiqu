「衢」是四通八达的路口。知衢帮高考考生做两件事：

- **看清方向**：用一份 15–20 分钟的问卷盘点分数、目标、兴趣、性格和现实约束，生成一段「画像」
- **算清志愿**：AI 读取画像，给出适合的专业方向；再根据历年录取位次估计每个志愿的录取概率，排出一张**期望收益最高、滑档风险可控**的志愿表

"收益"不是学校排名，而是按考生自己排出的优先级（学校、专业、城市、前景、稳妥）来计算的。

**怎么用：**

1. 考生打开[在线问卷](https://wjsgzz.github.io/Zhiqu/)，填完后复制生成的「画像」
2. 把本仓库链接 `https://github.com/WJSGZZ/Zhiqu` 发给你的 AI Agent（Claude Code、Codex、Kimi、豆包、DeepSeek 都可以），说一句「安装并使用这个技能」，它会自己装好；然后把画像发给它，用大白话对话
3. 拿到一份 PDF 决策报告：一句话结论、推荐方向、排好顺序的志愿表、每一格的录取概率、风险对比、要亲自核对和询问的事项，全部写在里面；报告末尾还会按你的情况预备一组"可以直接问 AI"的问题（[看示例报告：2027 年浙江、想学计算机的虚构考生](skills/zhiqu/examples/case_b_zhejiang_2027/report.pdf)）

> 知衢不是官方工具，也不保证录取。一切以本省教育考试院和各校当年的招生章程为准。

### 读研版

本科生读研前也要做一次选择，而且路更多：考研（一年只能报一所，失败靠调剂）、境外读研、国内的中外合作办学（有的走统考、发中国学历，有的学校自主招生、只发外方学位）、先工作、考公。读研版先判断**该走哪条路**，再在路内选学校和项目，给出按月的时间线和失败后的备选。

1. 打开[在线问卷](https://wjsgzz.github.io/Zhiqu/)，选「读研规划」，约 15 分钟，复制生成的画像（以 `【读研 · 自我盘点】` 开头）
2. 把画像发给装好知衢的 AI

规则以教育部当年《全国硕士研究生招生工作管理规定》为准（当前收录 2027 年版）。保研（推免）不需要填报志愿，不在读研版范围内。院校数据在确定学生和方向后才按需收集。

### 求职版

专科、本科、硕士都适用。目标是找到**工作内容、收入、城市、节奏都满意，自己也做得好**的工作：先从兴趣、能力和底线找出几个具体的职业方向；在投递中就诊断卡在哪一步；手里有 offer 就算清到手收入、时薪和合同条件，再按你自己的优先级比较。

1. 打开[在线问卷](https://wjsgzz.github.io/Zhiqu/)，选「求职方向」，约 15 分钟，复制生成的画像（以 `【求职 · 自我盘点】` 开头）
2. 把画像发给装好知衢的 AI

## 使用教程

只有两步：考生填问卷，然后把画像交给装了知衢技能的 AI。查数据、算位次、排志愿都由 AI 完成，你只需要用大白话和它对话。

### 第一步：填问卷，生成画像

1. 打开 **[在线问卷](https://wjsgzz.github.io/Zhiqu/)**，选「高考志愿」，手机和电脑都能用。
2. 先准备好：**全省位次**（比分数更重要，查本省"一分一段表"即可）和**选科组合**。
3. 按顺序填完十节。拿不准的题可以留空；选了"出国""考公"这类选项，下面会自动出现追问。
4. 第九节"排个序"最关键：按你真正在乎的程度，依次点选五项，它决定了后面怎么计算收益。
5. 点页面底部的 **「生成我的画像」** → **「一键复制」**。复制出来的是一段以 `【高考志愿 · 自我盘点】` 开头的文字。

作答会自动保存在当前浏览器里，中途关掉页面再打开还在。换设备或清理浏览器数据后会丢失。

### 第二步：让 AI 分析方向、排志愿

**最省事的装法**：把仓库链接发给 AI，说「安装并使用这个技能」。AI 会按本页顶部「给 AI Agent」一节自己完成安装。

**手动安装技能**（需要 [Claude Code](https://claude.com/claude-code) 或 Codex 这类能运行本地脚本的 AI Agent，以及 Python 3.8+）：

```bash
git clone https://github.com/WJSGZZ/Zhiqu.git
```

把 `Zhiqu/skills/zhiqu` 整个文件夹放进 Agent 的技能目录：

| Agent | 放到 |
|---|---|
| Claude Code（所有项目可用） | `~/.claude/skills/zhiqu/` |
| Claude Code（只在某个项目用） | `<项目>/.claude/skills/zhiqu/` |
| Codex | `~/.codex/skills/zhiqu/` |

以 Claude Code 为例：

```bash
mkdir -p ~/.claude/skills && cp -r Zhiqu/skills/zhiqu ~/.claude/skills/
```

**开始对话**。把画像粘贴给 AI，并说明你想要什么，例如：

```
这是我的知衢画像，帮我分析适合的专业方向。
【高考志愿 · 自我盘点】
……
```

```
按这份画像帮我排本科批的志愿表，我是 2027 年 XX 省考生。
```

AI 会按以下顺序工作，每一步你都可以打断或纠正：

1. **查缺**：只追问会影响结论的信息，比如位次、选科、体检、学费上限、是否服从调剂。
2. **找方向**：给出 2–4 个专业方向，每个都附上证据、反证，以及怎么验证（通常是去读目标院校的培养方案）。
3. **核实数据**：查本省当年的填报规则（志愿个数、专业组模式）、一分一段表和候选志愿的历年最低录取位次，并注明出处。
4. **预测**：换算分数与位次；还没出分就按估分给出位次区间；预测每个志愿今年的录取位次和分数线，以及你单独过线的概率。
5. **打分**：给每个候选志愿的学校、专业、城市、前景打分，按你的第九节排序加权，并请你确认。
6. **计算**：算出期望收益最高的志愿表，同时和"只冲名校""只求稳"两种填法对比。
7. **交付报告**：生成一份 PDF 决策报告。开头是给普通人看的一句话结论和摘要，后面是志愿表（每一格的理由、录取概率、冲/稳/保）、三种填法的对比、换参数后结论会不会变、院校调研、填报前核对清单，最后是方法、数据来源和声明。

**用好它的几个建议**：

- 数据越实，结果越可靠。如果你手上有考试院的投档表、学校的分专业录取表，直接发给 AI。
- 觉得某个打分不对就直接说，比如"我其实很想去成都"。AI 会改权重重新计算。
- 想考研或想早点实习，就告诉 AI。它会帮你查目标学校的推免率、升学去向、课程负荷和当地实习机会，并给你一份问学长学姐的问题清单。学长学姐要由你亲自去问（AI 不代为联系），问完把回答发给 AI，它会帮你整理、判断哪些可信。
- 家长和你想法不一样时，可以让 AI 按两种排序各算一版，对比两张表的差别。
- 还没出分也能先用：告诉 AI 你的估分和大概误差，它会按往年数据给出位次区间，先把方向和候选池准备好，出分后再精算。

## 填志愿的冷知识

下面几条来自平行志愿的投档规则，以及我们对 10 个省份官方投档数据的回测（详见[回测记录](skills/zhiqu/references/backtests.md)）。

1. **把保底志愿放在前面，是在浪费志愿。** 平行志愿是先看分数、再按你填的顺序逐个检索：排在前面的志愿不会挤掉后面志愿的机会。所以表内应该按喜好从高到低排；把冲刺志愿放在保底后面，就等于没填。
2. **不服从调剂，不是"大不了去下一个志愿"。** 一旦投档后被退档，通常直接掉出本批次，不会再回头检索你后面的志愿。
3. **比往年，要比位次，不比分数。** 今年卷子难，全省的分都会往下掉，但"全省第两万名"年年都站在同一个位置。辽宁的投档分整体一年就能上下差 15 分，全是试卷难度造成的。
4. **招生人数翻倍，录取线几乎不动。** 在两省 4 万多组相邻两年的对比里，招生计划翻一倍，录取位次平均只放松 1%–3.5%。原因之一是扩招的专业会吸引更多人去报。
5. **往年的线，只有去年最有用。** 10 个省份的回测都显示，把前年、大前年平均进来，预测反而更不准；最好的做法是以去年为主，再修正全省整体的年度漂移。
6. **大小年因省而异，而且几乎没法拿来押宝。** 浙江去年异常的专业今年会轻微回调，河北却是去年变热的专业今年倾向继续变热，山东、辽宁则看不出规律。把这些规律加进预测，样本外误差几乎没有改善。"去年爆冷，今年必反弹"并不可靠。
7. **有一小批志愿每年都会"变脸"。** 浙江、河北、山东每年约 1%–3% 的专业，位次一年变化超过 40%，中外合作、小语种、冷门医学类最常见。
8. **"去年的第 5 组"，今年可能已经不是同一个组。** 在广东、江苏、湖南、上海等按院校专业组填报的省份，同一个组号一年后大幅"变脸"的比例高达 11%–45%，因为组号每年重编、组里的专业也会换。看往年线之前，先核对今年组里装的是什么专业。
9. **规则一变，全省洗牌。** 浙江 2024 年起执行新的选考科目要求，理工农医类九成以上专业要求同时选物理和化学。当年位次剧变的专业是往年的 5 倍，没招满的专业翻了一倍。
10. **"包学费、包工作"的定向计划，往往比普通批还难考。** 江苏乡村教师计划的投档线比同一所学校的普通批高近 50 分，广东教师专项、农村卫生专项的门槛也更高。真正"降分"的是面向农村地区的专项计划：广东高校专项的投档位次，大约是同校普通批的两倍。
11. **想考公，专业几乎决定了能报多少岗位。** 广东 2026 年省考本科可报的录用名额里，不限专业的只有 4.2%。法学专业能报其中约 31%，计算机 13%，物理学只有 0.4%。
12. **专业名字最会骗人。** "信息与计算科学"其实主要学数学，"生物医学工程"骨子里是工科。选专业前，先去看它的培养方案。

## 原理

一句话：平行志愿下，你会落到表中第一个"位次过线"的志愿，所以表内顺序应该按喜好排，真正要决定的是**选哪几个**。知衢用历年位次模拟今年录取线的波动（包括各校一起涨落），再逐个挑出让期望收益增加最多的志愿。在各志愿互相独立的情况下，这种挑法被证明是最优的（Chade & Smith, 2006）。详见[数学模型](skills/zhiqu/references/volunteer-game.md)。

用一份虚构数据（6 个志愿位）做对比：

| 填法 | 期望收益 | 滑档概率 |
|---|---|---|
| 知衢优化 | **76.4** | **0.00%** |
| 只挑最想去的 6 个 | 67.6 | 6.85% |
| 只挑最稳的 6 个 | 63.9 | 0.00% |
